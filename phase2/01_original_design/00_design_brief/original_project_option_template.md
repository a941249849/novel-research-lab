# Original Project Option Template

Future Hermes output is limited to original project candidates.

Each candidate must use this structure.

## Candidate Template

```yaml
project_codename:
genre_direction:
core_reader_promise:
selected_mechanism_ids:
  main:
  auxiliary:
  constraint:
mechanism_combination_logic:
original_world_premise:
protagonist_initial_condition:
core_conflict_engine:
power_or_growth_system:
resource_constraint:
hidden_state_or_public_mask:
risk_control_or_evasion_logic:
backlash_or_cost_model:
faction_or_social_pressure:
originality_risk_notes:
why_it_is_not_a_copy_of_source_books:
book_dna_mapping_notes:
narrative_dna_mapping_notes:
state_ledger_mapping_notes:
```

## Required Fields

- `project_codename`
- `genre_direction`
- `core_reader_promise`
- `selected_mechanism_ids`
- `mechanism_combination_logic`
- `original_world_premise`
- `protagonist_initial_condition`
- `core_conflict_engine`
- `power_or_growth_system`
- `resource_constraint`
- `hidden_state_or_public_mask`
- `risk_control_or_evasion_logic`
- `backlash_or_cost_model`
- `faction_or_social_pressure`
- `originality_risk_notes`
- `why_it_is_not_a_copy_of_source_books`

## Explicitly Forbidden In Candidate Output

Do not include:

- prose
- first chapter
- concrete scenes
- dialogue
- source-style paragraphs
- source proper nouns
- source artifact names
- source organization names
- source level names
- direct bridge from one source protagonist path

## Output Count

Future Hermes controlled entry may output exactly `3` original project candidates.

No extra candidates are allowed unless Owner approves a new task.
