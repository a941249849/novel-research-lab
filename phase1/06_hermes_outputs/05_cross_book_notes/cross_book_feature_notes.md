# Cross-book feature notes — Phase 1B Core7

范围：仅比较 7 本 Core skeleton 的抽象机制候选，不读取全文，不产出最终机制库。

## 1. 弱势起点不是单一“废柴”，而是不同类型的压迫源
- 《斗破苍穹》：公开等级跌落与尊严羞辱。
- 《凡人修仙传》：贫寒、低资质与资源不足。
- 《求魔》：资格缺失与身份不确定。
- 《人道至尊》：族群整体被压迫。
- 《诡秘之主》：认知与生存安全被异常事件剥夺。
- 可复用机制：先确定“被剥夺的核心权利”——尊严、资源、身份、族群未来、认知安全，而不是复用桥段。

## 2. 隐秘资产承担长期复利与暴露风险
- 典型形态：外置导师、可增殖资源、规则空间、古老传承、异常碎片、未来记忆。
- 叙事功能：给弱者可成长通道，同时制造“怀璧其罪”的持续风险。
- Schema 映射：StateLedger.inventory、public_mask、BookDNA.zero_sum_constraints。

## 3. 地图升级的四种模式
- 商业阶梯型：《斗破苍穹》从家族到学院、宗门、中州、远古族群、位面。
- 风险市场型：《凡人修仙传》从江湖到修仙界、跨界、仙界，每次重评估风险。
- 神话回环型：《遮天》《人道至尊》从现实/祖星出发，最终回到古史和宇宙正统。
- 认知冰山型：《诡秘之主》空间扩展让普通日常不断露出水面下的恐怖结构。

## 4. 压迫/释放节奏存在谱系差异
- 快速商业释放：《斗破苍穹》短压迫、强兑现。
- 长期风险压制：《凡人修仙传》压迫多，释放克制。
- 黑暗博弈释放：《蛊真人》释放来自规则套利而非道德胜利。
- 悲情延迟释放：《求魔》最终释放以主角缺席为代价。
- 史诗群像释放：《遮天》《人道至尊》释放常是旧人、旧誓、族群正统的回收。

## 5. 机制转化红线
- 不能把“青铜古棺、春秋蝉、小绿瓶、异火、灰雾、薪火、黑色碎片”等原著专名或标志物作为机制名。
- 应转化为：现实入口物、时间回切资产、资源增殖资产、可吞噬火种系统、仪式隔离空间、传承火种、身份触发碎片等更抽象功能。
- 原创时还必须改写外观、来源、使用代价、组织生态、触发条件和人物关系。
