命审台的石桌面还留着昨夜未干的潮气。仇慎把三样东西分开摆：共同保管箱从塌屋基下取回后沾的灰泥还在箱角板缝里，箱盖上三户各自的轮守纸角叠得齐整，没有一张被补过字；废弃命址内壁的压痕拓片卷在竹管里，竹管两端用黄蜡封了口，蜡面上有仇慎自己半印冻结前最后一次落下的冷金薄纹；顾巡退回的那道追缴令搁在最远处，令纸对折线上归属断裂的标记从纸面凸起来，摸上去像干裂的旧疤。

陆沉渊站在石桌短边。他没坐，左膝撑不住坐下去再站起来的那一下。手腕上骨色苍白的冷痕从袖口探出半截，在清早的光线里比昨天又白了一层，像是有人拿冰块沿着腕骨内侧画了一道擦不掉的粉线。胸骨旧裂处闷响了一声，他把下颌收紧顶住那股往上涌的东西，喉头滚了一下，吞回去的味道又冷又涩，像含了一口碎石粉。

顾巡站在长边靠门那一侧。左手腕的铁环今天没碰石壁，因为他把那只手整个插进袖筒里，关节僵到弯不出角度，袖子鼓起一块硬邦邦的轮廓。右手五指微曲搁在桌沿上，指腹有磨出来的新茧——那是这几天被迫换手执笔留下的痕迹。他面前摊着从断梁上带回的木屑，和退回的追缴令并排放，中间隔了两指宽的空。

仇慎没有抬头。

他先拿竹管。蜡封揭开时发出一声脆响，拓片抽出来铺在桌面上，边角卷翘，他用掌根压住。压痕拓下来是两段：一段向外推，一段向内收，纹理方向和宽度都与顾巡带回的木屑吻合。拓片左上角有仇慎自己的验核小字，墨迹干得发灰，落款日期是封存当月。

然后他拿追缴令。令纸展开，归属断裂标记正好压在顾家追缴泥灯巷的第三行——那一行写的是一笔命火征收，征收对象是泥灯巷第六户，征收理由是欠征补缴。仇慎把令纸翻过来。背面有顾巡退回时新添的一句批语：本令所指征收与本地原件所记封存时序不符，归属断裂，退回复核。字迹歪斜，笔画起收都带着不自然的顿挫——左手腕僵死之后，顾巡只能用不惯的右手握笔，笔杆在虎口里搁不稳，每一横都向右下方坠出弧度，像是字本身也在往下沉。

仇慎又拿共同保管箱上的轮守纸。十张纸他没有合并，一张一张翻。每张纸上只记了那一天那一户亲眼看见的东西。第三张纸上，莫井兰的字迹记着封口蜡色未变、盏底泥痕干裂纹路与前日一致。第七张纸上，第二户轮守者只写了"未开箱、未闻异味、封口在"九个字。没有任何一张纸替另一户补写了不在场时的见证。

他把三样东西在桌上排成一条直线。拓片居左，轮守纸居中，追缴令居右。三件物证的间距一样宽，像仇慎用尺量过。

"顾家对泥灯巷第六户的第三行征收，"仇慎说。他的声音很干，像石桌面上那层潮气蒸掉之后剩下的灰白盐渍。"本地原件记录该户命火在封存期内未被调出，共同保管原件的轮守记录无补写、无缺项。废弃命址的压痕拓片显示一取一放两段同型纹路。追缴令退回时标注归属断裂。"

他停了一下。不是在等谁接话，是手指从桌面缩回来的时候蜷了一下，冻结在封档槽旁的那只左手上冷金暗纹微微发颤。

"这一笔不得继续列作欠征。改作错征退回。"

仇慎从桌下取出一只小铜匣。匣盖打开，里面躺着五盏户灯——泥灯巷被扣押的五盏，连同第六户的那盏。灯盏是冷的。淡青色的光从灯芯底部往上只够照亮半截灯身，上半截沉在暗里，像被人从中间切开。

他把第六户的灯盏单独取出来放在石桌正中。灯盏碰到石面的声音闷而短，铜底座的冷意透过石板往四周扩开一小圈深色水痕。然后他把剩下四盏依次排在旁边。

"错征退回，户灯归还。"

话音刚落的时候陆沉渊听见一声极细的响——不是从灯盏里发出来的，是从自己胸骨内侧传上来的，像一根旧裂纹被体腔里那层没咳出来的冷灰泡软了一分。他右手不自觉地按住左边肋骨。指尖摸到的体温比手腕上的冷痕稍微暖一点，但那点暖正在往外退，像有什么东西从肋骨缝里把热度一丝一丝地往外抽。

没有人鼓掌。没有人道谢。莫井兰站在门外廊柱旁边，手背上取盏时磨开的那道旧口子已经结了痂，痂色发暗，她的眼睛从户灯上移开，看了一眼陆沉渊按着肋骨的手，又移回去。

顾巡在仇慎说完之后把右手从桌沿收回去。指腹上的新茧在袖口边缘蹭了一下。他没有多余的动作，只是把面前的木屑重新拢进一只布包里，布包扎口的时候单手拽绳，绳结系得歪歪扭扭。他自始至终没有碰过那张追缴令，仿佛那张纸从退回的那一刻起就不再与他有关。

户灯发回来的程序走完后，桌面上空出一片石色。仇慎没有收拓片，没有收轮守纸。他把手从桌面完全缩回去放在膝盖上。

然后廊外的光暗了一格。

不是云遮日。是入口方向的空气里多了一层银灰色的东西。质地比昨天在废弃命址出口看到的影印更薄，薄到几乎透明，只在边缘处凝成一道细霜。霜线沿着命审台外墙的砖缝蔓延，爬过廊柱底座，停在门槛前。

霜线上浮出字。

不是仇慎的字，不是顾巡的字。字迹没有笔锋，像是从砖缝里长出来的冰晶被风吹成了形状。字只有一行：

泥灯巷须于三日期限内指定交人姓名。

字下面是三道短横——每一道短横的颜色比上一道深一个层次，从银灰到铅灰到近乎黑色。第一道短横的末端微微弯曲，像一枚还没有合拢的钩。

仇慎看见那行字的时候下颌肌肉抽紧了一下。他认得那个手法——州府命库影使闻照微的冷影刻度，留在砖缝里的不是墨，是一种借霜固形的法权印记。三道刻度代表三次灯温核查，每闭合一道，全巷户灯就会在原有失温基础上再降一个品级。

他站起来。椅子脚在石地上刮出一声短响。

"本地无权拒绝州府覆核要求，"他说。声音比刚才宣布改账时低了半截，像是那口气在从喉咙到嘴唇之间被什么东西压扁了。"期限三日，逾期未指定交人，全巷户灯永久失温。"他看了一眼陆沉渊，又看了一眼门外的莫井兰。"本地命审台只记录是否有人填写姓名。填写与否，是泥灯巷住户自行决定的事项。"

他把一张空白名帖放在石桌上。名帖上方印着州府命库的转运残印格式，下方是一个等着填姓名的长方形空格，空格里什么都没有。纸面泛着一层极淡的银光，那是州府封印留下的底色，冷得连纸纤维都像被冻硬了。

陆沉渊没有碰那张名帖。

他的右手还按在肋骨上，左手垂在身侧，手腕的冷痕从腕骨延伸到掌根。他看着那张空白名帖上的长方形空格。他知道那个空格等的是什么——如果填上他自己的名字，州府影使会把他作为交人收走，泥灯巷的三日期限立刻解除，户灯会回温，苏晚的掌背裂纹会暂时不再恶化。

他没有拿笔。

他没有替住户作答。

门外传来脚步声。不是一个人。泥灯巷的住户从巷口方向过来，前后隔着三五步的距离，脚步踩在砖地上的声音参差不齐，有拖步的，有顿步的，没有一个走得干脆。走在最前面的是莫井兰，她身后是第二户的轮守者，再后面是第六户刚拿回户灯的那家人——丈夫把灯盏捧在胸前，灯盏的淡青色光映在他下巴上，像一块浮在水面的薄冰。

他们看见了门槛前的霜线和那行字。

第六户的丈夫站住了。他低头看着手里刚领回来的灯盏，灯光冷得连掌心都照不暖，然后抬头看那行字。他的嘴唇动了一下，像在念"交人姓名"四个字，念到一半停住，喉结上下滚了滚，把后半截声音咽了回去。

莫井兰已经走到石桌边。她看见了那张空白名帖。她的视线从名帖上的空格移到陆沉渊脸上——他没有点头，没有摇头，没有给出任何暗示应该怎么选。

她把目光收回来，看着名帖。

然后她把轮守纸从桌上一张一张拿起来，叠好，放进自己衣袋里。那是她的、属于她轮守那一天的见证。她拿走的动作很慢，给了在场每一个人看清她在做什么的时间。最后一张纸塞进衣袋的时候布料发出细微的皱响。

"我不填。"

声音不大。说完之后她退到门柱旁边，手背上那条旧疤痂在袖口下面露出一截暗色。

第二户的轮守者走上前。他没有看名帖，看的是仇慎。"填了名字之后，被交出去的人还能回来吗？"

仇慎没有回答。他不是拒绝回答，是这个问题超出了他的本地权限。他只能记录。沉默里他的视线落在自己左手冷金暗纹上停了一瞬，又移开。

第二户的人站了一会儿。他的户灯还没从铜匣里取，灯盏冷光从匣缝里漏出来照在他鞋面上，把布鞋前端映出一小块惨淡的青白。他伸手把自己那盏户灯拿起来，灯身冰得他手指缩了一下，指节发出一声细微的骨响，然后他转身往门外走。走过门槛的时候他踩在霜线上，霜线没有碎，他的鞋底印在霜面上留下一道湿痕。

"不填。"他说。背对着屋里。

第六户的丈夫最后走到石桌前。他把灯盏放在名帖旁边。灯光和名帖上空格的白色挨在一起，一冷一空，两样东西都不给人任何温度。

他看了陆沉渊一眼。陆沉渊没有说话。没有用眼神做任何引导。他站在那里，左膝承重的那条腿微微打颤，手腕冷痕在光线里白得像骨头从皮肤下面顶出来。

第六户的丈夫把灯盏重新捧起来。灯盏从石面上离开的时候底座拖了一下，在名帖边缘留下一道极浅的冷凝水印。

"不填。"

仇慎坐回去。他从桌下取出登记簿，翻到新的一页。笔尖蘸了墨，墨汁在纸面上洇开一个极小的圆点之后他才落笔。他写的不是姓名。他写的是：泥灯巷住户拒绝填写交人姓名。到场三户，均拒。本地命审台无权追加追缴。

墨干了之后他把登记簿合上。合上的声音闷而短，和刚才灯盏碰石桌的声音一样。

门槛前的霜线上那三道短横还在。第一道的末端弯钩在日光移动的过程中像是合拢了一丝，又像是没有。银灰色的霜附在砖缝里，不化，不散，不长，只是等着下一次灯温核查到来时闭合。

苏晚站在巷口的回灯架旁边。回灯架是巷民自己搭的木架子，用来临时搁户灯，木条上有多年烟熏的黑色渍痕。她没有进命审台。她的掌背暗光在指根处停着，手背裂纹在清早的风里颤了颤，裂口边缘泛着一层干燥的灰白色，像冬天皲裂的泥墙。

住户们一个一个从命审台门里出来，捧着冷灯盏经过她身边，走回巷子深处。没有人把灯盏放到回灯架上。每一盏灯都冷得发青，每一个捧灯的人手指都缩着，指关节因为冷意发红发僵。

陆沉渊最后出来。他经过苏晚身边的时候，她看见他肋骨那侧的衣襟有一小片深色洇痕，不是汗，是冷灰渗进布料之后留下的颜色，边缘洇得不规则，像一块正在慢慢扩大的淤青。她没有伸手。他也没有停步。

他走过回灯架的时候，架子顶上落了一层极薄的霜。霜色银灰，和门槛前那一道同出一源。

巷口的风从护阵缺口灌进来。护阵裂口处的黑色空洞今天比昨天又大了一指宽，边缘处有细碎的暗色颗粒在往下掉，像一道正在剥落的旧墙。夜气不等天黑就已经开始从那道缺口往巷子里渗了，贴着地砖蔓延，凉意从脚底往上爬。
