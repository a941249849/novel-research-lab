# NRL 2026-07 市场驱动原创概念池 v0.1

> 状态：候选概念，不代表项目立项，不授权 Story Bible、创作资产或正文生产。
> 研究时间：2026-07-18。

## 一、热度判断

本轮不按榜单标题复刻题材，而把公开热度拆成四类可利用信号：

1. **都市玄幻、末世高武、游戏化叙事仍是男频强入口。** 2025 年行业报告将《诸神愚戏》《游戏入侵》《我不是戏神》列为番茄年度代表作品；同时指出年轻读者对互动感、探索感、参与感的需求正在推动多线叙事。
2. **玄幻、仙侠、历史仍有基本盘，但纯升级已经不够。** 纵横当前榜单同时出现传统玄幻、凡人修仙、历史、末世、高武和辅助职业题材，说明入口多元，竞争重点已转向“熟悉类型 + 新机制”。
3. **民俗、传统技艺、地域文化是有效差异化变量。** 国家新闻出版署明确提到古建、服饰、非遗与玄幻、仙侠、悬疑的融合；这类元素应参与规则、职业和冲突，而不是只做皮肤。
4. **平台正在治理低质与同质化。** 番茄官网近期列出低质治理、长篇推荐验证等公告；2025 行业报告也将 AI 低质内容和叙事同质化列为风险。因此候选必须同时具备快入口、人物情感和可验证的长篇机制。

## 二、候选组合

### A 级：建议进入下一轮立项复审

### 1. 《末日写进县志以后》

- **赛道**：民俗志怪 + 灾难求生 + 县域群像 + 轻规则悬疑
- **一句话**：县志馆临时工发现，新修县志会提前七天出现灾难记录；想让灾难消失，必须找回被地方历史故意删掉的人，而每补回一个名字，现实就会多出一段人人都记得、唯独他不记得的人生。
- **核心抓力**：第一章县志出现“七日后，全县无一人记得自己的母亲”；主角母亲却已失踪十年。
- **主角矛盾**：他靠删改档案替地方处理麻烦谋生，却必须用恢复真相的方式救人；每次修史都会改写自己的私人记忆。
- **长篇引擎**：村志异变 -> 县域灾谱 -> 河流与山脉的地方记忆 -> 省级志书战争 -> 全国失落地名网络。每一层扩大地图，也扩大“谁有权定义共同记忆”的冲突。
- **前三十章**：母亲遗忘灾、废弃水库婚书案、无名烈士回村三案串联；前两个案子闭环，第三案揭开县志不是预言而是灾难分配器。
- **NRL 机制组合**：CB-M3 认知冰山、CB-M4 外部倒计时、CB-M7 生存型势力冲突、CB-M9 古纪元断层、CB-M10 缺陷导师。
- **原创防线**：不用副本闯关、神明牌组或固定规则播报；所有超自然规则必须落在档案、地理、人情债和集体记忆上。
- **规模建议**：220-320 万字，12 卷；既可走番茄快节奏，也具备影视和有声改编潜力。

### 2. 《百工夜行录》

- **赛道**：都市高武 + 非遗职业 + 群像成长 + 东方幻想
- **一句话**：灵气复苏后，决定力量的不是血脉，而是濒临消失的手艺；古建修复学徒能借用百工祖师留下的“工序”，但每完成一次超凡修复，就必须替原物承担它经历过的一次损伤。
- **核心抓力**：城市地铁贯穿无名古墓，全城建筑开始在午夜“退回”建造前；主角必须在天亮前补完一根从史书中被抹去的梁。
- **主角矛盾**：他想证明父亲死于工程事故并非失误，却发现父亲主动拆掉了一座保护城市的古建筑；修复父亲的名誉，可能等于恢复一场更大的灾难。
- **力量体系**：识材、定式、起工、合榫、镇物、传承、立宗。能力来自木作、锻造、织染、陶烧、纸扎、戏装等真实工序的幻想转译，每种手艺都有材料、时间和身体代价。
- **长篇引擎**：城市工程事故 -> 行业公会竞争 -> 地域工艺谱系 -> 国运级巨构维护 -> 人类文明“可维修性”之争。升级靠承担更复杂的公共责任，不靠无限加点。
- **前三十章**：地铁古梁、纸扎代班人、失火戏楼三线交汇，形成第一支五人百工小队。
- **NRL 机制组合**：CB-M2 高收益高暴露资产、CB-M6 辅助职业抬升、CB-M7 势力碰撞、CB-M11 认知扮演与污染、CB-M12 群像回流。
- **原创防线**：非遗不是技能名称库；每项能力必须对应工序逻辑、材料约束、师承伦理和现实职业处境。
- **规模建议**：300-450 万字，15 卷；本轮商业性、差异化和 IP 可视化最均衡。

### 3. 《山河停服之后》

- **赛道**：末世高武 + 文明维护 + 游戏化探索 + 多线群像
- **一句话**：现实每晚会有一个地区进入“停服维护”，被留在其中的人会变成历史版本的自己；主角是唯一能读懂维护日志的人，却发现所谓系统只是上一代文明用来延缓世界崩溃的工单平台。
- **核心抓力**：高考前夜，主角所在考场被回滚到三十年前，所有人都成了父母年轻时认识的人，只有一个本不该出生的同学还保持原样。
- **核心机制**：每次修复必须在“保留当前人命、恢复历史事实、维持区域稳定”三者中牺牲一项；选择会永久成为下一地区的系统规则。
- **长篇引擎**：校园维护区 -> 城市版本冲突 -> 省域服务器 -> 旧文明运维者 -> 世界是否值得继续迭代。副本结果持续回写现实，杜绝互不相干的单元剧。
- **情感支点**：主角逐步发现每次世界回滚，母亲都会更早忘记他；队友则可能是某次错误维护产生的“合法漏洞”。
- **前三十章**：考场回滚、旧商场停服、城市更新工单，完成“系统并非奖励主角，而是在征用主角”的反转。
- **NRL 机制组合**：CB-M3 地图降维、CB-M4 倒计时、CB-M5 身份隔离、CB-M8 自我缺席式奉献、CB-M9 断层遗址。
- **原创防线**：没有神祇卡牌、职业转职和通关积分；核心爽点来自修复权限、现实回写和群体选择。
- **规模建议**：250-360 万字，12 卷；番茄适配强，但必须严控设定解释量。

### B 级：值得保留，需验证开篇或平台方向

### 4. 《潮神失踪以后》

- **赛道**：海洋东方幻想 + 港口经营 + 民俗冒险 + 商路群像
- **一句话**：沿海所有潮汐突然晚到一个时辰，破产的船厂继承人发现每座港口都在偷偷扣留自己的潮神；他能修船，也能修复海与人的旧约，但每恢复一条航路，就会唤醒一种被贸易史掩埋的海上灾害。
- **卖点**：妈祖信俗、造船、海图、岛屿贸易和海怪生态共同构成规则；“港口信誉”既是商业资产也是超凡力量。
- **长篇引擎**：小渔港自救 -> 沿海港盟 -> 群岛商路 -> 远洋文明 -> 全球潮汐契约。天然适合地图扩张和势力经营。
- **风险**：海洋题材的即时点击弱于高武，需要用“全城退潮，海底出现一条回家街”做强开篇。
- **规模建议**：260-380 万字，13 卷；起点/纵横适配优于纯番茄。

### 5. 《仙门基础设施维护手册》

- **赛道**：仙侠经营 + 技术职业 + 宗门群像 + 灾害治理
- **一句话**：主角继承的不是仙门，而是一家负责维护灵脉、飞舟航道和护山大阵的破产工坊；他修好的每一处基础设施，都会自动恢复一份数百年前无人履行的服务契约。
- **卖点**：把炼器、阵法等辅助职业从配角能力提升为世界运行核心；爽点是修复系统、谈判收费、建立标准，而不是开店签到。
- **长篇引擎**：乡镇灵井 -> 宗门电网式灵脉 -> 跨州飞舟交通 -> 上界基础设施垄断 -> 修真文明公共品战争。
- **风险**：经营文容易变流水账，必须保证每项工程绑定人物选择、势力代价和不可逆状态变化。
- **规模建议**：300-500 万字，16 卷；最适合作为 NRL 长篇机制压力测试项目。

### 6. 《大明报灾人》

- **赛道**：历史架空 + 灾害治理 + 官场博弈 + 技术成长
- **一句话**：驿站小吏能听见灾民尚未写出的报灾文书，却不能证明消息从何而来；他每救下一地，就会让另一份灾情更难抵达朝廷，只能从送信人做起，重建一套不会被权力截断的灾情网络。
- **卖点**：不以背百科全书碾压古人，能力只提供模糊预警；真正升级的是调查、组织、测量、仓储、河工和制度信用。
- **长篇引擎**：县域水患 -> 漕运与仓政 -> 边地军粮 -> 全国灾情网络 -> 王朝在连续极端气候下的制度选择。
- **风险**：考据成本高，真实朝代与架空尺度必须在立项时锁定；番茄标题可更直给，正文仍需克制现代口吻。
- **规模建议**：220-320 万字，12 卷；纵横/起点适配更高。

## 四、建议的下一门禁

不应同时启动六本书。下一步只对前三名做 **Concept Stress Test**：

1. 各产出三种开篇承诺、主角欲望/恐惧/代价三角、世界规则反例和 30 章节奏摘要；
2. 用九类创作资产检查缺口，但不生成完整 Story Bible；
3. 做标题与简介的番茄/起点双版本测试；
4. 选出一部进入 `project-init`，其余继续留在候选池；
5. 项目初始化后仍保持 `content_authorized=false`，直到 Owner 单独授权正文。
