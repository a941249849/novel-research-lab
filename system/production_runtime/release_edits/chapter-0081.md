寒风从那道永久缺口里钻进来，贴着地面走，把碎砖上的灰吹得一阵一阵翻起。护阵被切走的一段边缘还露着白裂，裂里没有暖意，只有被风磨得发硬的银灰火屑。苏晚用左膝抵住铺板，把这块充作临时风档的木板往缺口前又顶了半寸。她掌背上先前被阵角划开的那点血痕，此时被粗糙的木刺蹭得散开，在寒风里红得很薄，转眼便被周围粘连的冷气压得发暗。她没有去擦，任由那股黏湿在手背上慢慢被冻得发硬。陆沉渊站在铺板内侧，整个人陷在墙角落下的阴影里。他的右臂软软垂着，袖管在风里微微晃动。腕骨、肘弯、肩下的三根暗金细线绷得极紧，隐没在衣袖深处，随着风声一紧一松地勒着皮肉，像有看不见的手在外头拽他。他右眼瞎了，只把左眼望向断砖边缘。那上面原本没有东西，此时一片黑影自雾里压下来，落在裂缝旁慢慢抻平。它薄得像一张水泡过的纸，边缘却齐整得过分，贴住砖面时，砖缝里残存的冷灰一下全熄了。巷子两边的命灯同时矮下去一截，火苗褪成发白的颜色。苏晚扶灯的手停住了。

在影印正中有一道浅灰竖纹，像从纸背后压出的门缝。门缝里传出极轻的锁扣响，随即有女声落下，不高，也没有急意：“泥灯巷外层交付已收。”闻照微并未踏进巷子。她的影子站在断口外，肩颈和衣摆都被雾吞得模糊，只有一只抬起的手指向地上的影印，指尖不碰砖，影印便凹陷了一层，字迹底部的亮色被擦得更鲜明。“协助隐匿的挂记，依前核结果撤下。禁修亦撤。”她停了停，仿佛在等巷里谁去摸那张影印，“但后压时刻牵出的活体校时，不在此列。陆沉渊，到案。”暗金丝线骤然勒进陆沉渊腕骨。他肩背一歪，左手按住墙，指节在粗糙砖面上擦出一层白灰。没有人上来扶他，巷里只响着各家门后压低的呼吸声。那些人已经把私人的烟灰、防风记号从阵砖上刮掉，也已经看着阵段被拖出巷口；现在没有谁的名字该被推到这张影印上。陆沉渊缓过一口气，抬头问：“凭据落在哪里？”

“州府复核入口。”闻照微说，“影印熄灭前抵达，准入外层校时。逾时，冻结你外层通行记录，沿路关口不再认你此前留下的通行痕。到时再要复核，只能按拒到处置。”“冻结多久？”“校时未结，冻结不解。”她得平直，影印竖纹却扩开了些。冷亮沿着纹路往下流，压到陆沉渊脚前，像一道没能跨过去的水线。巷口的命灯又低了一次，苏晚那盏灯罩里原本贴着裂缝游动的暖色忽然退到灯芯深处，灯壁发出细微的绷裂声。苏晚低头看了一眼，没有捂灯罩，也没有把灯递给别人。她手背上的血已经冻凝，指尖发青。她把灯提稳，转过来问：“到案的是他。我的旧债、这盏灯、巷里交出去的阵段，都不添在他的令上，令上也不许添回来。”闻照微并未立即回答。影印边缘浮起一圈极细的灰，风卷过去却不散，像被无形的指腹一遍遍按进砖里。陆沉渊看见那圈灰，胸口像被凉铁贴了一下。封在衣襟里的旧章也有了动静，沉重地压迫着他的胸口。

闻照微的目光落在那只手上。“苏晚，你的独立追缴仍在外层可见。它不在今次到案令里。你若担心他借此拖延，可以替他作一份债线切断陈述。州府会将你的姓名、旧债印和命灯裂损重新核对，再给他留出——”“不要。”苏晚答得很快。她把灯提得更高，灯火照亮她掌背那道新凝固的血痕，也照亮命灯上横过灯腹的深灰裂纹，在失温里显得更深。“我自己的债，我自己认。他到案，他自己认。你们要核我的，就照旧核；别把我的债塞进他身上，也别拿他的令替我改一笔。更不要拿巷里谁的灯来填。”门后有人轻轻挪脚，旋即又安静下来。没有人说愿意或不愿意，那份安静没有替谁担保，只是把每一盏灯都留在原处。闻照微的影子纹丝不动：“你很清楚，他此刻离巷，便失去你们的遮护。那枚碎章一旦在路上现痕，州府会依回收令跟进。你们若不愿送，谁也不会被记作拒令；他若不去，外层冻结落下，复核便退回强制追索。”

陆沉渊从墙上收回左手，掌心蹭满灰。他把衣襟压紧，企图压制旧章带来的下坠感。他能看见的只有砖边的冷亮、母亲命灯失掉的温度，和金线在右臂下勒出的三道硬痕。“我到案。”他说。暗金线同时一震。影印上那道竖纹向两边裂开，露出一行新的字。字在砖面投下一条向雾外伸去的细灰线。线头停在巷口，线尾没入远处黑暗，像有一扇门正隔着整座城等人把手伸过去。闻照微的声音随之落下：“公开受令，即刻起计时。”陆沉渊看着那条灰线，问：“到案条件。”“携本人生时痕，接受外层校时。不得以假命页遮蔽。残印若在身，列为待验物。”“待验，不是交出。”“待验。”“也不是调用巷里住户命火。”“州府没有向泥灯巷索要命火。”“不能把苏晚并到我的到案记录里。”“今次令上没有并入。”

陆沉渊盯着影印。影印边缘的一点灰光沿着断砖的棱角慢慢爬。他知道这并不等于母亲的旧债被抹掉，也不等于裂纹会少一道。闻照微只把令推到了巷口，把后果一寸寸摆明。他抬起左手，掌心向下，压在影印旁边的断砖上。冰冷从砖面钻进掌骨，顺着手臂往肩里走。衣襟内的印壳骤然一烫，带着旧灯烧尽时才有的焦味。银灰印屑从他指缝里渗出来，落在砖上，没等风吹便被影印吸住。右臂那三根金线随即收紧，肩下像被钩子往外扯了一把，陆沉渊咬住牙，额角渗出冷汗。闻照微看见了那点银灰，只说：“那物件仍在回收范围。”“我知道。”“到州府入口前，它若自行启用，沿路会留痕。”“我知道。”“若你愿意交出，州府可以另议暂缓。”陆沉渊把手从砖上抬开。掌心冻得失去血色，灰屑却黏在纹路里。他没有拍掉，只将那只手握成拳。“我到案。”他说，“不交残印。不借命火。不拿她的债换时间，也不拿巷子给我背路。”

苏晚看着他。风把她鬓边的碎发吹到唇角，她没有腾出手去拨，只把命灯搁在铺板上，走近两步。她伸手碰了碰他左肩，落得很轻，避开那根勒在肩下的金线。“再说一遍。”她道。陆沉渊的喉结动了动。巷子里的灯都发白，门后的街坊依旧没有出来答话。断口外，闻照微的影子像一笔悬着的墨。陆沉渊看着母亲命灯上那道深灰裂纹，声音比刚才低，却让巷里每个人都听得见：“我走，是我自己去校时。那印在我身上，谁也不替我认来源。你们的灯、你们的债、你们留在巷里的名字，都不跟着我出这道口。娘的债也不算到我令上；我的令，更不能压回她身上。”苏晚的手停在他肩头片刻，随后收回去。她没有说去，也没有叫他留下。她只是把命灯重新提起，灯焰在她指间抖了一下，勉强回了一丝黄。“我听见了。”她说。这一句落下，巷内有几盏灯缓慢地稳住火苗。没有谁把灯凑过来给陆沉渊照路，也没有谁把灯绳交到他手里。

缺口依然漏风，护阵白裂依然横在那里。可那些灯各自留在原处，照着各自门前被风刮花的地面。闻照微抬起的手终于落下。影印上的灰线蓦地亮了一截，随即又暗回去。陆沉渊正要转身，影印最下方却浮出一条先前藏在冷亮里的细字。那字比上面的令文浅，像被谁刻在纸背后，等到他亲口受令才翻过来。苏晚先看清了，脸色在灯光里白了一层：“下面还有一条。”闻照微没有替她读。苏晚死死盯着那行字迹，手背上那道新凝固的血痕显得越发清晰，血液已经不再流动。她将握着命灯柄的右手收紧，灯焰一缩，映得她脸色发白。雾气外的闻照微向后退开一步，在见证的边界之内，没有任何人出来替苏晚分担这“只送路”背后的重量，也没有人能替她将代表无底深渊的“作保”字样抹去。巷口之外是无灯的漆黑边界，没有一丝光明能透进来。暗金丝网一紧一缩，锁扣每响一下，陆沉渊腕上的金线便紧一分；他垂着失去知觉的右臂，左手却按在封档外沿，没有碰那片银灰。苏晚看了他一眼，那一眼很短，很冷。她没有把干结的血迹抹到影印上，甚至没有去碰他的手。风声呼啸，冷光又向白裂处探了半寸。

陆沉渊低下头，那只尚能视物的左眼一字字在字迹上扫过。那行字被刻得极深，如同钩子一般，紧紧钩在青砖缝里，显露出最完整的意思：“同行者出巷之前，须自行定名：只送路，或为残印来源作保。”风声大作，影印边缘发出轻响。苏晚的手停在半空，指尖与冷光只有半寸。她把手中的命灯往自己的身侧微微挪开了半寸，任由那片无灯的漆黑将自己的肩膀吞没，但命灯裂纹深处漏出的暗黄光芒，却依然固执地照亮着那行用来套住他们的细小字眼。巷子外的黑暗里，有人踩碎了地面上结出的薄霜，发出清脆的碎裂声。几道从门缝里投射出来的冰冷目光，隔着残破的阵砖空隙，冷冷地落在了他们身上，依旧没有任何声音替他们回答。陆沉渊只用左手将掌心翻开，让掌纹里那些擦不掉的银灰印屑暴露在光亮中，随后退开一步，将面前刻满字迹的砖石空了出来，留给苏晚和巷子里所有的见证者，看清那最终的选择。“只送路”三个字在微光中轻轻起伏，其后的话却像冰冷的倒钩，牵连着阵砖外沿上尚未完全消退的宿印灰屑。苏晚垂眼看着自己那只在冷风中瑟瑟发抖的手背。她没有把血抹上去，也没有伸手去拉住他的手。她只是冷冷地立在无灯的边界之上，任由寒风吹过她单薄的衣襟。“我自己定。”她轻声说道，眼神越过了冰冷的影印，投向了巷道外那片深不见底的浓雾。
