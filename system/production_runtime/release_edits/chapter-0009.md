辰时未过，命籍衙的门扇还含着昨夜积下的冷气。门槛缝里凝着一层薄白，像霜，又不像霜；人一靠近，鞋底便被那股阴凉黏住，拖不出半点响。

陆沉渊走得很慢。

左眼眼皮垂死般合着，眉骨下的焦纹已结成硬壳，每一步落稳，颧侧便有一两点碎黑脱下来，轻轻坠在青砖上。他没有抬手去擦。右手垂在身侧，掌心那圈暗红印线嵌进旧伤，指节稍一弯曲，便像有细线在皮肉里收紧。

苏晚扶他走到门外便松了手。她掌背缠着旧布，布边磨得起毛，裂口处透出的凉意却没散。隔着衣袖，陆沉渊仍能感觉到她指节失温后的僵硬。

“进去以后，只认你亲眼看见的。”她说。

陆沉渊点头，没有多问。

命审台左侧，莫井兰抱着陶片站着。她把陶片护在臂弯里，指尖扣住边缘，连衣料都没让它碰到台面。顾婶站在另一边，双手空空，神色紧绷。门上的追缴纸是仇慎亲自揭下来的，纸角还黏着昨夜门缝里的湿泥。台后那盏顾家户灯摆得很正，焰尖发白，细得仿佛稍有一阵风，便会从中折断。

仇慎先看向陆沉渊的左眼。

“今日先验在场认痕。”他把冷金小印搁到台沿，印底与木面相触，发出一声极轻的闷响，“再验纸下原灰。陶片不交，也得贴台给看。谁多说一句没亲眼见过的，后一句作废。”

莫井兰没有动。

“我的陶片不贴你的印。”

“没说要印。”

“也不压在残页上。”

仇慎的嘴角收紧了一线。他没同她争，只从命审台下抽出一张本地残页，放在追缴纸旁。残页边缘破得厉害，几处墨迹像被冷灰慢慢啃过，褪得发白。他把纸平放，手指离开时刻意没有压住破口。

陆沉渊只扫了一眼，便移开视线。

仇慎道：“看字。”

“我不看。”

“你来复核残籍，不看字看什么？”

“我只能认灰。”陆沉渊抬起右手，掌心暗红印线在旧伤上勒出一道更深的痕，“残页写着谁，欠着谁，不在我能认的范围里。你若要我认人，我现在就退出。”

顾婶立刻往后退了半步，后背几乎碰到台柱。莫井兰抱陶片的手也紧了些。

仇慎的手停在冷金小印上。台后的户灯轻轻一颤，焰尖褪去一点暖色，只余下惨白。他看了眼灯，翻过残页，使有字的一面朝下。

“那就只认灰。”

追缴纸被他慢慢压平。

昨夜偏落的冷金印在纸面留下半轮薄痕，原该落印的位置空着。灰线从纸边下穿出来，绕开那处空印位，又断在旁注之前。残页背面同样有一处灰白空缺，只有半指宽，紧贴着一块陈旧的冷金痕。

两处相隔不过一掌。

陆沉渊没有立即俯身。他先让顾婶站到能看清纸边的位置，又问莫井兰：“陶片旧墨边，你看得见？”

“看得见。”

“纸里的灰呢？”

“看见它从边下出来。别的我不认。”

“顾婶？”

顾婶盯着追缴纸，喉头动了一下：“我只认这张纸昨夜贴在我家门上。揭下前没换过。陶片也没打开。”

仇慎冷声道：“命审台不是给你们排词的地方。”

“那你来问。”陆沉渊说，“一人一句，问完再动印。”

仇慎额角的青筋跳了一下。他看着陆沉渊，像要从那张失血的脸上看出别的意思，最终却仍先开了口。

顾婶只说门纸未换。莫井兰只说陶片一直在她怀里，又说昨夜新咳出的冷灰停在冷金边外。苏晚站在门槛外，没替任何人补话，只把裹着掌背的手收进袖中，明确拒绝验灯。

话落完，衙内静了一刻。

门外街巷尚未真正醒透，远处偶有木轮压过石路的钝响，传到这里时已被冷气磨平。户灯的细焰没有晃，却显得比先前更白。

陆沉渊俯下身，右眼贴近命审台。

识账术起得很浅。

没有火光，没有响动，只有瞳孔边缘缓慢渗出一圈焦黑，像被谁用冷墨细细描过。纸面上的灰在他眼中拆成粗细不一的银屑：昨夜门纸所沾的湿泥沉在最下，新写旁注浮在上层，冷金偏印则压过旁注的边缘。那条原灰更旧，细屑已钻进纸纤维，死死伏着，不肯沾上空印位。

残页背面的灰却沉在旧冷金痕之下。

陆沉渊呼吸顿住。

他没有追灰从何处来，也不去看纸背被翻过去的字，只盯住那半指空缺。空缺旁的灰粒微微朝外翻，像曾被什么东西压住，又在后来被人揭开；追缴纸上的灰粒则朝里伏，贴纸时便已存在。方向不同，避开的却都是本地冷金印该落的位置。

银灰火屑骤然铺满右眼。

陆沉渊扶住台沿，掌骨里传出一串极细的摩擦声。左眼下结硬的焦壳崩开，黑屑落进残页和追缴纸之间。他急忙偏头，仍有一片沾在命审台上。

仇慎抬手便要落印。

“别压我的灰。”陆沉渊咳出声。

腥冷从喉间翻上来，一口灰落在台角。新灰摊得松，碰到冷金小印投下的阴影便停住，没有朝两张纸爬。莫井兰看得分明，低声道：“这口灰停在外头。”

顾婶也应了一声：“没碰纸。”

仇慎没有否认。他把小印移开半寸，印底擦过台面，拖出一道冷金细痕。

顾家户灯随之一暗。

焰尖从白转灰，灯腹里发出极轻的一声裂响，像细瓷被指甲刮了一下。

顾婶猛地转过身。

“你碰了什么？”

“只擦了台。”

“灯先前没响。”

仇慎脸上的血色退了些。他低头看自己的印底。冷金边缘沾着一点暗红，正从印缝里往内缩。那不是陆沉渊新咳出的灰，也未碰到莫井兰的陶片；它只在小印擦过残页旁的台面后出现。

苏晚在门外开口：“你先动印，灯后响。我们都看见了。”

仇慎抬眼：“你没进命审台。”

“我站在门口，能看见你的手，也能听见灯响。”苏晚语气平平，“我只认这两件事。”

他没有再驳。

陆沉渊右眼里的银灰火屑尚未散尽，眼前的人影时断时续。他用指节抵住台沿，刻意避开那两张纸。

“残页这处灰在旧印下面，门纸上的灰在新字下面。两处都避印，但一处灰向外翻，一处向里伏。”他缓慢吐出每一个字，“不能说它们同源。”

仇慎道：“还能说什么？”

“残页上的空缺被压过，也被揭过。门纸上的空缺没有。”

“谁压的？”

“不知道。”

“何时揭的？”

“不知道。”

“哪一户的页？”

陆沉渊闭了闭右眼：“我没看字，也不能认个人残页。”

仇慎将残页往自己这边抽了半寸，动作快得带起一阵纸风。纸角刮过那道冷金细痕，台后的顾家户灯又是一晃，灰白焰尖竟向残页偏去。

这一回，谁都没立刻出声。

仇慎的手停在半空。

他慢慢把残页推回原位，又把追缴纸移到另一侧。户灯焰尖没有跟过去，仍固执地偏向残页。顾婶咬紧牙，手背青筋根根绷起，却没有上前抢灯。莫井兰腾出一只手，指向焰尖。

“我认这一回。”她说，“残页往左，灯焰往左。追缴纸往右，灯没跟。”

“你只认动作。”仇慎道。

“我只认动作。”

仇慎将残页推回右侧。

灯焰迟了一息，才细针般转回。灯腹第二次发出脆响，比先前还轻，顾婶的肩头却猛地缩了一下。她盯着灯腹新添的白痕，嘴唇抿得毫无血色。

陆沉渊低声道：“别再移了。”

仇慎也看见了那道白痕。他立即按住残页边缘，没再动。冷金小印躺在一旁，印面失了原本的光泽，像覆着一层薄霜。

顾婶走近一步，目光仍不离户灯。

“这盏灯留在衙里，每回动你们的残页，它都要跟着失色？”

“今日只能记今日。”仇慎道。

“那就记。”

“记了也不归灯。”

顾婶嘴唇颤了一下，最终没有再往前。她望着那盏灰白的户灯，声音发紧：“我认两次移动，两次偏焰，两次灯腹响。别的，我不认。”

莫井兰接道：“我认小印先擦台，灯后失色；也认残页移，灯焰跟。陶片从头到尾没碰台，没碰印。”

仇慎把目光转向门外。

苏晚道：“我认你动印在前，灯响在后。残页上的字，我没看见。”

最后是陆沉渊。

他用袖口擦去唇边冷灰，没擦净，反在下巴拖出一道灰黑。他停了一息，才道：“我认灰的上下和翻伏。残页灰在旧印下，有压后揭开的痕；门纸灰在新字下，没有揭痕。灯怎么偏，不属于识账结论。”

仇慎的指腹在残页边缘压出白痕。他没有落印，只把冷金小印竖起，用失色的印面朝向众人。

“顾家折记不改。户灯不归。陶片仍由莫井兰暂带。今日所见，分句入本地附录。”

顾婶问：“那这张残页呢？”

“暂扣命审台，不并回原叠。”

“你知道是哪一页了？”

“只缩到这张。”仇慎看着陆沉渊，“页上缺的那一处，不再按普通破损记。其余没有结论。”

衙外忽有一阵冷风压来，门上的薄尘齐齐向内倒。仇慎下意识朝衙内更深处看了一眼，又立刻收回视线。他把残页压在命审台中央，掌根停得很稳。

“这张页若在本地再失序，呈印资格先问到我。”他顿了顿，视线转回陆沉渊，“若灰痕落不到该落处，问到你。”

陆沉渊掌心的暗红印线应声收紧。旧伤像被细丝勒开，血没有流出，皮下却浮起一圈冷光。他右眼一黑，膝盖撞上台沿。

苏晚从门外进来半步，抓住他没有落印的那只手。

“停术。”

“已经停了。”

“那就别再看。”

陆沉渊顺着她的力道退开。左眼仍死闭，右眼也只剩一线模糊。顾家户灯没有恢复颜色，灯腹新白痕贴着旧裂，细焰仍朝残页所在的位置偏着。顾婶守在灯旁，没有碰灯。莫井兰抱回陶片，也没有因几句入录便松手。

仇慎将四人的陈述逐句压在残页旁。冷金小印悬了许久，最后只落在附录边角。印落时，他手背浮起一道冷金细痕，台后户灯再暗一分。

他盯着那道痕，声音发沉。

“明日午后，仍在命籍衙。先复验这张异常残页，再验陆沉渊今日留下的在场认痕。顾家户灯继续留衙，莫井兰携陶片到场，顾婶只带今日所见。苏晚拒验续记，不得以巷中任何人的灯代验。”

门外的风停了。

苏晚扶着陆沉渊跨过门槛。她掌背旧布下的冷光没有消，陆沉渊掌心的印线也没有松。身后，仇慎把那张残页压回命审台正中，灯焰仍细细偏向它，像一根被冷气拽住、暂时折不断的针。
