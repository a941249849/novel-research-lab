命审台的双槽石案硬生生从泥灯巷冻结的青砖地底缓慢而不可阻挡地挤压而出。伴随着刺耳的、令人牙酸的岩石摩擦声，砖块成片崩裂，惨白的冰屑如同暗器般四下飞溅。这方粗糙的石台没有沾染哪怕一丝活人的气息，通体呈现出吸光死寂的暗灰色，带着长年深埋地底、被死气浸透的霉涩，以及陈年刑具特有的浓烈铁锈气味。石案的基座彻底卡死在地面，沉闷的撞击让整条巷子的青砖跟着震颤。随着石案立稳，实质化的压迫感化作刺骨寒风贴着地面横扫，泥灯巷周遭本就微弱的暖意被瞬间剥夺。墙角的霜花以肉眼可见的速度向外蔓延，将残存的泥土生机尽数冻结。

石案宽阔的案面上，两个深深的凹槽左右并列。左侧的凹槽宽阔而幽深，底部沉积着经年累月的暗红色旧痕，边缘石质被重压打磨得异常光滑，这正是专门承接“原债印”的位置。右侧凹槽则稍显狭长，边缘透出挥之不去的阴冷，卡槽深浅与“迁籍附条”的尺寸严丝合缝。在双槽石案最上方，镶嵌着一根半透明的石质刻度管。石案完全升起的瞬间，刻度管内最后一格暗色液体骤然沸腾。无数细小气泡在管壁内部疯狂炸裂，液体翻滚着化作带有生锈铁器气味的蒸汽，从顶端细孔喷涌而出。液面以恐怖的速度向下猛跌，走刻的节奏被强行拉快。刻度管壁上浮现出一行冰冷的暗纹警告：选错争点的一方，将在最后一格液体耗尽前失去所有再次申辩的机会。

苏晚直挺挺地站在石案正前方。她把不能用力的右手收进袖中，只用左臂托住命灯，使灯座与两道凹槽保持相同距离。石案要求债主本人选择，她便先核对左槽旧印的完整轮廓，再看右槽附条新浮出的灰边。每一次转动灯身，她都等案面显影稳定后才继续，既不让陆沉渊代持，也不让自己的伤势成为命籍衙中断受理的借口。

她极度僵硬地托举着命灯。灯盏本身未能从极限拉扯中幸免。抵御外部侵袭时的强行抽离，加上此刻石案散发的极寒，冷热交替的剧烈摧残突破了灯具材质极限。伴随着清脆却令人绝望的碎裂声，灯腹处猛地炸开一条全新的裂纹。这道裂纹像一条扭曲而狂暴的冰痕，从圆润的灯腹处突兀生出，以野蛮的姿态向上蜿蜒，毫不留情地撕裂原本勉强维持的完整，一路向上攀爬，直到直逼灯口位置才堪堪停住。命灯内本就微弱的火苗，因为这道新裂痕的出现，被外界灌入的寒风吹得剧烈摇晃。

陆沉渊站在她侧后方半步，只能凭左眼辨认案面公开显出的槽位。他已经承担异议认痕，不能再替债主触碰选择机关；于是他把双手压在身后，逐项报出两边证据能够支持到哪里。左槽通往原债根部，却缺少来源链；右槽只处理迁籍执行，却有附条后压的现场观察。说完这些，他便闭口，把最后的决定留给苏晚。

命审台没有丝毫讨价还价的余地：封档寿印的光芒和能量，在这座石案上只允许其中一个凹槽被点亮。审查范围在此刻被强制性收窄。苏晚只能在挑战原债的根本效力和挑战迁籍附条的执行方式之间，做出一个绝无可能撤回的单向选择。

左侧承接原债的凹槽散发着致命吸引力。若是能在这个凹槽里将其掀翻，就能彻底摆脱压在脊骨上的桎梏。然而，陆沉渊那只被银灰填满的右眼，无比清晰地感知到那条通往原债深处的证据链是彻底断裂的。旧债的核心深不可测，被层层迷雾、更古老的契约和更高权限的封锁完全掩盖。他明确承认当日辨痕已经断了，只能触摸令面公开位号，未继续追查灰线。确认在场认痕与残页下灰之间存在一线无法跨越的断口，不能据此认定其碰过残页、认定接触者的真实身份、断裂的具体时间或灰的最初来源。如果凭着孤勇贸然选择左槽，在关键证据完全缺失的瞬间，刻度管里沸腾的液体就会瞬间烧干，导致直接判定败诉。

相比之下，右侧的迁籍附条槽则实在得多。狭长槽口边缘隐约残留着在命审台挤压下贴合边缘浮出的、比原债印更新且带灼烧感的灰边。贫城旧匠把这种受热后外浮的痕迹称作“灼位灰”，它与现场观察共同指向后加覆印。挑战它，本地的证据链是闭合且完整的。但这个选择等于在程序上向规则妥协，默认本轮审查完全不涉及原债本身。苏晚旧寿债的债名、那枚如同附骨之疽的原始债印，都将在这一轮被确认为继续有效。他们无法借着附条的错漏，将那笔沉重的、不知起源的旧债一并抹除。

陆沉渊喉结在冰冷空气中艰难滑动，咽下翻涌的血腥气。他主动止步于三令同位、同尾灰与同一处压缺，不追索抄压先后、来源链或第四张令。他没有开口劝说，也未用眼神暗示。他撤回了所有代管要求，不再借用苏晚寿债作本案证明、交换或临时并入追缴。在此之前，他已以自身半寿登记痕为抵押，将柳木异议片提交并完成了身份拆分。此刻，他作为迁籍异议的唯一认痕责任人，已经锁定了局部事实陈述。他服从苏晚的选择，绝不在此刻生出多余的动作，亦不会把这属于后加覆印的焦灼痕迹，夸大为原债本就不存或旧债无效的空泛口实。他锁死在已知事实范围内，不替任何经手人洗清意图，也不替州府补写因果，只限定亲见事实。

苏晚没有回头，目光始终停在右侧较浅的凹槽。点亮它，意味着原债这座大山仍在；可去碰左槽，便是在没有证据的地方拿最后一次申辩下注。她让命灯向右平移，直到附条的灰边与槽口刻线完全重合，用这个动作给出了选择。

在身形因剧痛和极寒微微摇晃的瞬间，陆沉渊向前迈出半步。他没有越界抢夺灯匣，也未试图代她把证据推入槽口。母子代管与代债边界永久收紧，他严格限定在纸面与槽口范围后，平直伸出左臂，手肘稳稳悬停在苏晚身侧她刚好触手及、却绝对不会主动碰触的位置。这仅仅是一个纯粹的物理支撑。

苏晚的手臂在半空中停顿了微小的半秒。她手肘微沉，虚虚地靠在了陆沉渊冻得僵硬如铁的小臂上。借着这微弱却坚实的支撑，她稳住身形，收回了部分命灯直射，接受在已知事实范围内定案，毫不犹豫地将那份代表迁籍异议的凭证按入右侧凹槽。

苏晚做出了最终选择：只争迁籍附条。

石案内部传来令人牙酸的岩石摩擦轰鸣声。右侧迁籍槽骤然亮起刺目白光，带着毋庸置疑的裁决力量直冲上方。左侧原债槽在一阵沉闷的机括声中，被石案内部弹出的厚重黑色石板封住。命审程序永久锁定，本轮审查争点收窄为：迁籍附条的形成与执行效力。母债有效性被强行搁置，不发生任何隐性免债。

争点锁定后，石案没有给出胜负。右槽的白线沿附条边缘走完一周，左槽则被黑石板封住，连原债印的轮廓也一并遮去。苏晚知道这不是免债，只是把今夜能争的范围永久缩窄。她重新把命灯托回胸前，等待机关提出下一项检验。

身侧的陆沉渊依然如铁铸般立着，左臂平直，为她提供着毫无温度却异常沉稳的物理支撑。他的右眼蒙着死寂的银灰，任由那些暗青色的纹路在面颊上如蛇般游走。哪怕那剧痛已让他的呼吸变得缓慢而艰难，他也未发出一声闷哼。他只是以一种近乎自毁的姿态，将自己彻底钉在这个协助者的位置上，不再向命审台输出任何涉及原债的感知，将所有的反噬与惩罚默默承受下来。

刻度管中剩余的暗色液体仍在翻滚，虽然液面下降的速度因右槽的点亮而微微一滞，但那股带有铁锈味的蒸汽依然顽固地从细孔中喷出，在半空中散开，化作一片薄薄的、带有酸涩气味的雾气。这雾气笼罩在石案上方，让两人的视线都变得有些模糊。

然而命审的程序并未停歇。随着左侧原债槽被黑色石板彻底焊死，右侧迁籍槽的白光也逐渐由刺目转为内敛的乳白色。那光芒像一柄无形的刻刀，在狭长的槽口边缘反复摩挲，将那层残留的“灼位灰”后压痕迹逐步剥离、拓印。石案内部的齿轮咬合声越来越大，每一次震动都让石案表面的石粉索索抖落。

就在这令人窒息的等待中，原本平整的石案正中央，地面突然裂开一道细缝。伴随着又一次沉闷的机括撞击声，一块约莫巴掌大小、通体呈现出暗灰色、表面布满粗砺纹路的方形压印石，缓慢地从双槽之间升起。

这块压印石没有丝毫光泽，其上隐隐有两个下凹的印记轮廓，大小分别对应着原债的古老法印与那份迁籍附条上的新覆印记。

刻度管内最后一格暗色液体终于停止了沸腾，液面卡在最底端的刻度线上，散发着最后的、微弱的灰光。

方形压印石稳稳地停在石案正中，宣告着第一阶段的争点选择已彻底结束。它不提供任何宽免，亦不彰显任何结论，只是以一种冰冷而严苛的姿态矗立在两人面前。它所代表的程序律令清晰地悬浮在半空：原债印与附条必须在同一块压印石上重新受压，下一步，将直接进入复验两印的死局。更沉重的阴影与无可逃避的重压，在这一刻，自石案中央轰然扩散开来。
