# 《圣墟》深读剖析报告

- batch: 1
- evaluator: Agent
- verified_against_schema: yes

### 1. 主角初始处境
楚风，地球灵气大复苏后的普通青年，遭遇天地剧变被困荒野，依靠捡到的三颗古老神秘石罐种子踏上异变进化路。

### 2. 核心欲望
在异兽与域外降临者威胁下的地球求生 -> 踏入进化序列 -> 守护亲友 -> 扫平诸天高原黑祸。

### 3. 成长路径
觉醒、枷锁（挣断人身枷锁）、逍遥、观想、餐霞、金身、大圣、混元、映照诸天。副职为“场域研究师”（阵法解密）。

### 4. 爽点释放机制
“场域陷阱反杀域外圣子”。地球灵气复苏吸引星空万族大教弟子降临，主角利用地球山川场域布置绝阵，公开在网上直播售卖被俘的域外天骄。

### 5. 地图推进方式
大荒昆仑山（地球复苏） -> 星空母星（万族进化） -> 阳间大千世界 -> 诸天荒原诡异。

### 6. 资源竞争结构
核心资源为花粉异果、阳间进化呼吸法、神秘石罐。

### 7. 阶层压迫结构
星空大教视复苏的地球人类为低等土著；诡异高原视诸天文明为可以定期收割的祭祀庄稼。

### 8. 组织 / 阵营关系
昆仑异兽公社与地球反抗军，对立面是星空神殿、阳间世家、高原诡异始祖。

### 9. 世界观扩张方式
地球只是没落的圣墟 -> 阳间是真正的进化主位面 -> 整个世界其实是诡异族群定期收割的破碎药田。

### 10. 情绪主轴
废土进化、搞怪与后期黑暗降临的末日抗战悲壮。

### 11. 写作手法
前期大荒进化的怪兽动作与幽默直播非常轻快；后期完美整合遮天三部曲，宏大悲凉。

### 12. 叙事节奏
“发现神果 -> 场域暗中套利 -> 遭遇域外掠夺者公开围剿 -> 依靠场域绝阵坑杀 -> 地图迁移”。

### 13. 读者长期追更机制
三颗种子何时发芽、前两作主角何时归来相助、黑祸的终极秘密。

### 14. 二次传播生命力
“楚风大魔王”、“直播坑圣女”在读者中广为流传，终章跨万古的三部曲大主角重聚激起广泛情怀讨论。

### 15. 可蒸馏经验
1. 花粉进化/辐射进化的废土生存感；2. 直播售卖战利品的娱乐化爽感；3. 场域（阵法）作为空间套利工具。

### 16. 不应复刻内容
石罐这一法宝的具体罐体外观、花粉进化的名称命名。
