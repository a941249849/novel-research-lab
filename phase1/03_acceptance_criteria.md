# Phase 1 成果验收标准与玄幻主轴对齐规范 (Acceptance Criteria)

*   **当前阶段**：`Phase 1`
*   **版本**：`v1.0.0-acceptance`

本文件确立了 Phase 1 阶段结项的硬性验收指标与对齐规范，用以证明系统确实在往“玄幻叙事母机”方向靠拢，而不是退化为简单的术语替换器或科幻试水机。

---

## 1. 核心产出交付物指标 (Deliverables Check)

Phase 1 必须产出并完整归档以下文件，少一项则判定为未完成：
1.  **7 个骨架切片文件**：均存放于 `phase1/01_skeletons/`。
2.  **21 个单书 DNA 与 Ledger 描述 JSON 文件**：均存放于 `phase1/02_...`。
3.  **1 个跨书特征矩阵 JSON 文件**：存放于 `phase1/03_features/`。
4.  **1 个机制清单与至少 30 个分类归档文件**：存放于 `phase1/04_mechanism_library/`。

---

## 2. “中文玄幻叙事母机”主轴偏离度判定 (Xuanhuan Alignment Gate)

为确保系统不偏离中文玄幻的核心主轴，结项评审时必须对提取出的“机制库”进行以下审计：
*   **元素审计**：提炼的机制中，**超过 80%** 的条目必须属于典型的中文玄幻/仙侠/修真类型叙事动作。例如：
    *   *修为隐藏*（敛气、伪装灵根、神识障眼法）
    *   *夺宝反噬*（本命法宝受损、邪功血祭反弹、心魔入侵）
    *   *因果绑定*（天道誓言、因果业报折损寿元、气运抢夺）
    *   *逆袭机制*（退婚激将、宗门大比打脸、禁区死地奇遇）
*   **偏离判定**：如果提炼出的机制大量偏向现代异能、科幻机甲或西幻魔法（且无法合理解释为玄幻映射），则判定为“主轴偏离”，必须重新清洗语料提取。

---

## 3. “机制母机” vs “桥段改写器”判定 (Narrative Matrix Gate)

必须通过以下标准，证明系统沉淀的是“抽象叙事机制”，而不是简单的“桥段复刻”：
1.  **机制的纯粹性**：机制库中的每一个机制描述，**必须完全剥离原著的特定专有名词**。
    *   *错误示例*：定义一个“韩立小绿瓶催熟机制”。
    *   *正确示例*：定义一个“时间流速不对称之种植资源超速进化机制”。
2.  **高可复用度**：任何一个机制，其定义必须可以通过 Originality Transformer 映射到至少三个完全不同的世界观（如：传统修真、蒸汽朋克修仙、高魔东方玄幻）中，并产生合理的本土化因果归因。

---

## 4. 准入 Phase 2 原创长篇设计阶段的标准 (Next Phase Entry Standard)

只有在以下条件达成后，系统才可宣告结束 Phase 1，并正式交付 Phase 2 启动：
*   **协议零报错**：所有 JSON 提取资产的协议错误率为 0%。
*   **重合度预警未触发**：机制库中无任何一条机制与 7 本代表作的特定独占情节（Non-replicable elements）发生直接指代冲突。
*   **机制库完备度**：提取的机制不仅能完全表达 Phase 0B.5 Demo 中所测试的 4 大机制，还必须成功表达“宗门声望/因果关联”以及“神智/心魔变化”等高级玄幻动态。
*   **Owner 正式签署批准结论**。
