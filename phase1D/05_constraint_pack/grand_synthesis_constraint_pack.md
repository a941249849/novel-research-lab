## 2. Core Creative Doctrine (核心创作教条)
为了让长篇原创小说拥有生命力，Hermes 在生成概念时必须牢记以下六大战略教条：
1. **灵感先行，机制为燃料**：首先构思具有宏大宿命感、大时代气象的世界观与主角命运，然后再将具体的叙事机制（如信息差、状态机）作为引擎燃料填充进去，绝不能本末倒置。
2. **大世界先于小机制**：长篇的生命力取决于“这片天地的运转规则是否残酷、庞大”，而非“主角的金手指多么独特”。
3. **主角命运债务先于金手指**：主角变强不是因为贪婪，而是因为身负无法偿还的“命运债务”（如文明的遗忘、亲友灵魂在冥河流沙中的消逝、背负整个族群名字的重量）。
4. **社会压迫结构先于反派个人恩怨**：压迫感必须来自社会阶层法则、利益垄断或天道定期收割，杜绝弱智反派因私仇降智挑衅。
5. **情绪主轴先于爽点清单**：爽点仅是情绪释放的出口，必须先确立整本书的底层情绪主调（如凡人求生的清冷、大荒求索的苍茫、对抗宿命的悲壮）。
6. **原创性审查做结构级防抄，不做词级恐慌**：玄幻类型文学的公共母题（如仙朝、劫数、荒古、法宝）在脱敏后均可自由引用；原创红线集中警惕“特定人物命运因果链的完全克隆”。

## 3. Hard Constraints (硬性设计约束)
Hermes 脑暴原创项目时，必须在主角、成长、世界观、爽点中注入以下八大硬性规则：
1. **主角初始低位伤口**：主角开局必须处于物理或社会性的极度负债伤口状态（如气海破碎、被夺舍残存、家奴欠税），但禁止直接复刻原著退婚或灭门桥段。
2. **慢变量增殖外挂**：主角的外挂金手指不能是直接提供战斗力的爆杀武器，必须是一个需要持续投入时间、资粮才能产出隐秘复利的“慢变量增殖器”（如药草培育箱、时空流速不对称的沙盒、法则碎片熔炼炉）。
3. **境界突破代价与阶层绑定**：力量升级绝无天然无痛的晋升。每一次突破必须在 Narrative DNA 中绑定巨大的天地劫数、规则反噬或生存资源代偿；且主角必须掌握一门非直接战斗的专业副职（如账簿审计、图腾解析），作为其切入上流阶层的社会学杠杆。
4. **爽点释放的情绪蓄洪**：每一个高潮爽点释放前，必须经历至少 20 章的情绪压抑与危机潜伏（蓄水期）；反杀必须在公开场合发生，且必须伴随围观配角的震惊侧写，在 State Ledger 中引起社会声望指标的跳跃性结算。
5. **地图切换的秩序降维**：主角飞升/迁移至新地图后，此前积累的财富与社会名望必须强制清零；且高级地图必须对低级地图的底层法权进行“降维解构”（如发现原世界的漫天神佛仅是高阶修士圈养的幻术投影）。
6. **高阶压迫的世界合法性**：大势力的敌对与压迫必须基于宏观利益零和或天命规约收割（如仙界收割信仰、仙朝收割天道、测名院定期抹杀未成年名字）。
7. **温馨护短小共同体**：必须为主角建立一个富有人格温度、绝对护短的“温馨避风港”组织（如残疾长辈村、拙道拙峰、黑夜值班所），作为主角在冷酷丛林世界生存时的人性锚点。
8. **长期追更契约**：必须在第一卷大纲中植入让读者追更的长线悬念（如大劫临身的倒计时、主角隐藏身份被戳穿的持续暴露风险、复活故人所需的命运法典解封度）。

## 6. Anti-Mechanism-Assembly Rules (防机制拼装规则)
为了根治 Phase 2A 暴露的“机制拼装病”，Hermes 必须遵守以下四条防臃肿组装铁律：
1. **禁止先列机制，后拼世界**：不准在没有任何原创核心画面与情感主轴前，先从机制库中抓取 3-5 个机制 ID 强行塞入立项书。
2. **禁止机制的孤立组装**：外挂、副职、地图及阵营绝不能作为孤立的乐高组件拼接，它们必须在世界级压迫结构的缝隙里，在主角挣扎生存的宿命轨迹中自然生长出来。
3. **禁止无冲突的状态填表**：故事的发展不准以“填满 State Ledger 字段”为导向，状态账本仅是事后结算工具，不能反向指挥剧情创作。

## 7. Grand Synthesis Direction Requirements (高概念立项基本盘)
Hermes 生成的原创立项候选，必须包含以下六个大格局支柱：
1. **世界级压迫结构**：这个世界底层有怎样的利益黑洞与压迫法则？
2. **主角命运债务**：主角开局背负着怎样无法推卸的物理、精神或血脉债务？
3. **百万字成长系统**：主角的变强路径有什么清晰的阶梯与代价代偿机制？
4. **换图与扩张逻辑**：当主角打破当前秩序后，世界如何以认知降维的形式向更宏大版图扩张？
5. **二次传播符号系统**：设计一个高辨识度的原创核心物理符号与具有流行潜力的角色外号/名金句。
6. **原创红线自检说明**：详细说明本项目在结构级与词级如何规避了 Core7 原著的特定投影。
