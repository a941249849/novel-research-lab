# Creation Asset Registry v0.1 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Build a read-only Creation Asset Registry that makes Studio coverage gaps inspectable and validated without advancing content.

**Architecture:** Add a stable JSON registry artifact under `system/creation_assets/`, a focused Python assembler/validator module, a read-only `creation-assets` CLI command, and Studio drill-down rendering sourced through `studio-data`. Keep current Mission Controller state and Mission Registry as the runtime source of truth.

**Tech Stack:** Python 3 runtime CLI, `unittest`, Vite, React, TypeScript, Astryx, npm.

## Global Constraints

- No Phase 2F.
- No novel prose.
- No chapter plan content deliverable.
- No full character cards.
- No final NPC sheets, faction dossiers, technique trees, naming dictionaries, or item catalogs as creative content.
- No Hermes execution.
- No Antigravity execution.
- No raw `novel_training_set/` reads.
- `current_phase_state.json` and `mission_registry.json` remain source of truth.
- No asset family may be marked `complete` in v0.1.
- Studio remains read-only.

---

## File Structure

- Create `system/creation_assets/creation_asset_registry.v0.1.json`: system metadata for the nine asset families.
- Create `system/runtime/nrl_creation_assets.py`: loads, validates, summarizes, and returns registry data.
- Modify `system/runtime/nrl.py`: add `creation-assets` read-only command.
- Modify `system/runtime/nrl_studio_data.py`: include `creation_asset_registry` in Studio data and align Coverage Matrix from the registry.
- Modify `tests/test_sys3_runtime.py`: add CLI and Studio contract tests.
- Modify `apps/studio/src/types.ts`: add asset registry types.
- Modify `apps/studio/src/App.tsx`: render Creation Asset Registry drill-down under Coverage Matrix.
- Modify `system/runtime/README.md`: document `creation-assets`.
- Generated by build: `apps/studio/public/nrl-studio-data.json`, `system/runtime/studio/`.

    result = self.run_cli("creation-assets")
    self.assertEqual(result.returncode, 0, result.stderr)
    data = json.loads(result.stdout)
    self.assertEqual(data["registry_name"], "Creation Asset Registry")
    self.assertEqual(data["version"], "0.1")
    families = {item["asset_id"]: item for item in data["asset_families"]}
    self.assertEqual(
        set(families),
        {
            "characters",
            "npcs",
            "factions",
            "artifacts",
            "techniques",
            "naming",
            "emotional_bonds",
            "foreshadowing",
            "state_ledger",
        },
    )
    self.assertNotIn("complete", {item["status"] for item in families.values()})
    self.assertEqual(families["techniques"]["status"], "missing")
    self.assertEqual(families["naming"]["status"], "missing")

def test_creation_assets_summary_matches_status_counts(self):
    result = self.run_cli("creation-assets")
    self.assertEqual(result.returncode, 0, result.stderr)
    data = json.loads(result.stdout)
    status_counts = {}
    for item in data["asset_families"]:
        status_counts[item["status"]] = status_counts.get(item["status"], 0) + 1
    self.assertEqual(data["coverage_summary"]["total"], 9)
    self.assertEqual(data["coverage_summary"]["by_status"], status_counts)
    self.assertIn("No family is complete in v0.1", data["guardrails"])
