冷线从暖墙根下横切过去，把泥地分成截然不同的两层。靠墙一侧还存着旧灯熏出的暗黄，泥面软而湿，踩下去会缓慢回弹；三步之外却覆着青白霜壳，鞋底碾过，不见碎裂，只拖出尖细绵长的刮声。昨夜落上第一盏解封户灯座的刻度已经越过底沿，顺着灯绳垂到地上，又从两巷之间折回，笔直指向那块始终无人肯填的空处。

暖墙前没有围出完整的圈。柴凳横放在中间，两侧铺板错落相接，受助户自行摆下的灯位木牌有的贴墙，有的停在冷线外，还有三块仍被主人攥在手中。风钻过墙缝，豆大的灯焰被压得东倒西歪，照不清人的神色，只在冻裂的手指和木牌边角上反复一闪。

“交一户，暖区就能保住。”

话从铺板右侧响起。说话的人没有看那块空处，只盯着墙根尚未结霜的一条泥缝，仿佛只要目光不偏过去，便不算点了谁。

“先填个名而已。”他把手掌按在膝头，指节因用力透出青白，“不必动命火，也不必真把人拖出去。等复核下来，再把名撤掉。”

有人用鞋跟压住被风掀动的草角：“你见过填进去的名字自己退出来？”

“总比全挨冻强。”

这句话落下后，原本散乱的视线慢慢聚向最外侧的一户。那户的木牌搁在脚边，牌角沾着湿泥。持牌人察觉到众人的目光，弯腰把牌拾起，紧紧抱进怀里，没争辩，也没求谁，只带着自家灯向后退了半步。灯罩擦过衣襟，发出一声短促的轻碰。

陆沉渊站在柴凳外侧，寒气正沿右袖往上钻，十道冷金锁痕绷得像嵌进骨里的细索。他没有问是谁先提的，也没有去看最外侧那户。他握住柴凳一端，拖开半尺。凳脚犁过泥面，带起一道深沟，也把众人窥向那户的路截断了。

“谁留下，谁拒绝，谁撤回，都把自己的牌摆出来。”他说，“我不替两巷点人，泥灯巷也不替你们收灯。”

先前开口的人终于抬眼：“让大家各选各的，最后还不是一起冻？”

“那就先看清要失去什么。”陆沉渊将两块相叠的铺板分开，使暖墙前露出一条仅容一人通过的窄道，“空额不准拿一户去填，暖区也不准拿住户命火来换。除此之外，铺位、灶位、靠墙的时辰，你们自己减。谁减下去，今夜就照着执行。”

第一户从人群里出来，把木牌放在暖墙左端。牌面朝外，灯仍由自己提着。

“我不填那一户，也不交灯。原来夜里靠墙两轮，减成一轮。”

陆沉渊没有替他应声，只把柴凳又挪开一掌，留出下一块牌的位置。第二户随即蹲下，将自己的木牌放得更远些：“临时铺位撤掉。灶留着，只用后半夜。”

旁边立刻有人提醒：“铺位撤了便不能等风头过去再补。”

持牌人没有回话，先伸手摸过铺板。板面被几夜体温焐得发滑，木缝中压着发黑的旧草，边缘还有反复搬动留下的毛刺。他用指腹沿着板缝慢慢划过，最后抽出固定铺位的系绳，一圈圈缠到腕上。

“我知道。牌留下，见证也留下。谁趁我不在把灯记成公用，我当场撤回。”

“可以撤。”陆沉渊说。

第三户始终没走进窄道。那块牌被两只手轮流握着，灯光从指缝间漏出，照见手背上尚未消退的冻斑。有人催他们：“冷线已经压到灯绳了。你们总得让出一样。”

两只手一同把木牌翻过来，空白背面朝外。

“今天不答。铺位不撤，灯也不交。若因此少靠一轮暖墙，我们自己认。谁替我们写留下或退出，我们就把见证收回。”

四周顿时响起压低的争执。有人说他们占着位置却不肯承担，有人逼他们至少让出半轮灶位。陆沉渊弯腰把窄道边的碎木踢开，给那块没有摆下的牌留出原处，既不接，也不往前推。

“未答就是未答。不能拿沉默充名字。”

另两户听见这句，也把刚探出衣襟的木牌收回胸前。一户要等第一轮灶位排完再定，另一户只肯撤去见证，不肯退出暖墙照护。三块牌就这样留在主人手里，谁也没有替他们放下，像三道没有闭合的门缝，让冷风从人群中间穿了过去。

先前主张填名的人站起身，鞋尖抵住最外侧那户旧铺板的一角。他扫过那三块未摆下的牌，声音绷紧：“他们可以不答，答了的人就要替他们多熬一夜，这算什么共同承担？”

靠墙的一户把灯往怀里压稳：“你要觉得填名能救大家，先把自己的牌填进去。”

那人的嘴唇动了几下，掌心却始终扣在自家灯罩上。灯焰隔着指骨映出微红，烫得他缩了一下手。他最终收回鞋尖，转身抓住铺板边缘：“我也不填，灯更不交。东侧灶位让一轮，再拆一处铺位。”

铺板底沿冻进泥里，两个人抬不动。又有人把柴凳斜塞到板角下，几只手同时压住另一端，以凳沿为支点向上一撬。泥壳先发出沉闷的挤裂声，随后整块木板猛地翘起，湿冷气息从板底扑到众人脸上，混着潮木、旧草和积灰的苦味。

原先睡在板上的人下意识扶住板面，指尖刚碰到那层残余温意，便像被刺了一下似的缩回。他绕到另一侧，托住更沉的一端。铺板竖起后，底下露出两道人形浅坑，旧草被压得乌黑发亮，边缘正迅速爬上白霜。

“能不能先撤到天亮？”有人盯着那两道浅坑，“若复核缓下来，再搬回去。”

持牌人解下腕上系绳，绳子被汗与寒气浸得僵硬。他没有把它留在板边，而是塞进柴凳下的泥水，用鞋底踩进泥里。

“既然撤，就不靠一句‘也许’占着地方。木榫拆开，别留整铺。”

众人把铺板重新压平，冻僵的手沿接缝掰动木榫。湿木连续发出令人牙酸的吱响，终于从旧裂处崩开。断口露出潮白木芯，细碎木屑落在霜面上，很快被冷雾打湿。两段板分别移到暖墙两端，再不能拼成一处可供人躺卧的完整铺位。

排灶位比拆板更难。每让出一轮，就有人要在最冷的时辰守着失温的灶口。木牌在泥面上被推近、拨远，边角撞出断续的笃响，灯却始终跟着各自主人的手。有人把灯夹在膝间腾出手挪牌，仍用两臂牢牢圈住；有人原已答应换到后半夜，一听旁边提起“统一看火”，立刻把木牌拨回原处。

“只轮灶，不收命灯。”靠墙的人重重按住自己的牌。

“灶口熄了，临时借一点火也不行？”

“柴能轮，命火不动。”

“若住户自己愿意呢？”

陆沉渊的视线从一双双护灯的手上掠过：“真到调用的时候，再问一次。今日摆下木牌，不等于明日点头。”

右眼焦纹在他说完时骤然抽紧。泥地上的冷线顿时裂成数道重影，灯座下那圈刻度也化作模糊银白。他闭眼缓了片刻，没有再俯身辨认细痕，只用手背擦去眼角渗出的湿意。几粒银灰黏在皮肤上，被风一卷，滚入柴凳拖出的泥沟。

灶位逐轮排到暖墙末端时，一处临时铺位已经拆断，另一处仍完整贴在墙下。那一户迟迟没有动作，直到灯绳上的冷痕又往上爬过一指，才把自己的灯交给同住者抱住。灯只在自家两双手之间挪了一次，没有递向陆沉渊，也没有越过人群。

持牌人跪到铺板边，从板脚下逐根拔出木楔。木楔被湿泥咬得很紧，他双手握住一根左右摇动，掌心磨出血色，才听见泥里传来轻微的松脱声。

“我撤铺，不撤牌。暖墙若只剩一轮，我家自己排。灯不归巷里，也不归陆沉渊。以后谁拿今日的话说我们献过火，我便撤掉全部见证。”

一根木楔滚到泥灯巷众人脚边，有人弯腰接住，只把它放回柴凳旁，没有伸手碰同住者怀里的灯。几人合力抬起铺板，板底凝着完整的一层薄冰，冰面黏住泥地，被扯开时发出布帛撕裂般的声音。摇晃的灯影映在冰上，随着板身倾斜，一张张滑向冷线之外。

持牌人不许将板拆碎，也不许它继续留在可铺放的范围。铺板被抬到柴凳后竖起，拆下的木楔斜插进板缝和泥墙之间。众人轮流用掌根击打，直到木楔彻底别死，板面向外倾斜，再没有放平的余地。原本能供两户交替躺卧的地方，只剩一条侧身才能通过的窄隙。

失去铺位的人把木牌向暖墙推近半掌，又在牌角触及别人灯影前停住。他回头看了看仍旧握牌未答的三户，最后把牌拉回原位。没有人要求那三户补上撤去的铺位，也没有人把他们的沉默换算成更多灶时。第一户只认自己减下的一轮，第二户把让出的灶位往前挪了一格，第三户抱紧灯，脸色难看，却没有再提填名。

有人搬来柴凳，想横挡在空铺处阻住冷风。凳脚才触地，暖墙根下便响起清脆的一声，像薄瓦在暗处被指尖掰断。近处几人同时低头，看见护阵外沿原有的灰裂正从墙下探出，先擦过第一处空地，又折向第二处。裂口里没有火光，只有湿白霜粒一颗颗鼓起，沿裂缘挤落。

柴凳立即被抬走。新裂口失了遮挡，冷雾便从两处撤空的铺位下贴地涌出，绕着脚踝缓慢爬行。泥面在雾后生出密集冰刺，裤脚擦过便簌簌作响。靠外的人冻得连跺几脚，仍将灯藏进衣襟，没有交给任何人。

陆沉渊只在裂口旁蹲了一瞬。右眼里的重影已经无法让他辨清裂纹深处，他便不再强看。他按住柴凳起身，胸骨旧裂被牵得闷痛，右袖下的锁痕渗出一层冷汗，掌根也在凳面留下湿印。

“牌位不动。灶位结果，各自再认一遍。”他退到窄道外，“留下的自己认，只认今夜的也自己说；要拒绝、要撤回，现在就拿走。三户未答，空着，谁也不准补名。”

木牌沿暖墙依次被主人触过。有人按住牌面，认下减掉的一轮；有人只认今夜，天亮后仍要重问；有人将见证牌翻回空白，当场收进怀里。三户未答的木牌始终没有落地，他们保留着退出权，灯也没有被摆入任何公用队列。

轮到两处撤去的铺位时，原先使用它们的人亲手刮掉木牌上对应的位置。一处铺板已断成两截，一处被木楔别死在柴凳后，都无法再回到暖墙下。撤铺的人各自收回木牌，承担少去的避寒位置，却没有交出命火。墙前的空地因此更宽，也更冷；那块无人肯填的共同空额仍旧留在两巷之间，没有多出任何一户的名字。

最后一块铺板彻底离开泥面时，贴地冷线忽然向前滑动。细长的青白痕迹越过断木留下的碎屑，到了三处空着的住户灯位前，却没有攀上任何一盏户灯。它沿木牌之间刻意留下的间隙绕行，贴着新裂口钻入暖墙，随即分成三股，缠住泥灯巷三处共用灯龛。三处灯焰同时矮下一截，冷光沿龛沿收紧，第一道新刻度当着所有人的面咬进共用灯龛边缘。
