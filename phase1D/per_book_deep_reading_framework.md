# Per-Book Deep Reading Framework

本文件定义了 18 本书全训练集在 Phase 1D 深读期间必须执行的 **16 维深读剖析框架**。
所有单书深读报告必须结构化地填充这 16 个维度，严禁长篇大论，单书报告严格限制在 1000 字以内。

---

## 1. 16 维深读剖析框架 (The 16-Dimension Framework)

### ① 主角初始处境 (Protagonist Initial Condition)
*   **提取内容**：主角开局的底层身份、微观伤口（如经脉受阻、无名编号、欠税盐民）以及初始生存危机。
*   **分析重点**：如何建立最初的读者代入感和安全防线。

### ② 核心欲望 (Core Desires)
*   **提取内容**：主角在长篇中各阶段的核心求索目标（如活下去、退婚洗雪、复活故人、解封族群、掌握天道）。
*   **分析重点**：欲望如何随地图迁移而合理跃迁与升级。

### ③ 成长路径 (Growth Path)
*   **提取内容**：力量与境界升级的阶梯设定，境界名称及其反馈频率。
*   **分析重点**：副职（如炼丹、验声、读碑）如何作为成长的资源缓冲器与社交驱动器。

### ④ 爽点释放 (Satisfaction Release)
*   **提取内容**：核心打脸、反转、声望暴涨的剧情高潮点。
*   **分析重点**：爽点前的情绪蓄洪长度，反转瞬间的配角侧写及声望变动逻辑。

### ⑤ 地图推进 (Map Progression)
*   **提取内容**：世界地图层级（如小城 -> 门派 -> 仙界 -> 诸天）。
*   **分析重点**：地图迁移的切换引线和世界法权升级。

### ⑥ 资源竞争 (Resource Competition)
*   **提取内容**：修仙/成长过程中的不可再生零和资源（如异火、名额、时间时长、灵药）。
*   **分析重点**：秘境或竞渡等关卡设计如何加剧配角淘汰。

### ⑦ 阶层压迫 (Strata Oppression)
*   **提取内容**：世界观中垄断上升通道的特权阶级（大仙朝、古族、测名院）。
*   **分析重点**：压迫感的外显方式（如境界威压、降级惩罚、剥夺资源）。

### ⑧ 组织/阵营 (Organization/Faction)
*   **提取内容**：主角所在的温情师门/避风港，以及冷酷的财阀/教派利益链。
*   **分析重点**：阵营对立背后的核心逻辑（非简单善恶，而是生存法权碰撞）。

### ⑨ 世界观扩张 (World-View Expansion)
*   **提取内容**：随着故事深入，认知盲区的层层剥离（如发现修仙世界的终极真相、仙界是收割农场）。
*   **分析重点**：认知套娃的悬念设置与揭秘节点。

### ⑩ 情绪主轴 (Emotional Main Axis)
*   **提取内容**：贯穿全书的底层情绪基调（凡人的谨慎、求魔的悲壮、诡秘的诡异与日常并置）。
*   **分析重点**：如何通过特定桥段强化该核心情绪。

### ⑪ 写作手法 (Writing Techniques)
*   **提取内容**：作者标志性的文字表达、悬念设置、群像塑造和草蛇灰线手法。
*   **分析重点**：如何用最简洁的场景勾勒庞大气象。

### ⑫ 叙事节奏 (Narrative Tempo)
*   **提取内容**：日常积累期、危机潜伏期、高潮爆发期、休整过渡期的黄金周转循环。
*   **分析重点**：单章留白与阶段性大纲收束节奏。

### ⑬ 读者长期追更机制 (Long-Term Retention Mechanics)
*   **提取内容**：支撑读者在连载期间日更追看的悬念和长期承诺（如三年之约、复活白师姐的倒计时）。
*   **分析重点**：核心危机与短期成长目标的嵌套。

### ⑭ 二次传播生命力 (Secondary Vitality)
*   **提取内容**：网络流行梗、名场面金句（“我命由我不由天”）、考据热点（扮演法序列解析）。
*   **分析重点**：世界设定如何为读者留下解密和同人二次创作者空间。

### ⑮ 可蒸馏经验 (Distillable Lessons)
*   **提取内容**：剔除原著外壳后，可以直接被叙事母机吸收的 3 个最核心逻辑骨架。

### ⑯ 不应复刻内容 (Non-Replicable Elements)
*   **提取内容**：原著独占的标志性符号、因果组合与人名道具，列为原创红线。

## 2. 框架执行标准格式 (Markdown Output Template)

单书深读报告统一使用以下格式：
```markdown
# [书名] 深读剖析报告

- batch: [批次编号]
- evaluator: Agent
- verified_against_schema: yes

### [16个维度按顺序输出]
1. 主角初始处境：...
2. 核心欲望：...
...
15. 可蒸馏经验：...
16. 不应复刻内容：...
```
