# Phase 2A Tool Roles

## Codex

Codex owns:

- filesystem structure
- validation scripts
- asset indexes
- JSON load checks
- report generation
- Google Drive synchronization
- deterministic package preparation

Codex must not:

- write original prose
- call Hermes without Owner authorization
- treat stub books as promoted assets
- modify Phase 1 formal assets during planning

## Antigravity

Antigravity owns:

- Phase 2A planning review
- originality direction review
- mechanism combination review
- review of whether Phase 2A plans remain aligned with Phase 1 accepted assets

Antigravity should reject:

- source-plot imitation
- mechanism-name reuse from original works
- direct prose generation before approval
- skipped originality review

## Hermes

Hermes may be used later only under controlled prompts.

Hermes may produce:

- original setting candidates
- abstract mechanism combination candidates
- structured design candidates

Hermes must not:

- directly write chapters
- freely expand without an approved prompt
- imitate source novels
- read forbidden input files

## Owner / ChatGPT

Owner / ChatGPT owns:

- direction decisions
- scope approval
- phase transition approval
- final acceptance or rejection of planning outputs

No phase may proceed from planning into creative production without explicit Owner approval.
