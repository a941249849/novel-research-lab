# 《永生》深读剖析报告

- batch: 1
- evaluator: Agent
- verified_against_schema: yes

### 1. 主角初始处境
方寒，羽化门龙渊省第一世家方家的卑微家奴，命贱如蝼蚁面临皮鞭打死危险，偶获白海禅临终遗赠的九窍金丹与黄泉图。

### 2. 核心欲望
摆脱奴仆身份踏入修行 -> 成为羽化真传 -> 夺取天地一切大道法则 -> 轰开纪元之门证道仙王，掌控命运。

### 3. 成长路径
肉身十重、神通十重、长生十重、仙人、至仙、天仙、仙王、无上破碎。

### 4. 爽点释放机制
“极其野蛮疯狂的掠夺与吞噬”。外号“方老魔”，顺我者昌逆我者吃。爽点在于他在门派天刑台上，当着门派所有长老和真传，以最霸道的姿态轰杀真传大能，强行融炼对方的法则修为作为升级资粮。

### 5. 地图推进方式
方家 -> 羽化门 -> 大玄帝国 -> 仙界（神界争霸） -> 纪元之门（终局）。

### 6. 资源竞争结构
核心资源为三千大道神通法则（如大宿命术、大灾难术）、纯阳丹（硬通货币）、黄泉图。

### 7. 阶层压迫结构
修仙世界赤裸裸的弱肉强食阶层，仙道大派将世俗王朝当做圈养的韭菜。

### 8. 组织 / 阵营关系
全靠实力说话无情利益博弈，唯一的助力是黄泉图器灵“阎”与大宿命术。

### 9. 世界观扩张方式
世俗界只是韭菜地 -> 仙道十门只是仙界在下界的放牧代理 -> 仙界只是一场纪元毁灭潮下残破的避难所。

### 10. 情绪主轴
霸道、唯我独尊、肆无忌惮地掠夺诸天。

### 11. 写作手法
“吃人流/掠夺流”巅峰写法，剧情极其利落；将纯阳丹作为硬通货写得极其写实，构筑了完美的金融资源消耗体系。

### 12. 叙事节奏
“缺少资源/纯阳丹 -> 去古迹遗迹大肆杀人夺宝 -> 回归天刑台越级轰杀异己 -> 掠夺金丹法则升级”。

### 13. 读者长期追更机制
方寒的大宿命术进度、黄泉图何时修复、纪元之门何时轰开。

### 14. 二次传播生命力
“方老魔”作为冷酷、霸道、毫不手软的主角形象，经常在网络讨论中作为无脑圣母主角的对立反面教材而广泛引用。

### 15. 可蒸馏经验
1. “修仙货币纯阳化”的硬核资源消耗博弈；2. 顶级掠夺反哺（吞噬敌方金丹法力）的爽利节奏；3. 大道法则作为规则特性的收集链。

### 16. 不应复刻内容
黄泉图内蛟龙“阎”这一具体器灵外观、大宿命术等具体名字。
