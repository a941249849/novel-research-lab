泥灯巷深深的青砖通道里，那条凹陷在石板底部的回执槽此时正呈现出一种异样的静止。粗糙的槽缘包覆着一层泛黄的黄铜薄片，这些黄铜在长年的水汽与摩擦下已经有些发绿，带着斑驳的锈点，与冰冷的青石嵌合在一起。齿轮的咬合齿尖正好卡在半个旋回的缝隙中，既没有向下吞没，也未向上吐出。金属与青石接触的缝隙里，几点暗沉的油垢混杂着极细的石粉，在寒风中凝固成干涸的黑色颗粒。槽底深处隐隐有细微的符文光晕在闪烁，却像被某种无形的力量按住，只能在铁青色的机械缝隙中发出微弱而断续的挣扎。这里的空气是冰冷的，带着一种陈旧纸张与生铁长期摩擦后的苦涩气味，连同周围泛起的淡淡雾气，都被吸附在回执槽周围的青石表面，结成了一层薄薄的、带有灰尘质感的冰壳。这台半埋在泥灯巷底部的账籍执行机器，其局部的算筹与铁片在这一刻完全失去了往日的尖锐鸣响，只是冷冰冰地维持着这处于停滞边缘的暂停状态。那些泛着锈斑的铁齿，就如同一张在严寒中被冻僵的兽口，突兀地横在窄小的道路中央，将原本流畅的账籍流转程序拦腰斩断。

异议悬置后，查看槽两侧的挡板同时落下，把隔槽相对的母子分别逼向两条出口。苏晚只能从债主侧的院落内门退回泥灯巷，陆沉渊则被认痕侧的窄道送到石墙外。两人各自绕过封闭的查看墙，赶往回执槽在巷内共同开放的登记端。

嘎吱一声沉重的闷响，侧面院落那扇包了铁角的内门被人从里面缓缓推开。苏晚的身影从那道狭窄的门缝中挪了出来。她走得很慢，双脚在覆盖了碎冰的砖面上发出生硬的摩擦声。她的双手紧紧环抱着那个黑漆剥落的黑木灯匣。那只灯匣的边角已经磨损得圆滑，却因为她掌心不断渗出的冷光而泛着一种半透明的死灰色。每一次呼吸，她胸口都剧烈地起伏一下，连带着怀里的灯匣也跟着发出轻微的木料挤压声。她没有回头看那扇渐渐合拢的内门，只是将所有的注意力都集中在脚下冰冻的路面上，每迈出一步都显得异常艰难而迟重。

在街道的另一侧，陆沉渊正绕过那堵高耸且湿漉漉的黑色石墙。墙面上剥落的泥灰在冰冻后像干燥的鱼鳞般挂在半空，他每迈出一步，粗糙的衣角便会拂过那些尖锐的石砾，发出生硬的沙沙声。他的脚步略显沉重，身体在严寒中有些僵硬，但他没有停顿，而是紧紧顺着墙根的阴影，迅速且安静地移动着。黑布鞋底在湿滑的冰面上踩出清晰的印记，随后又被狂风卷起的雪屑与煤灰迅速掩埋，不留一丝痕迹。

两人在泥灯巷门内的一侧碰面了。这里的空间逼仄，两侧的砖墙因为年深日久而微微向内倾斜，将上方阴沉的灰色天空压缩得只剩下一道窄窄的缝隙。刺骨的寒风在破旧的巷口来回打着旋，吹得苏晚的额发散乱地贴在苍白的脸上。陆沉渊在她身侧站定，用自己单薄的肩膀正好挡住了从外门灌进来的部分冷风。他们就站在回执槽的同侧，相距不过一尺，彼此甚至能听到对方胸腔里那粗重而艰难的喘息声。在这个狭小的空间里，两人的影子在昏暗的光线中交叠在一起，仿佛在狂风中瑟瑟发抖的单薄枯叶，紧紧依偎着那堵冰冷冰封的石墙。

陆沉渊的视线从苏晚的脸上缓缓下移，落在了那只布满裂纹的木质灯匣上。木匣缝隙里漏出的冷光像是一根根无形的冰针，正顺着苏晚的手臂向外散发着实质般的寒气。他缓缓抬起右手，五指微微张开，掌心带着仅存的温热，试图去握住灯匣的下沿，将其从苏晚的怀中接管过来。他的意图很明显，这盏承载着沉重旧债的命灯，如果任由苏晚一个人抱持，那股持续的损耗迟早会把她彻底抽干，他想用自己的身体去代管这笔债务的物理载体，用自己的命格去分担那股冰冷的压力。

然而，还没等他的指尖触及到木匣边缘的那层霜冻，苏晚的肩膀便猛地耸动了一下。伴随着关节处一声生硬而短促的骨节咬合声，她以一种近乎粗暴的姿态，将灯匣向自己的怀里收回了三寸。那坚硬的木匣边角重重地顶在她的肋骨上，她却连眉头都没皱一下，只是将五指收得更紧，指尖几乎要扣进木料的纹理中。她那双布满血丝的眼睛盯着陆沉渊，眼中没有泪水，只有一种冷酷而顽固的拒绝。她没有开口说话，但那僵硬的姿态和紧绷的下颌线已经将她的态度表达得极尽决绝：这是她的寿债，是她自己的因果，她绝不允许自己的儿子将手伸进这个泥潭里。她不要他的代管，更不要他的代偿。

这猛烈的动作抽干了她身体里仅存的力气，她的膝盖猛地一软，整个人顺着冰冷的墙壁就要滑倒下去。陆沉渊没有再去尝试触碰那个被她视若性命的木匣，而是迅速将手掌向下移动，穿过她棉袄的缝隙，牢牢地托住了她的左肘。他的手指陷在厚重的棉絮里，用一种温和却极具韧性的力道，将她的身体向上托举。苏晚的手臂剧烈地颤抖了一下，但她最终没有推开这股力道。她任由陆沉渊的手扶着她的关节，将她的大半个身躯靠在他的肩膀上。那是一种纯粹的、物理上的支撑。灯匣依然被她抱在胸前，与陆沉渊的身体保持着那生硬的三寸距离。母子二人在这一刻达成了一种近乎残酷的默契：她接受他作为儿子的肉体扶持，但绝不交出债务的任何一丝主控权。

陆沉渊用肩膀顶住母亲的身体，左手则摸索着伸入了自己的怀中。指尖在衣襟内侧的暗袋里触碰到了一块粗糙的木片。他将木片抽了出来，那是一块只经过简单劈砍的柳木，表面还残留着青绿色的树皮，木肉处呈现出新鲜的、带有一丝湿气的淡白色，散发着一股独属于雨后新柳的苦涩味道。这是他身上仅存的一块空白异议板，也是他最后的凭证。

他深吸了一口气，将柳木片平放在自己的膝盖上。他没有使用任何钢刀，而是直接用自己右手大拇指那粗糙的指甲，抵住木片的纤维，开始一笔一画地在上面雕刻。木质很硬，每划下一笔，指甲缝里都会传来一阵酸痛，但他没有停手，甚至没有抬头，只是任由那冰冷的痛感在指端蔓延。他克制住自己想要长篇大论的冲动。他没有在上面写下任何关于迁籍背后主使者编造的谎言，没有去写那些官吏是如何在半夜修改了底册，也未去推断这笔债被转移的具体路径。他强迫自己只留在已验证的本地观察中，仅仅记录下他眼前所见的局部事实：
“原债印先成，迁籍附条后压。”
十二个字，刻得极深，柳木的汁液顺着刻痕的边缘渗出来，带着一种青绿色的黏稠质感。每一个字都像是用铁犁在干涸的土地上翻耕出来的沟壑。刻完最后一个字，他没有丝毫犹豫，将自己右手的大拇指重重地按在了这行字迹的下方。他的大拇指上，那道代表着他自身残缺生命周期的半寿印记，在此刻因为用力的按压而亮起了一抹暗红色的微光。红光沿着柳木的纹理迅速延展，将那十二个字深深地染成了一种如血般的暗沉颜色。
这不再是一份普通的书面陈述，而是一份以他自己的命格为质押的具名异议。

他转过身，将这片唯一的柳木片推入那道半张的回执槽。木片在进入槽口的一瞬间，底部的黄铜齿轮发出一声沉闷的“咔嚓”声，随即将木片拖入了黑暗的机械深处。
几乎在木片脱手的刹那，陆沉渊便感觉到手腕处传来一阵剧烈的刺痛。一条呈现出淡青灰色的追踪印记，如同活物般从木片消失的地方延伸出来，缠绕在他的手肘上。这道追踪印记在皮肉下发出细微的脉动，将他的气息、命格以及一举一动，都与命籍衙的底层追踪机制强行绑定在一起。从这一刻起，他成为异议程序唯一的认痕责任人，独自走入那片无处不在的监视阴影。苏晚仍是旧债主体，仍要独自承受命灯与追缴后果，只是不再替儿子承担这份异议留下的追踪。

随着柳木异议片的没入，回执槽内部的轰鸣声突然变得高亢起来。那种声音听起来像是无数片生铁在相互摩擦，又像是沉重的算盘被人在地上疯狂地拖曳。
程序正在以前所未有的速度运转，在冰冷的算力中，这两个截然不同的凭证被摆在了同一个天平的两端。
一方是苏晚，她持有那盏残存的命灯，那是债务的本体，代表着这笔旧债的债权依然依附在她的命格上；另一方是陆沉渊，他用自己残缺的半寿印记，对那张试图将债务迁走的附条提出了正式异议。
两者的诉求在程序的逻辑链条中发生了剧烈的撕扯。本地的账簿机制无法将这两者强行揉合在一起，因为它无法在不触动半寿印的前提下，去判定旧债的主权归属。
窄巷里的空气变得更加滞涩，那些飘散在半空中的碎冰屑仿佛被某种无形的力量定格住了。最终，在回执槽深处传来的一声犹如闷雷般的铁件撞击声中，程序的逻辑判定做出了最冷酷的分流：
债务主体与异议主体，被彻底拆分。
在这个系统里，苏晚的名字与她的命灯木匣被牢牢地锁在债务主体的档案架上，代表着那笔原始的债务依然由她独自承担，没有发生任何转移；而陆沉渊，则被单独剥离出来，成为了迁籍附条异议的唯一主体。他的名字被用代表着追踪的红墨，写在了异议书的首页。两者的法律责任与程序角色，在此刻被物理上、绝对地割裂开来，再也并无混同的余地。

回执槽上方的铜制活门在剧烈的震动中微微开启了一道缝隙，从里面吐出一阵微弱的、带着炭火余温的灰色粉尘。这粉尘落在两人脚边的冰霜上，发出一声细微的、冰雪消融的叹息。
紧接着，一个尖锐而沙哑的机械声音，顺着那道铜质活门的缝隙，在这条被冰雪覆盖的巷子里回荡开来。那声音里并无人类的情感，只有冷冰冰的齿轮摩擦感，在两旁的砖墙之间不断地激起刺耳的回声。
“债务主体与异议主体已拆分完毕。”
“争点锁定。”
声音稍作停顿，随后，最严酷的宣告随之而来：
“下一步程序，只在原债与迁籍两个争点中择一而动。”
“警告：选定原债，则默认迁籍附条合法，只辩债务本金之虚实；选定迁籍，则默认原债无误，只辩户档转移之真伪。两端争点，不可并存。走刻既始，只容一次择定，无有复核之期，亦无撤回之途。”
“在最后一刻度耗尽前，若无确定之争点，则两端皆行判定，旧债即刻执行。”

随着那沙哑的声音落下，回执槽旁边的青石板上，一个一直暗淡的琉璃刻度管里，那一格深红色的油状液体突然开始以一种肉眼可见的速度向下滴落。那黏稠的液体每落下一滴，都会在琉璃管底部激起一点小小的气泡，发出细微的“啵啵”声。
走刻正式开始了。
寒风依旧呼啸着穿过泥灯巷的豁口，带走他们身上所剩无几的温度。苏晚抱着木匣，身子倚在陆沉渊的肩头，指尖的冷光微弱却顽固地闪烁着。陆沉渊的右手腕上，那道青灰色的追踪印记在皮肤下剧烈地跳动着，传来阵阵如针刺般的痛楚。
他们站在这条寂静而死板的巷子里，看着那道已经彻底合拢、如同一道伤疤般横在石板路中央的回执槽。两个争点如同两条黑漆漆的分岔路，在他们面前缓缓铺开，而他们被钉在了这倒计时的起点上，再无退路。
