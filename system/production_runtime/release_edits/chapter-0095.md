裂灯伏在苏晚脚边，灯腹那道深灰裂口被霜气压得发白，豆大的火缩在灯芯里，一跳一跳，照不暖脚边的砖缝。

泥灯巷的潮气早已陈旧，冷意自巷口逼进来，把墙根和青砖都冻出一层薄脆的白。砖缝里原先塞着黑泥、枯苔和碎瓦，此刻尽数凝成硬块。巷口外那道旧缝本该只隔开街风，今日却有湿白从缝里漫进来，像浸透的纸被人按在泥墙上。

白意沿墙根析出，悬在离地三寸处，一笔一笔自行结成。

“命籍衙提验。”

“疑接转运命火。”

“限期交验。”

最后四字落定，裂灯里的火猛地收缩，只剩贴着灯芯的一点蓝绿。苏晚掌背上原有的暗色被冰水似的寒意浸开，沿腕骨漫出一线青灰。她没有去捂，只把脚尖向前挪了半寸，挡住裂灯朝巷口歪去的方向。

旧墙阴影里，陆沉渊的投影静静悬着。

那只是从数里外州府石台映来的淡薄轮廓，半透明的衣角偶尔没入墙面凸出的土坯，不沾尘，也不带风。他的真身仍被留在石台上，无法离开术式圈定之处。投影能看见巷内景象，也能将声音送进来，却触不到砖石、纸页、灯盏，更不能越过旧缝替任何人落印。

第二层字随即浮起，比先前更粗，更冷。

“疑接者苏晚，分期核验改为强制提验。”

泥灯巷一下静了。

几扇木门后的细碎脚步骤然消失。屋檐落下一滴水，砸在石地上，水珠还没散开，便结成浅白霜痕。有人把门闩按得极紧，木头发出一声被捂住的闷响。

苏晚望着“疑接者”三个字，许久没有动。

她从衣襟里取出一张分期旧页。纸边早已磨损卷翘，纸面焦黄，字迹被汗水和寒气反复浸过，摸上去坚硬粗糙。她将旧页摊在脚边，用一块碎砖压住，才抬头望向巷口。

“把接收落处写出来。”

冷字悬在半空，没有回应。

“这是我的旧债，也是我自己按过的分期。”苏晚指向旧页上那列模糊小字，“上面哪一笔写了我接过转运命火？账目要清，规矩要明。你们若要验这一笔，总得把来路写在账上。”

仿佛受她这句话牵引，提验文书自最上方展开。原先隐在白意里的细格一栏接一栏显露，先是“送出”，其后跟着一枚残缺衙印；再是“接收人”，格内没有姓名，只有一道未能闭合的墨框。墨框中央空空荡荡，既无指印，也无代押标记。

下一栏写着“交接时刻”。年月只显出一段模糊残笔，日、时、刻三格全无记录。文书试图将那段残笔向后拖长，笔锋才越过格线便自行断开，留下三个大小不一的空处。

再下一栏是“在场见证”。本应并列容纳两名见证人的位置只浮出两个浅框，框下的籍贯、差役编号与复核署名也一概空白。没有谁证明命火曾被送到泥灯巷，没有谁说明苏晚当时在场，更没有谁写下她以何种方式接收。

最末才是“接收落处”。州、坊、巷三层位置均未填实，只有“贫城外层”四个泛白的字悬在格外，既没压进栏内，也没有对应门牌。那不是落处，只是一片足够宽泛、足以把许多人一并圈入的范围。

苏晚逐栏看完，语气没有抬高：“接收人缺名，时刻缺日时，见证两空，落处没有入格。我的旧债只有原额、分期和每期核验。我认这三样，也只认这三样。旧债该还到哪一期，我照旧页上的边界还；边界以外的接收，不在我的分期里。”

霜意从巷口往里挤了一寸，墙皮簌簌落下泥沙。

“疑接，待验。”

“待验就待验。”苏晚说，“谁把命火交到我名下，什么时候交的，由谁看见，最后落在哪里，都该写清。没有具名落处，不要拿这两个字压我的名字。账上没有的东西，谁也不能凭空塞进来。”

文书在“接收人”空格旁添出一枚细小的待补印，又依次扫过时刻、见证和落处。每到一栏，那枚印都会停住，却始终找不到可以依附的字迹。四处空白彼此相连，将“疑接者苏晚”隔在另一侧，像一条尚未架成的桥。

苏晚没有替它补一个字。

“我能陈述的只有旧债。”她道，“债从何年起，分作几期，哪一期已经验过，哪一期尚未到期，都在旧页上。除此之外，你们问送出人，我不知道；问交接时刻，我没有；问见证，我不能代写；问落处，也不能用我站着的地方倒推成接收之地。”

悬着的字微微一颤，细白粉末从笔画边缘落下。

灯腹裂口旁又绽开一道发丝细纹，缓慢爬到灯肩。苏晚没有再去挪动它，只将那张旧页留在原处，呼吸压得极浅，却没有退开。

陆沉渊的投影微微低下头，虚影中的手停在空中，终究没有伸向任何实物。

“别替我答。”苏晚没有回头。

这一句不只对他，也是对巷里所有紧闭的门、门缝后压低的呼吸，以及巷口那些冷硬的字。

陆沉渊的声音从州府石台传来，经过数里术路，落入巷中时已显得淡薄：“她已经答了。她只陈述旧债与分期边界。文书上仍空着接收人、交接时刻、见证和落处，我在此只能看见，不能替任何一栏作证。”

他说完便止住，没有猜测提交方，也没有为苏晚解释那笔旧债的来由。投影仍在旧缝之内，与地上的文书相隔数步，连压住旧页的碎砖都无法挪动半分。

冷字没有理会。

“提验”二字下方忽然拖出一道细长横划，贴着地面扫向两侧门槛。扫到第一家门前时，白色笔锋伏在石阶上，安静等待里面开门，或者等一个名字被交出来。

整条巷子没有人动。

苏晚看见那道横划，脸色更白。她没有回头辨认是哪一家，只把旧页往脚边拉近一点。

“我的名字在这里。”她说，“巷子不在这里。你们找的是我，别把门后的人填进空栏。”

冷字停顿片刻，重新组合。

“疑接，可连问同处者。”

“问可以。”苏晚平平抬手，“谁愿意答，谁自己答。谁不答，也该由他自己不答。你们不能拿没说过的话，替人写成接收。命籍衙也不能替人落这种账。”

墙根的白痕猛地向上蹿了数寸。巷里几盏门灯齐齐晃动，火苗被压成细长黄线。门后传来一声急促吸气，又被粗糙布料死死捂住。

陆沉渊望着盘在门槛前的细线，投影没有越过旧缝。

他能辨出文书的外层格式：送出一栏留痕，接收四项俱缺。缺失原该逐项回查，可眼前的提验却越过空格，先将苏晚列作疑接者，再把同处者纳入连问。陆沉渊只能把自己看见的次序说出来，不能替命籍衙改字，也不能替任何一户作出回应。

闻照微被共持锁在州府石台的外层投影没有移动；泥灯巷线外显出的，只是同一道投影经旧缝回传的远端映像，既不能踏进巷内，也不能从石台撤回。

她腕上的共持锁纹淡得几乎看不见，只在白光闪烁时泛出一点冷亮。她看着苏晚，又看向悬空的文书，沉默片刻才开口。

“提验文书里确实没有具名接收。此前的复验记录留过档，不能随意更改。”

冷字转过一笔，落在她脚边。

“待补，可先验人。”

闻照微没有代苏晚争辩旧债，只按监验所能核看的栏次逐项念道：“接收人未具名，也无代收身份；交接时刻缺日、时、刻，无法与此前分期核验相互勾连；见证栏无人署押，外层复核也没有补入差役记录；接收落处只写贫城外层，没有坊、巷、门籍。”

每念完一项，对应空格便显得更深。待补印来回游移，仍没有落下。

“这四项缺失，都应保留原状。”闻照微道，“监验可以核对文书是否齐备，可以注明空缺，可以将不一致之处送回复核。但监验权限不能代替命籍衙撤回提验，也不能把申请改作撤销。”

“申请未撤。”

“我知道。”闻照微道，“我没有权力替她撤回，也不会宣告这份文书已经失效。可程序未完之前，不能把未具名的接收写成既成落处，更不能因为她人在这里，就把此地倒填进原始交接。”

她停了一下，目光落在分期旧页上。

“旧页能证明的，只是她所说的分期边界。它不能证明转运命火由谁送出，也不能证明由谁接收。缺失的部分仍须向原始提交处追索，不能由监验补写。”

巷子里的静默被这句话绷得更紧。

苏晚抬眼看她，神情平静得近乎冷淡。

“那空缺处写谁？”

“现在谁也不能写。”闻照微答道，“接收人须有具名依据，时刻须能核对交接记录，见证须本人署认，落处须对应原始门籍。在这些东西送到以前，空栏就是空栏。”

她望向陆沉渊投影所在的旧缝，目光停留不过一瞬，便移开。

“若命火确从某处送出，就回提交方查送出名册与经手记录。账目该归谁清，由谁清。”

数里外，陆沉渊看见文书上的待补印朝旧缝偏转了一瞬。他没有承认那一行，也没有替任何人接下未写明的责任，只从术式另一端说道：“我能转述此刻所见：四栏未补，苏晚未认接收，监验也未撤申请。除此之外，我无权替命籍衙作结论。”

巷口的冷字似乎找到了新的去处。

原先压在苏晚名字上的白线移开，顺着地面游向两侧门槛。第二扇、第三扇门前也浮出浅白。它不钻进屋内，只贴着石缝爬行，将被鞋底磨亮的泥土顶开，露出底下黑硬的冻土。

第一扇门里，一只冻得发青的手从门缝悄悄探出。指尖刚碰到石阶，便猛地缩回。里面传来孩子翻身的动静，随即被一声极轻的“别出声”压住。

苏晚的呼吸停了停。

她没有叫出任何人的名字，也没有去看那扇门。她只是将手朝外，平平举在自己身侧，立下最后一道界线。

“问的是谁，就让谁自己答。”她的声音低，却清晰地传遍巷中，“我的旧债记在我的名下，分期到哪里就止在哪里。没有具名接收，没有可核时刻，没有署认见证，没有原始落处，谁也不能替我添加这一笔，也不能替这条巷子添。”

灯里的火没有变亮，却稳住了。

远端映像停在线外，没有宣布撤销提验，也没有抹去门槛上的白痕。数里外的石台上，闻照微只将扣住外层投影的共持锁纹收回半寸。

那半寸不足以替任何人解除文书，却让悬在巷口的残缺印记暂时停住。接收人、时刻、见证与落处仍旧空着，待补印悬在四栏之间，没有一枚真正落定。

远处贫城方向传来极细的动静，仿佛有人隔着长街，在粗纸上重重落笔。失温的笔画顺着入口游移而来，停在第一扇门前的细线上。

巷子里依旧没有一扇门打开。

苏晚弯下腰，用碎砖将分期旧页重新压实。她站回灯旁，掌背的青灰没有再往上蔓延。陆沉渊的投影仍悬在旧缝之内，淡得几乎要融进墙影，却始终没有跨出半步。

门槛前的细线向内弯出钩形，钩尖对准幽暗的门缝。新的字一笔一笔显出，淡灰扭曲，深深嵌进石阶缝隙。

“限期前答：交人，或共承拒交后果”。
