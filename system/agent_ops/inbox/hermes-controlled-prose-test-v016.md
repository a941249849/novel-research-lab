灰雨落进泥灯巷时，天还没亮。

细灰从歪斜的檐角垂下来，起初像灶膛里飞出的余烬，沾上人手背，便一点点沁出暗红。卖炊饼的周婶先叫了一声，忙把摊上的孩子往门板后塞；巷尾修阵的瘸腿匠人拎起铜钉，一瘸一拐地去压墙根新裂开的缝。

那裂缝里没有风，只有一盏又一盏命火被人从暗处吹细的声音。

陆沉渊站在自家门前，掌心托着一只粗陶盏。盏腹裂纹纵横，像干旱河床，里面却伏着一星银灰的火。他看见雨灰落在莫井兰的腕骨上，灰粒忽然蜷成一道细小的红痕，顺着皮肉往她心口爬。

“不是旧尘。”守灯老妇咬着牙，反手把袖口扎紧，“这是有人又来认咱们巷子的命。”

巷里没有人散。

周婶把炊饼篮塞给隔壁少年，自己拎着滚烫的铁铲守在门口；瘸腿匠人用肩顶住阵脚，肩胛被震得渗血；几个女人各自捧出命灯，把灯火聚在巷口，宁肯自己的灯影短一寸，也不肯让灰雨钻进孩子藏身的屋。

屋内传来一阵压抑的咳。陆沉渊回头，见母亲苏晚扶着门框，面色白得像纸。她胸前那盏小灯已经有六道裂纹，灯影落在地上，短得只够覆住她半双鞋。

“沉渊，”她望着他，声音很轻，“不许拿街坊的火去填。”

陆沉渊没有应，只把灰烬回灯盏压在掌心。那一点银灰火忽然照亮雨幕，照出每一粒灰中蜷缩的断痕——有的是周婶年轻时丢掉的三年，有的是瘸腿匠人亡妻临终前被抽走的一截暖光，还有一道细得几乎断绝，分明缠在苏晚的命灯上。

他闭了闭眼，指节发白。

“莫婆，认得出来么？”

莫井兰盯着那一缕灰火，眼眶发红，重重点头：“是阿青的。那孩子死了七年，怎么还在收他的年月？”

陆沉渊抬手，盏中灰火猛地一翻。他以指尖划过自己的心口，低声吐出四字：“烬痕归火。”

冷灰骤然倒卷。

第一根白发在他鬓边生出，接着是第二根、第三根。掌纹里的火钻入胸骨，皮肉裂开细细的口子，灰红光线沿着肋下游走，像有什么活物正从骨头里啃出来。他弯下腰，咳出一口冰冷的灰，灰落在石板上，竟烫出几个发亮的脚印。

巷外传来锁链拖地的声响。

可那被卷起的灰火没有落进他手里，而是越过众人，飞向一盏盏摇晃的命灯。周婶灯芯一颤，脸上深陷的皱纹稍稍松开；瘸腿匠人的阵钉重新泛起暖色；莫井兰腕骨上的红痕退成一道淡灰。

只有苏晚的灯，仍旧裂着。

陆沉渊抹去唇边灰屑，抬头望向巷口。雨幕尽头，一道披着黑甲的人影停在灰水里，甲片上垂着数不清的细链，链端轻轻颤动，正循着他胸前裂开的火光而来。

母亲扶住门框，想叫他回来。

陆沉渊却把陶盏交给莫井兰，转身站到泥灯巷最窄的入口处。身后每一盏灯都在亮，身前的冷灰却越积越厚。

他知道，今夜护住的不是一条巷子那么简单。

而是这些人本该活下去的年月。
