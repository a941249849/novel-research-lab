# 《凡人修仙传》深读剖析报告

- batch: 1
- evaluator: Agent
- verified_against_schema: yes

### 1. 主角初始处境
韩立，农家子弟，无背景，资质为低劣的四伪灵根。进入七玄门沦为墨大夫记名弟子面临夺舍危机，依靠捡到的青铜小绿瓶踏上仙途。

### 2. 核心欲望
在物竞天择的修仙界中保全自身 -> 追求长生。

### 3. 成长路径
炼气、筑基、结丹、元婴、化神、炼虚、合体、大乘、渡劫、仙人。副职为炼丹术（依靠小绿瓶催熟药草）。

### 4. 爽点释放机制
“扮猪吃虎与防守反杀”。韩立行事低调，遇事能跑则跑，杀敌前优先设阵、施毒。爽点在于一旦被逼入绝境，韩立冷静使用底牌反杀自大强敌，并熟练搜刮战利品（舔包），增殖隐秘资产。

### 5. 地图推进方式
越国七玄门（凡人武林） -> 越国修仙界（门派乱战避战） -> 乱星海（海岛开拓） -> 天南（扬名归来） -> 灵界与仙界（高阶秩序博弈）。

### 6. 资源竞争结构
极其零和。法宝材料、万年灵药极度稀缺，修士为了筑基丹或冲关丹药进行疯狂猎杀。

### 7. 阶层压迫结构
高阶修士对低阶修士拥有生杀大权；宗门视底层弟子为炮灰与弃子。

### 8. 组织 / 阵营关系
门派家族纯属利益纠葛；韩立唯一的安全网是自己的隐秘洞府与谨慎的行事准则。

### 9. 世界观扩张方式
越国只是修真小国 -> 乱星海是荒凉且规则截然不同的海洋秩序 -> 灵界是万族大世界 -> 仙界飞升后发现自己重新跌落为底层矿奴开始重构。

### 10. 情绪主轴
凡人求索的清冷、孤独与理性的利己避险。

### 11. 写作手法
战斗描写细节写实（注重距离、施法时机与符箓消耗）；升级逻辑严密自恰；“韩跑跑”特征贯穿全书。

### 12. 叙事节奏
“低调行事/收集灵草 -> 洞府闭关炼丹升级 -> 秘境夺宝反杀强敌 -> 局势危险跑路换图 -> 下一次闭关”。

### 13. 读者长期追更机制
韩立何时突破元婴、乱星海何时横推、掌天瓶的秘密何时揭晓。

### 14. 二次传播生命力
凡人流鼻祖，诞生了“韩天尊”、“万人敬仰厉飞雨”等长盛不衰的名梗。

### 15. 可蒸馏经验
1. 贫寒风险敏感与低调风控避战；2. 隐秘资产的长期催熟复利机制；3. 境界大跃迁后的起点归零与秩序重估。

### 16. 不应复刻内容
小绿瓶催熟植物的具体操作、厉飞雨背锅这一特定因果人物交互。
