# Mechanism Recipe Selection Policy

## 1. Purpose

This policy controls how future Phase 2A work may select mechanism recipes from the 35 Core7 mechanism inventory entries.

It prevents source-book cloning and keeps mechanism use abstract, transformed, and reviewable.

## 2. Selection Limits

Each original project candidate may select:

- main mechanisms: `2-3`
- auxiliary mechanisms: `2-4`
- constraint mechanisms: `1-2`

Recommended total per candidate:

- minimum: `5`
- maximum: `9`

The selected set must not come entirely from one source book.

## 3. Source-Book Distribution Rule

An original project candidate must:

- use mechanisms from at least `3` different Core7 books
- avoid selecting more than `3` mechanisms from the same source book
- avoid selecting mechanisms that recreate one source book's protagonist path

Forbidden:

- moving one book's mechanism set as a group
- following one book's opening pressure, growth path, midpoint escalation, and ending logic in sequence
- using a single source book as the hidden outline

## 4. Originality Red Lines

Do not use:

- original proper nouns
- source artifact names
- source organization names
- source level names
- source cultivation names
- source place names
- iconic source relationship combinations
- recognizable source event order

## 5. Required Original Transformation

Every selected mechanism must undergo all five transformations:

1. Appearance replacement
   - replace visual symbols, objects, spaces, and sensory presentation

2. Causal replacement
   - replace why the mechanism exists and what system produces it

3. Cost replacement
   - replace the price, backlash, limit, failure mode, and risk

4. Social-structure replacement
   - replace organizations, institutions, factions, class logic, and authority structure

5. Emotional-feedback replacement
   - replace the reader-facing emotional path, not just the names

## 6. Required Documentation Per Selected Mechanism

Each selected mechanism must record:

- mechanism_id
- mechanism_name
- source_book
- selected_role: main / auxiliary / constraint
- transformed_function
- transformed_cost
- transformed_social_context
- originality_risk
- target_schema_mapping

## 7. Review Rule

Any future candidate that fails this selection policy must be rejected before prose or scene work is considered.
