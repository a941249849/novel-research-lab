# v1.0 延期与裁剪功能清单 (Deferred Features)

本报告详细列出了不计入 Novel Research Lab v1.0 核心实现范围的复杂功能，并定义了它们未来被重新启用的条件与前置依赖。

---

## 1. 延期功能详情列表

### ① 重生多时间线 DAG 分叉引擎 (DAG Rebirth Engine)
*   **不进入 v1.0 的原因**：时间线的回溯与世界状态重载会导致大纲生成分支呈指数级分裂，严重干扰模型对单一故事走向的控制。v1.0 不需要真正运行时间线回滚，只需在故事关键节点通过纯文本描述“主角重生了，他知道未来的秘密”作为静态背景即可。
*   **未来启用时机**：当需要构建“多周目交互式网文写作沙盒”或进行“解密向/循环向复杂大纲自动推演”时。
*   **依赖的前置条件**：状态账本（State Ledger）的时间戳快照引擎、支持回溯的版本控制库。

### ② 多马甲因果/声望防火墙 (Multi-Persona Karma Firewall)
*   **不进入 v1.0 的原因**：在 v1.0 中，主角使用假名（马甲）只需要作为文本生成的本地指令，没必要在系统底层建立多套平行的、带因果阻断的安全机制。这会大幅增加实体关系数据库的关联开销。
*   **未来启用时机**：开发需要支持“跨数百万字、多势力长线智斗、掉马事件概率性推演”的复杂剧情生成器时。
*   **依赖的前置条件**：具备隔离视图的派系声望数据库、动态身份曝光率算法模型。

### ③ 法则覆写与动态领域限制图层 (Dynamic Domain Rule Overlay)
*   **不进入 v1.0 的原因**：类似于《人道》中“泰山封禅导致范围内神力失效”或《遮天》的“生命禁区压制修为”法则。在 v1.0 中，此类压制仅需在地图节点（Map Node）上设置静态的 `rule_desc` 提示词文本，由生成模型在写作时自行遵守，无需在代码层设计动态重载或公式重写的逻辑。
*   **未来启用时机**：当我们需要让模型在虚拟修真界中进行自动的“战力PK模拟”或“AI代理沙盒对抗”时。
*   **依赖的前置条件**：面向对象的战力公式解析器、支持规则动态重载的数值计算引擎。

### ④ 动态社会与派系利益模拟 (Dynamic Social Simulation)
*   **不进入 v1.0 的原因**：网文的宗门派系争斗多服务于主角的局部剧情冲突（如打完云岚宗换地图），无需真正运行一个以纳什均衡为底层的、带关税、贸易壁垒和联盟博弈的地缘政治动态模拟系统。
*   **未来启用时机**：大后期需要生成多势力混战、种族大战等超长线自适应剧情大纲时。
*   **依赖的前置条件**：基于 LLM Agent 的派系决策树算法、社会学动力学关系图谱。

### ⑤ 物理图数据库强依赖 (Graph Database Integration)
*   **不进入 v1.0 的原因**：为了表达《诡秘》的相邻途径互换，先前建议直接将系统迁移到图数据库上。v1.0 通过标准的 JSON 文件或简单的内存 Dict（字典）记录点和边即可，无需引入 Neo4j 等外部重量级图数据库，降低系统部署难度。
*   **未来启用时机**：当分析极其复杂的百万级关系网、家族血统图谱或几十条超凡途径的大型世界观时。
*   **依赖的前置条件**：轻量级内存图计算库适配、Schema-Graph 映射器。

### ⑥ 智能武器与极道帝兵 Entity 级实体化 (Sentient Weapon Actor)
*   **不进入 v1.0 的原因**：将法宝帝兵升级为拥有独立意志、羁绊和复苏度的独立 Actor 会破坏状态账本的“Actor 唯生物性”。v1.0 应继续将武器归类为 Inventory 静态道具，其自主战斗或觉醒描写仅通过道具属性中的描述字段驱动。
*   **未来启用时机**：开发“神兵流”或“法宝共生体”等特殊垂直题材的网文生成器时。
*   **依赖的前置条件**：支持非生物实体挂载意志状态的状态 ledger 扩展协议。
