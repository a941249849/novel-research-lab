# 《借天改命账》卷一生产契约 v0.25

## 唯一规模口径

- 全书：18 卷、1,800 章、600–680 万中文字符。
- 卷一《贫城错账》：100 章，单章 3,200–3,800 中文字符；高压结算章最多 4,200。
- 已验收：第 1–10 章。待生产：第 11–100 章。
- 旧的 8 卷／卷一 60 章蓝图仅保留为历史记录，禁止用于新 Intent、正文或发布包。

## 卷一五段节奏

| 窗口 | 章节 | 兑现边界 |
| --- | --- | --- |
| 开局残籍 | 1–10 | 母亲获得短缓冲，主角与共同体暴露上升。 |
| 护阵寿裂 | 11–30 | 共同体证据与一次有限遮掩，不得把信任变资源。 |
| 公开反打 | 31–60 | 第一次公开反打与首笔局部改账，核心寿债仍存。 |
| 封档余震 | 61–80 | 胜利后果转为封档、迁籍和州府边缘压力。 |
| 离城入口 | 81–100 | 贫城拒绝交人，打开州府入口，不解释古债全貌。 |

## 质量与发布门禁

1. 每章必须经过 Sol 正文、Luna 事实观察、独立连续性审计、状态结算、接受五道门。
2. 第 20、30、60、80、100 章必须额外进行窗口复盘；任一阻塞项会停止后续批次。
3. AI 味不是“已被消除”的可证明结论。当前通过禁用模板句、感官/动作约束、重复开头指标、独立审计和跨章状态核对降低风险；卷一发布前仍需要人工通读验收。
4. 番茄上传包只能从所有 100 章 accepted revision 生成，不能使用草稿或审计未通过文本。
