# 《不死不灭》深读剖析报告

- batch: 1
- evaluator: Agent
- verified_against_schema: yes

### 1. 主角初始处境
独孤败天，太古战神百世轮回凡胎。资质废柴无法凝气，开局因家族没落和未婚妻悔婚陷入武林底层挣扎。

### 2. 核心欲望
解开百世轮回封印 -> 寻找远古爱人 -> 斩杀天道，重塑天地法则。

### 3. 成长路径
蜕凡、破空、御空、涅槃、长生、天皇、神皇、逆天。

### 4. 爽点释放机制
“前世苏醒与万古战意”。在被正邪两道伪神围杀的绝局中，主角战魂觉醒，手持太古魔刀斩断因果，展现太古第一魔的狂霸战力，公开打碎伪神的虚伪法权。

### 5. 地图推进方式
武林大陆（凡人界） -> 天界神魔（大维度） -> 太古诸神废墟与逆天终局。

### 6. 资源竞争结构
核心资源为太古神魔舍利、神魔陵园气运、天地本源。

### 7. 阶层压迫结构
虚伪的天道与伪神将三界百族当做维持自身天劫和衰退周期的祭品。

### 8. 组织 / 阵营关系
太古神墓诸神（悲壮的逆天同战共同体）。

### 9. 世界观扩张方式
武林只是神魔游戏的沙盘 -> 天界只是众神墓地的一块碎片 -> 天道才是众生的永恒收割者。

### 10. 情绪主轴
狂放不羁、百折不回的逆天豪情。

### 11. 写作手法
场面狂暴、热血（经典的辰东早期神魔大战风格）；将百世轮回的悬念贯穿至终，意境极其开阔。

### 12. 叙事节奏
“被神魔围猎追杀 -> 绝境中魔性大发战神觉醒 -> 屠杀伪神重组世界规则”。

### 13. 读者长期追更机制
独孤败天到底是谁的转世、魔刀的终极因果、天道如何被屠杀。

### 14. 二次传播生命力
作为《神墓》前传，在太古神魔逆天史诗的网文迷中享有极高致敬度。

### 15. 可蒸馏经验
1. “神魔墓地与残魂觉醒”的宏大宿命气象；2. 战意化为实际力量的纯净格斗热血；3. 天道作为系统最高邪恶控制者的叙事闭环。

### 16. 不应复刻内容
独孤败天、神墓太古第一魔等原著具体人物名字。
