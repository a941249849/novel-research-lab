# 《完美世界》深读剖析报告

- batch: 1
- evaluator: Agent
- verified_against_schema: yes

### 1. 主角初始处境
石昊（荒），生来怀有至尊骨，却被同族石毅之母恶毒夺骨换血，导致生机濒死退化，在荒野石村柳神庇护下苟活。

### 2. 核心欲望
夺回至尊骨洗雪冤仇 -> 走出大荒击败石毅 -> 镇守九天十地与边荒关隘 -> 扫平黑暗源头，独断万古。

### 3. 成长路径
搬血、洞天、化灵、铭纹、列阵、尊者、神火、真仙、仙王、准仙帝、仙帝。

### 4. 爽点释放机制
“荒天帝无敌横推”。主角天资万古罕见。爽点在于他在边荒城墙下，以野性的格斗流在众神面前撕碎自大的异域天骄，极具强力横推的震撼感。

### 5. 地图推进方式
大荒石村 -> 石国皇都（宿命大战） -> 三千道州（大天骄角逐） -> 九天十地边荒（守关血战） -> 上苍之上。

### 6. 资源竞争结构
核心资源为至尊骨、十凶宝术、原始真解、仙种。

### 7. 阶层压迫结构
上苍大教和家族视边荒守卫为罪血弃子；异域天帝视下界为可以随意破坏的庄稼。

### 8. 组织 / 阵营关系
石村（主角最在乎的温情避风港，长线情感锚点）与天神书院。

### 9. 世界观扩张方式
大荒只是被遗忘的囚笼 -> 三千道州只是大千的一片断陆 -> 仙域背后是横跨纪元的万古黑暗黑祸源头。

### 10. 情绪主轴
极致大荒的野性生命力，与大后期“举世皆寂、独断万古”的苍凉悲壮。

### 11. 写作手法
早期的大荒求生写得极其生动，中期战斗场面极为宏大；主角荒天帝傲骨凛然的性格极具张力。

### 12. 叙事节奏
“在大荒野性成长 -> 走出石村打碎敌对血脉 -> 边荒九死一生守门 -> 举世凋零中冲关成帝”。

### 13. 读者长期追更机制
至尊骨涅槃重生、柳神下落、荒天帝最终结局。

### 14. 二次传播生命力
“独断万古荒天帝”在贴吧是无敌战力讨论的头号常客，悲情结局和柳神折柳在短视频平台引发广泛同人狂欢。

### 15. 可蒸馏经验
1. 至尊骨被挖的核心物理伤口；2. 独断万古、举世皆寂的史诗英雄孤独宿命；3. 守望者引导NPC（柳神）的设计。

### 16. 不应复刻内容
至尊骨骨质纹路直接描写、柳神作为大树的视觉表象。
