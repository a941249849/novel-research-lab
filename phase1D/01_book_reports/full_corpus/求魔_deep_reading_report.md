# 《求魔》深读剖析报告

- batch: 1
- evaluator: Agent
- verified_against_schema: yes

### 1. 主角初始处境
苏铭，生活在乌山部落的平凡少年，全身经脉被封无法修行蛮术，且记忆中存在不可解释的断裂与虚假感。

### 2. 核心欲望
变强走出大荒 -> 追寻消失的部落与阿公 -> 揭开记忆被随意篡改的真相 -> 对抗将蛮族当做轮回资粮的宿命大能（帝天）。

### 3. 成长路径
开尘、祭骨、蛮魂、命格、命缺、命界、命尊、荒劫、大域。副职为药草精炼。

### 4. 爽点释放机制
“绝望压抑后的玉石俱焚式爆发”。当主角发现自己的半生温情与亲人皆是仙族大能“帝天”编造的轮回幻境后，爽点在于他以近乎自残的疯魔意志击碎幻境，并在现实中给仇敌以毁灭性重创。

### 5. 地图推进方式
乌山（虚假新手村） -> 憨子与九蛮（交界） -> 蛮荒大陆（追寻真相） -> 神源废墟/阴死界（大宇宙废墟） -> 桑相与苍茫（宇宙大宿命）。

### 6. 资源竞争结构
核心资源为“蛮神传承”、“真身”与“阴死界坐标”。仙族将蛮族当做夺舍和延续寿命的温床。

### 7. 阶层压迫结构
仙族对蛮族实行纪元级的灭绝和记忆奴役，将蛮族当做剧本中的牵线木偶。

### 8. 组织 / 阵营关系
第九峰（反常的冷清师尊与温暖护短师兄共同体），对立面是仙族帝天、道晨宗等宇宙执棋者。

### 9. 世界观扩张方式
乌山只是棺木中的一场梦 -> 蛮族世界只是被阴死之地 -> 桑相宇宙只是虚空中一只将死蝴蝶的翅膀纹路。

### 10. 情绪主轴
孤独、执着与宿命式的悲凉之歌。我若执意化魔，天下无仙。

### 11. 写作手法
将悲剧美学推至巅峰；文字极具诗意与古风沧桑感；多重反转的宿命循环极具情绪张力。

### 12. 叙事节奏
长期蓄水（主角在宿命大网中苦苦挣扎与剥离记忆真相），高潮时在主角自我毁灭般的意志下越阶死斗爆发，最后以深沉的告别收尾。

### 13. 读者长期追更机制
乌山的真相、第九峰师兄的下落、苏铭如何反制帝天。

### 14. 二次传播生命力
极具逆境反噬和悲壮自献，在读者群中拥有极高的情怀碑。

### 15. 可蒸馏经验
1. 虚假回忆与认知断裂的开局；2. 反常师门庇护下的深厚情感羁绊；3. 最终“自我缺席式圆满”的史诗悲剧回收。

### 16. 不应复刻内容
帝天分身夺舍这一具体因果结构、蛮族祭坛命名空间。
