泥灯巷口的那株百年老槐树下，原本如哨音般尖锐刺耳的穿堂阴风，在这一瞬间彻底停滞了。空气凝固得如同被冻结的冰块，连同那股常年弥漫在巷子深处的霉烂叶子气味也一并被锁死。那些平日里积攒在青石板深缝处的潮湿黑泥，仿佛被一只从虚无半空中轰然按下来的无形巨手压制，再也无法往外翻涌出半点带着尸气与陈年水腥味的白雾。

在这死寂之中，原本高悬于半空、散发着青色墨光的迁籍附条突然剧烈地抖动起来。这纸试图将苏晚连人带命档一并强行转移的公文文书，在这一刻并没有如同先前那些废纸般在暴烈的罡风中被绞成漫天飞舞的碎屑，也未违背命审台刚刚落下的法理裁决而重新贴回那堵斑驳剥落的青砖山墙上。相反，它像是被某种无形而沉重的规矩所牵引，在虚空中微微一折，随即便被半空中突兀开裂的一道狭长裂缝吸入。

那裂缝之中，正缓缓降下一个暗沉沉的黑铁铜匣。铜匣的表面铸造着密密麻麻、重叠交错的命理云纹与飞禽走兽的浮雕，铜绿斑驳的边角散发着沉甸甸的阴司铁锈气味。随着匣口深处的重力齿轮发出一声低沉而令人牙酸的“咔哒”咬合声，覆盖在匣盖缝隙处的漆黑封泥瞬间凝结成坚硬的石质。那张一度压得泥灯巷喘不过气来的迁籍附条，便被这般永久地封死在黑暗的铜壁之内，作为一桩已被判决失效的陈年案卷，彻底归档封存，再无重见天日之可能。

这是命审台在最高法理记录中做出的裁决显影。附条被判定不能继承原印，其上所载的一切迁籍效力在法理册籍中被当场撤销。命籍衙在法理程序上，永远失去了以这枚附条强行将苏晚的命档转移至别处的支点与路径。

然而，程序上的撤销并未带来哪怕一丝温存的转机，也未能减轻笼罩在泥灯巷上空的任何重压。

相反，几乎是在铜匣封泥凝固的同一瞬间，天空中低垂的铅灰色浓雾疯狂地向内翻卷、堆叠，仿佛一池被煮沸的墨汁。在这墨汁般的浓云深处，一枚执行寿印带着沉闷至极的嗡鸣声轰然降下。那印章通体呈现出一种粘稠的暗惨红色，底部的朱砂印泥仿佛是由无数尚未干涸的陈年心头血混合而成，正散发着浓烈且令人作呕的铁锈气味。这枚新落下的重印上，并无转籍、迁户的冗余要求，只有最干净、最明确也最不容置疑的八个篆字——当期原地追缴，具名旧债。

命籍衙在失去了合规将人带走的迁籍路径后，立刻以最快的速度启用了命审台做出的补偿性裁定。既然不能把人连带命档一起迁走，他们便获准在泥灯巷的原地，对苏晚尚未结清的具名旧债进行一次仅限当期寿火位的即时扣取。

这是一场归属清楚、程序完全合法的原地追缴。狂暴的执行重压化作一圈圈灰白色的气流，呈环状向着四周横扫开来。泥灯巷巷口那道本就布满裂痕的护阵，在寿印纯粹的重压下，发出了不堪重负的细密呻吟。原本试图维持外沿守护的微弱青光开始剧烈闪烁，仿佛风中残烛，随时都会彻底崩解。

苏晚站在执行寿印的正下方，身体被压得略微前倾，左手却始终让命灯保持水平。她把失去知觉的右臂收在身后，不让它碰灯，也不给命籍衙留下“拒不受印”的借口。寿印每下降一寸，她便调整一次脚下的位置，让灯腹正对公开标出的当期火位。她不是在硬撑一副受伤的身体给旁人看，而是在用每一个可核验的动作限定这次执行：债归她，灯由她持，允许扣取的只有令上写明的一格。

“苏丫头！”泥灯巷的土墙后面，顾婶有些按捺不住，端着自家的油泥灯往前迈了半步。那盏破旧的陶灯里烧的是粗劣的猪脂，散发出阵阵刺鼻的油烟意。她身后，几户相熟的街坊也纷纷亮起了门前挂着的昏黄纸灯。那些微弱的灯火聚在一起，试图在苏晚的身周撑起一片能够遮挡寿印寒意的光幕。

然而，还没等那光芒靠拢，苏晚便冷冷地喝止了他们：“退回去。”她的声音冷静，甚至透着一种让人退缩的淡漠。

“这笔债挂在我的名字下面，写的是我的寿火位。”苏晚盯着那枚在头顶三寸处轰然停住的寿印，声音不急不缓，“泥灯巷的规矩，不替人代债，也不交人。你们要是把自家的命火递过来，便是主动将自己的名姓挂进这笔烂账的流转里。到时候，法理株连，谁也别想清白。都退回自己的门槛后面去。”

顾婶的脚僵在半空，又缓缓缩了回去。泥灯巷的街坊们面面相觑，终究是一个接一个地将手里的灯火掩进了衣袖里。随着那些微弱光芒的收回，原本覆在巷口的破损护阵失去了支撑，边缘的微光闪烁了几下，便彻底熄灭在黑暗中。

但这也划清了界限。这枚执行寿印，将无法波及任何一个无辜的住户。他们退回到了自己的界限之内，为苏晚保留了拒绝被错误救法绑架的权利，也保全了泥灯巷最后的根基。

陆沉渊站在苏晚侧后方三步开外，呼吸沉重得像一架老旧风箱。右眼的银灰盲区仍旧封死细节，焦黑眼眶外爬满血丝；他只能用左眼看见惨红寿印公开显出的轮廓和落向灯腹的方向。至于缠上脚踝与衣角的冷金细线，他并非看见，而是从皮肤逐寸收紧的刺痛中感觉到它们正在重新锁定自己。

那是州府法理的具象化纠缠。他的暴露度正在以一种恐怖的速度攀升，如果他此刻闭眼，或者退居幕后，先前用性命换来的程序破绽就会立刻被冷金丝线重新缝合。

“把眼睛闭上。”苏晚微微侧头，眼角的余光扫过陆沉渊那双满丝的眼睛。

“我闭不上。”陆沉渊的嗓音沙哑得不成样子，“我若不看，这印落下的分寸便无人见证。若是他们多抠走你一文寿火，便是死无对证。”

苏晚的眉心微微拧起。她握着命灯的左手没有动，藏在袖中的右臂却猛地向后一挥。一股夹杂着冰蓝色碎屑的冷风平地刮起，宛如一堵无形的墙，狠狠撞在陆沉渊的膝盖骨上。陆沉渊只觉得双腿一阵发麻，整个人不受控制地向后退去，直到后背结结实实地撞在顾家那堵冰冷潮湿的土墙上。

“站稳了，只许看，不许动。”苏晚的声音冷硬得像铁。

这是母子之间在防线边缘达成的一种默契。不能越界，不能用多余的抵抗去给命籍衙留下“抗拒追缴”的口实。

在迷雾朦胧的泥灯巷外，隐隐约约仍旧能听到沉重的马蹄声和皮甲摩擦的钝响。州府的甲兵并未因为迁籍的取消而撤走，反而像是一群闻到了血腥味的豺狼，盯着巷口的这盏命灯。他们手中握着的拘籍锁链在冷风中发出哗啦啦的闷响，冰冷而残酷。

半空中的惨红色寿印似乎也察觉到了两人的决绝。那庞大的印身在虚空中微微一顿，随即，底部的血红色纹路开始疯狂地向内收缩。原本铺天盖地的寒意被强行凝聚，化作一束仅有小指粗细、却亮得刺眼的暗红色光柱。那光柱带着尖锐的啸叫声，笔直地落向苏晚左手所持命灯的灯腹。

陆沉渊咬着后槽牙，强行将体内所剩无几的血气灌注进双眼。他的视线穿透了那一层粘稠的红色雾气，紧紧锁定了光柱落下的位置。命灯的灯腹上，那个原本用来承载命火的凹槽在暗红光柱的炙烤下，发出了轻微的吱呀声。那一处代表着当期寿火部位，突然剧烈地颤抖起来。

并没有预想中的命火被强行抽离并返回虚空的画面。在光柱极度凝聚的重压下，那个凹槽最深处的陶胎仿佛在微微发软。紧接着，一层诡异的、带有灼烧质感的黑色灰烬，缓缓从凹槽的最底部浮现了出来。那不是新生的灰烬，而是一层已经干涸、在岁月的沉淀下显得死气沉沉的旧痕迹。随着那层灰烬的浮现，一道已经完全闭合的、清晰无比的旧压痕展现在了陆沉渊的视线中。

那是一个完整的、不知在何年何月就已经落下的旧印记。它卡在当期火位的关节处，像是一把锈蚀的铁锁，冷酷地宣告着这个位置早已被某种未知的因果彻底填满，根本没有留下任何可以被重新扣取或写入的空间。这道闭合的旧压痕在暗红光柱的炙烤下反而显得更加清晰，它就像是一道深刻在命灯骨髓里的旧疤，任凭新的印章如何施压，也无法将其抹去，更无法在上面重叠印下任何新的债额。

但即便如此，头顶上的执行寿印也并未就此散去。那道暗红色的光柱依然顶在旧压痕之上，两股性质截然不同却同样冰冷的法理力量在灯腹的凹槽里剧烈咬合，发出令人牙酸的摩擦声。

州府的“外槽封锁”没有半分松动，泥灯巷外围的浓雾之中，甲兵的马蹄声愈发沉闷。而在苏晚左手端着的命灯之中，那代表着最后期限的计时液体，已经在滚烫的气泡中沸腾到了极点。那一滴滴粘稠的蓝色药液，顺着残破的刻度无可挽回地向下滑落，落在灯台的边缘，发出刺耳的哧哧声。水汽在寒风中蒸腾，最后化作一片虚无。

两个昼夜。

这是本命灯留给苏晚最后的活命时间。如果在期限届满之前，他们依然无法从那些陈年的旧账里翻找出这笔寿火转运起点的铁证，这盏早已千疮百孔的命灯，便会在下一次执行寿印的重压下彻底爆裂。

苏晚的左手微微发抖，灯台却仍停在执行线正中。顾家紧闭的院门后，街坊们的呼吸声与压低的争执断断续续传来；有人后悔撤了守位，也有人反复确认自家灯绳是否收净。今夜他们没有交人，也未让多余的命火被卷入，却再也回不到所有门灯同时亮起的时刻。允许撤守保住了各家的选择，也把共同体的裂缝明明白白留在了每一扇门槛上。

陆沉渊靠在冰冷墙壁上，右眼仍困在银灰里，左眼则盯着灯腹被寿印压力逼出的闭合旧压痕。那只是现场已经公开显出的表层事实，压痕下面写着谁、来自哪条链，他仍然看不见。若强行再开识账，他也许会越过这条边界，但残躯未必撑得到结果出现。

但他同样清楚，自己的这具残躯，可能根本撑不到看清真相的那一刻。

今夜的第一缕晨风从巷口吹来，却没有带来半点暖意。那风吹得供案上散落的旧账页哗啦啦作响，陈年纸张腐烂的霉味在空气中弥漫开来，宛如泥灯巷本身正在散发出的暮气。远处的迷雾里，马蹄声依然隐隐约约。命籍衙吃瘪后的下一步动作，或许已经在路上了。
