# 审查结论

本审查针对《百工夜行录》v0.2 结构设计文件（涵盖研究契约、文明机制库、系列蓝图、概念压力测试、世界史骨架及 P0/P1 地域证据卡）进行了独立结构评估。

《百工夜行录》在近现代东方幻想题材中展现出罕见的制度深度与劳动逻辑约束。项目摒弃了“非遗名词打卡”、“升级榜单”和“主角万能献祭”等常见网文套路，成功建立了一套基于“公载/暗载”、“识材/验损”、“责任账与退出权”的文明维护体系。第一卷及前三十章的叙事动力、生活肌理与角色冲突闭环表现优异。

然而，从 260 万至 340 万字超长篇连续创作的可持续性来看，目前 v0.2 设计在**中段结构布局、地域证据深度、机制重复使用率以及部分卷宗内容容量**上存在实质性缺陷。特别是 P1 路线研究债务未清、第六至十卷容易陷入“单工种巡回打卡与注水塌陷”，以及第十一至十五卷从地域单元突变为宏大议会辩论导致的结构断层，构成了阻止项目直接初始化的核心瓶颈。

## 阻断问题

1. **阶段门禁与研究债务违约（P0级）**
   根据 `concept-stress-test.v0.1.json` 与 `research_contract.v0.1.json` 的门禁契约，`fieldwork_debt_blocks_project_initialization` 为 `true`，且 `creation_assets` 阶段状态仍处于 `blocked`。目前 P1 路线（晋陕河西、岭南、西南、东北、高原绿洲）的证据卡存在严重结构缺口：
   - 晋陕河西路线（`p1-northwest-corridor`）证据卡全部集中于陕西造纸，山西会馆、堡寨、河西石作与金属铸造完全缺失；
   - 高原绿洲路线（`p1-plateau-oasis-boundaries`）自承“样本极薄，新疆绿洲金工、青海河湟、内蒙古毡作及跨语言商路均未进入取证”；
   - 在缺乏交叉核验证据的前提下推进第七卷（减去的城）、第九卷（药成两面）和第十卷（停伐钟），违反了“无真实劳动与场地证据不得生成机制”的底层契约。

2. **中段结构塌陷与地图巡回套路（P0级）**
   蓝图第六卷至第十卷（约 100 万至 180 万字中段）呈现明显的“一卷一地域一工种”机械拼盘倾向（第六卷江南陶瓷 -> 第七卷西北石作 -> 第八卷西南织染 -> 第九卷西南/高原医药 -> 第十卷东北林业工业）。这使原本在第一至五卷建立的高压城市退构危机，降维为单元剧式的“地方手艺巡回救火”，导致核心主线张力在大字数中段严重衰减。

3. **后半程议事突变与结构断层（P0级）**
   第十一卷至十五卷突然从地方具体的工序与材料修复，转跃为“九地互认”、“全国供应链”、“公共授权实验”、“天下旧账审计”与“终局四方案选择”。从“手艺与案件”直接跨越到“国家级政治议会”，缺乏中间层级（如中等区域流域治理、行业公会制度嬗变）的过渡，极易导致正文后期沦为高概念口水战与抽象哲学宣讲。

## 高风险问题

1. **机制使用率不均与概念重复（P1级）**
   - 纸扎与临时骨架机制（`temporary_frame_assembly`）仅在第二卷作为主机制出现一次，随后在整部 15 卷中彻底边缘化，未进入文明历史的主干；
   - 风险隔舱（`risk_compartmentalization`）、尺度协议（`shared_measurement_protocol`）与档案修补（`record_repair_and_versioning`）在第一、三、四、五、十一、十四卷中被反复使用，剧情冲突破解方式存在同质化风险。

2. **核心主角团专业权限盲区（P1级）**
   第九卷《药成两面》以医药炮制与受控转性（`controlled_transformation`）为核心机制，但五名核心人物（古建、材料检测、盔头戏装、造船水利、钟表档案）无一人具备医药炮制与专业医疗的资质与权限。由程雪青与林岱跨界主导第九卷，破坏了“不越级、不兼通、依赖专业人员”的硬性设定。

3. **单工种卷宗的注水与容量虚高（P1级）**
   第六卷《不开的窑》（20 万字规划）仅围绕“一座旧窑是否开窑与整批构件报废”展开，剧情线过于单一；第八卷《无主纹》（20 万字规划）仅围绕“纹样复制与社区版权”。单个工艺事件难以支撑 60-70 章的体量，若无强有力的副线案件与社会冲突填充，极易造成技术细节灌水。

4. **马小满工具人化风险（P1级）**
   马小满（钟表修复师/档案员）的长线动机虽然是推动档案公开，但在前四卷中其核心作用高度绑定在“手握周砺父亲事故的第二份秘密记录”上，容易退化为主角个人寻亲探案的剧情钥匙，弱化其作为“制度审计者”的独立阶级与专业立场。

## 通过项

1. **底层概念与力量体系逻辑严密**
   “百工维修律”摒弃等级化数值，将增长锚定在识材、验损、成序、合手、分载、留档六维能力上；坚持“能力不凭空增加承载，只能重组、补充或延期”，从根源上杜绝了战力膨胀与战力崩坏。

2. **五人核心群像具备实质性权限边界**
   五名主角均拥有明确的“技术上限”与“终局权限剥夺”：周砺无权单独决定承重者，程雪青不裁决文化解释权，杜承礼不垄断剧种传统，林岱必须接受期限审计，马小满不能替受害者决定和解。主角团无法靠个人英雄主义包办终局。

3. **第一卷（无名梁）与前三十章开局完成度极高**
   前三十章以“地铁工地断梁 -> 旧戏楼退构 -> 盔箱自行开启 -> 地下暗船显形”层层推进，成功将现代工程、传统营造、戏曲程式与水利隔离交织在一起。叙事紧扣生活压力与社会代偿，每一章均产生不可逆的状态改变（如周砺脊背留伤、街区仅获三年维护期），具备极强的开卷吸引力与情绪黏性。

4. **严苛的文化、医疗与宗教边界控制**
   契约严格禁止将真实族群纹样、纸扎丧俗、经文印制与民族医药直接改写为法器、邪术或万能药方，明确了“只研究结构、工序与社区组织关系，不抽取神圣设定”的创作禁区，展现出高度的学术敬畏与伦理自觉。

## 人物独立性诊断

1. **周砺（古建见习 -> 公共验损人）**
   - **独立性：B+**
   - **诊断**：第一视角推动力强，但全书前半程过于依赖“替父还账”这一单一动因。在第四卷与第十四卷中，若不能脱离父亲阴影，容易沦为传统网文的“复仇/平反型主角”。
   - **修正**：在第六卷前必须完成“从寻找父亲无罪 -> 承认父亲有罪并主动审计父亲”的心理切割。

2. **程雪青（材料检测工程师 -> 开放标准维护者）**
   - **独立性：A-**
   - **诊断**：代表现代工程科学的力量，逻辑自洽。但蓝图中其出场率过高（在 15 卷中主导 8 卷），容易掩盖地方工匠与特殊工种的专业光环。
   - **修正**：限制其在第七、八、九卷的参与深度，突出其“检测仪器在社会暗载面前失灵”的挫折感。

3. **杜承礼（盔头传人 -> 剧装维护制度者）**
   - **独立性：B**
   - **诊断**：第二卷高光后，在第六至十卷的中段几乎边缘化，直到第十一卷才重新出场。其关于“角色授权与卸装”的核心机制未能贯穿全书。
   - **修正**：让“角色授权/卸装”机制参与到后续公共官员、维保人员的身份隐喻中，使其专业在后半程持续发力。

4. **林岱（木船放样师 -> 应急隔离审计者）**
   - **独立性：B-**
   - **诊断**：第三卷《封舱潮》表现极其出色，但在第九卷《药成两面》中被硬凑为领衔人物，暴露出工种不匹配的硬伤。
   - **修正**：将其核心舞台严格限定在水利、舟船、水网及大型封闭设施（如第十卷工业管道、第十二卷运河供应链）中，剥离其在医药卷的领衔地位。

5. **马小满（钟表修复师 -> 责任账守护人）**
   - **独立性：C+**
   - **诊断**：目前存在严重的“剧情钥匙化”倾向。由于她掌握周砺父亲秘密档案，其前中期的行动几乎完全围绕周砺的诉求转动，缺乏作为独立的钟表/时间校准工匠的个人生计与职业困境。
   - **修正**：赋予其独立的修表作坊生计线、同行复核压力以及对“时间精度被官办机构垄断”的独立反抗线。

## 文化与证据边界

1
