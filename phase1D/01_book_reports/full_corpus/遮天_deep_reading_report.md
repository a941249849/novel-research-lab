# 《遮天》深读剖析报告

- batch: 1
- evaluator: Agent
- verified_against_schema: yes

### 1. 主角初始处境
叶凡，地球普通青年，突遭九龙拉棺降临被强行带入星空深处的北斗星域。因身怀荒古圣体（被天地环境压制的修行废体，升级极耗神源），开局被各大仙家洞天无情拒绝，面临修行资质判死刑的死局。

### 2. 核心欲望
重回地球寻找亲人 -> 打破圣体无法修行的宿命枷锁 -> 踏上奇士府与星空古路征道称帝 -> 平定生命禁区的黑暗动乱，立天庭，带领部属举教飞仙。

### 3. 成长路径
轮海、道宫、四极、化龙、仙台（半步大能、大能、王者、圣人、圣王、大圣、准帝、大帝、红尘仙）。副职配合“源术”寻矿、切石，用于冲关积累。

### 4. 爽点释放机制
“大劫雷劫越阶越野”。前期隐秘收集帝兵碎片与源石，在冲关的雷劫降临时，当着各大世家、圣地圣子包围，将雷劫引入敌群越阶坑杀。爽点爆发伴随着在场各门派长老的震惊、通缉与社会名望暴涨。

### 5. 地图推进方式
地球（认知断裂） -> 北斗禁地/东荒（门派发育、世家追杀） -> 紫微星域（认知跃迁） -> 奇士府与星空古路（同代竞技大地图） -> 禁区古原与成仙路（终极博弈）。

### 6. 资源竞争结构
核心资源为天地奇珍（“源”、“神源”、“大帝经文”、以及“不死药”）。通过古墓夺宝、切石赌命加速配角淘汰。

### 7. 阶层压迫结构
荒古世家（姬家、姜家）与顶级圣地垄断道书功法与神源矿产。至高生命禁区的古老至尊视世间百族为收割长生的庄稼（黑暗动乱）。

### 8. 组织 / 阵营关系
弱小时受太玄门拙峰（李若愚）及姜神王庇护（情感共同体），敌对势力是太古万族天骄、生命禁区至尊及各大自私圣地。

### 9. 世界观扩张方式
地球只是封印的帝星 -> 北斗荒古禁地是帝路一角 -> 星空古路是诸天万界圣体与天骄的竞技场 -> 生命禁区是历代残存大帝的自斩藏身处 -> 成仙路本身是一场横跨万古的骗局。

### 10. 情绪主轴
浩瀚、苍凉与对抗岁月的悲壮长歌。主角在一路前行中，战友红颜相继凋零，最终只能孤独地带着铜棺横推成仙路。

### 11. 写作手法
善用大尺度场面描写（九龙拉棺、帝兵对撞的视觉震撼）；群像塑造富有二次生命力（黑皇、段德）；在历史断层中掩埋大量伏笔。

### 12. 叙事节奏
“低调探秘/被世家追杀逃亡 -> 雷劫冲关引来轰动反杀 -> 换图休整切石发育”的黄金周转节奏。

### 13. 读者长期追更机制
圣体能否冲关荒古诅咒、九龙拉棺的来历、狠人大帝的布局、成仙路何时开启。

### 14. 二次传播生命力
极具网络传播的招牌金句（“我儿王腾有大帝之资”、“仙路尽头谁为峰，一见无始道成空”、“待我君临天下”）。

### 15. 可蒸馏经验
1. 宏大历史断层与神话闭环设计；2. 赌石/切石的局部趣味性玩法；3. 越阶雷劫的借势释放机制。

### 16. 不应复刻内容
九龙拉棺视觉特征、狠人大帝这一标志性因果。
