# 《百工夜行录》广域研究计划 v0.2

> 状态：资料生态已建立，P0 核心机制交叉核验通过，P1 五条路线已完成种子采集。未初始化项目，未授权正文。

## 研究目标

《百工夜行录》不能成为十二种非遗项目的说明书。它需要获得四层同时存在的中国经验：

1. **历史骨架**：地方志、行业志、文献、博物馆与学术研究提供年代、制度和技术边界；
2. **地方肌理**：村落档案、地方文史、县市媒体和区域研究提供地景、交通、生计和地方差异；
3. **劳动手感**：工匠口述、完整工序影像和行业回忆提供声音、动作、失败、协作和身体经验；
4. **民间叙事**：故事集、论坛、评论区、地方社区和口头异说提供记忆如何变形、冲突如何被讲述以及普通人真正关心什么。

官方来源只负责底线，不垄断故事。论坛和社区材料也不是低价值材料，它们对生活语言、异说、失传线索和当代态度尤其重要；但它们不能在未经核验时承担历史事实。

## 五级来源

| 等级 | 典型来源 | 可直接承担的工作 |
| --- | --- | --- |
| A | 方志、档案、博物馆、论文、专业准则 | 技术事实、历史时间线、制度边界 |
| B | 地方文史、传统村落档案、地方媒体、县市非遗机构 | 地方差异、社区关系、近现代变迁 |
| C | 从业者口述、长访谈、完整工序影像、行业回忆录 | 手感、术语、失败模式、劳动关系 |
| D | 论坛、知乎、豆瓣、贴吧、评论区、地方自媒体 | 关键词、异说、生活细节假设和一手线索 |
| E | 无出处怪谈、营销短视频、影视和网络二创 | 当代想象与陈词滥调观察，不承担事实 |

社区内容的正确路径是：

```text
帖子或评论 -> 线索卡 -> 反向检索地名/术语/人物 -> A/B/C交叉核验
             -> 保留异说与分歧 -> 才能进入候选Story Bible
```

## 九个地域研究镜头

首轮不按行政区机械平铺，而按生态、交通和行业网络建立九个研究镜头：

- 燕赵齐鲁与中原平原；
- 晋陕关中与河西走廊；
- 江南水网与徽州山地；
- 闽台海洋与侨乡网络；
- 岭南与珠江水系；
- 荆楚、巴蜀与长江上游；
- 云贵高原与横断山地；
- 东北平原、林海与边地河流；
- 高原、草原与西北绿洲通道。

这些名称只是检索镜头，不是文化统一体。同一镜头内部仍需标注县域、社区、族群、语言、时代和讲述者，禁止用“北方”“江南”“西南少数民族”等标签覆盖实际差异。

## 第一采集顺序

P0 先做四条能够反向强化现有核心机制的路线：

1. **闽台海洋路线**：福船、艌缝、船工、海损、侨批、庙宇营造，补足“隔离损伤”的真实操作；
2. **江南水网路线**：圩田、桥匠、织造、作坊账簿，补足“公共维护与责任记账”；
3. **荆楚长江路线**：船帮、纤夫、洪水、傩戏、药市，检验职业共同体和灾害记忆；
4. **中原平原路线**：木匠、上梁、庙会、地方戏班，检验营造、角色和公共仪式的连接方式。

其余五条路线已在 P0 证据卡模式通过后展开；每条先建立三张可追溯种子卡，再按真实债务继续加深，避免积累无法消化的链接。

## 单条证据卡

每条材料必须记录：

- 来源等级、URL、标题、作者或讲述者、发布时间与访问时间；
- 具体地点、适用年代、相关技艺和社区；
- 原始材料明确说了什么；
- 哪些内容是整理者或模型的推论；
- 支持的材料、工序、失效、人物关系或民间故事母题；
- 与已有资料一致、冲突还是补充；
- 可用于事实、生活肌理、叙事机制，还是只能形成待核问题；
- 版权、隐私、族群和宗教使用限制。

不保存整篇受版权保护内容，不复制独特表达和完整故事。系统只保存可追溯摘要、短事实、分歧和抽象机制。

## P0 首批结果

四条路线已经形成十六张证据卡：

- 闽台海洋：隔舱、放样、铺板、捻缝和试水是一条跨工种责任链；
- 江南水网：水利系统可能因维护单位各自为政而失效，技术能力不等于公共协作能力；
- 荆楚长江：号子是根据水势、岗位和劳动动作变化的多人同步协议；
- 中原平原：工匠馈赠俗规、行业班社和庙会演戏共同构成人情、报酬与公共记忆网络。

四条路线均已获得 A/B 基线与 C 级从业者或亲历者材料，核心机制状态提升为 `triangulated`。这只表示机制交叉核验通过，并不清除每条路线保留的原书、原始档案、事故记录和更多岗位视角债务。

## P1 首批结果

其余五个地域镜头已经形成十五张种子证据卡：

- 晋陕河西：先以陕西造纸建立原料、季节、交通和作坊生态模型，同时诚实标记河西、山西会馆、铸造和石作缺口；
- 岭南珠江：龙船修造证明能力属于完整班组，戏服制作证明器物必须接受舞台身体和使用现场校验；
- 云贵横断：枫香染、蜡染和手工纸显示技艺与家庭、集市、河流、纹样权属和生计不可拆分；
- 东北林海：林场口述、国家森工资料和停伐家庭把工具、道路、岗位、工伤、家庭与生态转型接入同一责任链；
- 高原绿洲：木碗、经幡和本地乐器维修首先建立社区知识边界，明确神圣图像和经文不得自由幻想化。

机器可读证据卡位于：

P1 中的晋陕河西、西南高地和东北林海三条高风险路线已扩充至每条八张证据卡，A/B 级来源占比不低于 50%，核心机制状态提升为 `triangulated`；岭南与高原绿洲仍为 `triangulation_pending`。所有路线继续保留具体地域、社区和岗位债务，不宣称九个地域已经研究完毕。

## 门禁

广域资料生态、P0 核心机制交叉核验和 P1 全域种子卡已经建立，但不等于地域研究已经完成。下一门禁是编译百工文明母库，并证明：

- 每条关键技术判断至少有 A/B 与 C 两类材料交叉支撑；
- 每个民间故事保留地区、版本和讲述语境；
- 论坛异说没有被包装成历史事实；
- 九条路线能够汇入“损伤可见、责任可分、风险可隔离、知识有边界”的核心机制，而不是堆砌风俗名词；
- 全书十五卷的每次地域扩张都有研究资产、人物责任和制度变化支撑，而不是地图打卡。

文明母库与十五卷脉络通过独立审查后，才能决定是否初始化正式项目和固化 Story Bible。正文仍需单独授权。
