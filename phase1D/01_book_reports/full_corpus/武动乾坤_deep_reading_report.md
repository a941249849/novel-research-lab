# 《武动乾坤》深读剖析报告

- batch: 1
- evaluator: Agent
- verified_against_schema: yes

### 1. 主角初始处境
林动，分家落魄弟子。父亲是天才却被宗家林琅天打废，分家备受欺压，林动偶然捡到神秘石符开启苦修。

### 2. 核心欲望
击败林琅天为父复仇 -> 夺得宗族大会主导权 -> 收集八大祖符 -> 救回复活应欢欢。

### 3. 成长路径
淬体、地元、天元、元丹、造化、涅槃、生死、转轮、轮回、祖境。副职为“符师”（精神力攻击）。

### 4. 爽点释放机制
“大比武与林琅天清债”。以分家战本家天才为暗线，主角在石符（隐秘资产）辅助下隐秘越级。在举国瞩目的宗族比武上众目睽睽下击碎林琅天的骄傲，情绪得到彻底释放。

### 5. 地图推进方式
青阳镇 -> 大炎王朝（宗族大会） -> 百朝大战（选拔） -> 乱魔海（祖符争夺） -> 邪域终战。

### 6. 资源竞争结构
核心资源为天地唯一的八大“祖符”（代表底层规则掌控权）、涅槃心。

### 7. 阶层压迫结构
宗家对分家的冷血剥削，异魔对整片大陆规则天道的污染蚕食。

### 8. 组织 / 阵营关系
青阳分家与道宗（温情共同体，尤其是应欢欢代表的道宗）。

### 9. 世界观扩张方式
大炎王朝只是外围 -> 百朝是超级宗门的沙盘 -> 乱魔海是远古符祖封印异魔的遗迹之海。

### 10. 情绪主轴
隐忍、家庭亲情羁绊与为了大局爱人献祭的悲情。

### 11. 写作手法
商业升级打脸套路纯熟；精神力副职的打法拓宽了爽点释放空间；女主对应欢欢的感情刻画动人。

### 12. 叙事节奏
“捡宝苦修 -> 宗族大比越阶复仇 -> 乱魔海九死一生争夺祖符 -> 爱人化道阻挡异魔”。

### 13. 读者长期追更机制
林动何时战胜林琅天、下一种祖符位置、应欢欢结局。

### 14. 二次传播生命力
林琅天与林动的双骄宿怨被贴吧津津乐道，应欢欢化道相助被广泛用来剪辑同人虐心视频。

### 15. 可蒸馏经验
1. “废人父亲复仇”的核心情感链；2. 祖符作为世界规则唯一核心权限的设计；3. 女主逆向献祭拯救世界的感人情节。

### 16. 不应复刻内容
祖符发光的视觉逻辑、林琅天这一专属敌人的具体名字。
