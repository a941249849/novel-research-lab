泥灯巷外沿的安置屋前，冻裂的泥缝正渗出惨白霜气。迁籍附条虽已失去效力，原债却没有少去半分，灯芯仍在裂灯期限的最后一格里细细发抖。苏晚站在檐下深重的阴影里，左手平端着属于她的命灯。粗陶灯腹上的裂纹自底座蜿蜒到灯口，冷风每钻过一次，火苗便向裂缝伏低。她右手掌背的红点已经崩成一道无法愈合的创口，没有鲜血，只有暗冷微光沿着指缝拉出细丝，滴在地上结成小小冰坑。失温顺着右臂往肩头爬，却没有影响她左手托灯的姿势。

命籍衙不能再借那张附条把苏晚连人带档迁走，却仍可凭有效的原债申请在原地追缴。此刻没有寿火被抽走，更谈不上返还；命灯上的裂损、掌背的失温和未清的债额都原样压在她身上。巷口正在渗出的黑字，正是那份原地执行申请获得受理后的回声。

巷口青砖地上，黑色的字迹正从冰冻的泥水缝隙里逐步渗透出来。那不是官差的脚步，而是命籍衙那纸“原地执行申请”在规则默许下化作的实体。这些黑字黏稠得如同融化的陈年墨锭，逐步碾过青石板上的积水，水面在触及笔画的瞬间便凝结成漆黑的硬冰，发出刺耳的冻结声。字迹最前端的笔画锋利如刚出炉的刀刃，抵在泥灯巷护阵的外沿。无声的挤压下，由各户人家命火气机牵引的护阵被逼出一道贯穿整堵矮墙的白裂。安置屋粗糙的墙面发出不堪重负的喀嚓悲鸣，大片发黄的泥灰簌簌掉落，原本亮着的阵纹迅速发黑、剥落。沿街的各户人家都没有睡，他们各自抱着命灯站在门内，门扇半开半掩，只照亮他们惊恐疲惫的眼睛。

“它要进来了。”住在最外侧的顾家男人压低声音，系在灯盏底座上的粗麻灯绳深深勒进指掌，指节被勒得泛出死人般的惨白。他盯着墙面上向内扩大的白裂，牙齿止不住地打颤。“原地执行……它今天若是不把人带走，就一定会在巷子里把这笔账算清。”
墙角泥灰加速脱落，白裂缝隙里刀刮般的寒气倒灌进巷子，吹得几户人家门板摇摇欲坠。另一个端着油泥灯的妇人退了半步，身后的影子在冷风中拉扯得剧烈晃动，声音带了哭腔：“昨晚守墙，才刚断了三处灯位，墙骨本就是强撑着。若这道裂口被冲开，外沿这排屋子就彻底废了！到时候连个遮风的地方都没有，我们的灯还怎么点？”

妇人没有直接伸手指苏晚，只是将手中的灯往怀里更深处缩了缩，侧过身去，用肩膀挡住了大半个门缝。但那充满畏缩与生存本能的目光，却刀子一样落在苏晚身上。
泥灯巷内原本就脆弱的默契，在绝对的暴力与致命的寒冷面前，瞬间被剥离。几户站在最外侧、正对着那道白裂的人家，不约而同地作出了选择。他们没有高声叫嚷，更没有动手去推搡苏晚，只是默默地将攀附在墙角上的气机收回。
顾家男人深深吸了一口气，将缠绕在自己右手手腕上的灯绳一圈圈解开，收回了灯盏里。随着那一根被汗水和油垢浸得发黑的绳子落回灯腹，他家门框上闪烁的一缕微弱火光悄然熄灭。他向后退了一步，将身体藏进了门板后面的阴影里。紧接着，那扇陈旧的木门在木轴艰涩的摩擦声中，缓缓合拢。

这像是一个无声的信号。旁边的妇人也跟着低下了头，她甚至没有再看苏晚一眼，只是用冻得红肿的双手将油泥灯紧紧捂在怀里，倒退着进了屋，拉上门扇。原本由数户人家合力撑起的外沿守位瞬间空出了一大片。
护阵上那道白裂失去气机牵引，发出一声沉闷的爆裂声，缝隙瞬间固定，向两边撕开一个难以弥补的豁口。冷风夹杂着冰渣长驱直入，吹得留在原地的赵老头手里的火苗剧烈摇晃。
赵老头站在自家檐下，看着那些正在缓缓拉上的门扉，眼角剧烈抽搐。他攥紧了拳头，隔着虚掩的木门，声音低沉而嘶哑地吐出一口唾沫：“糊涂啊……今天咱们能因为怕冷，把护阵的口子让出来，明天衙门要是换个名目来收税，咱们是不是连这门都别开了？不交人是底线，可你们把路让得这么干净，和把人送过去有什么分别？”

没有人回应他。只有几声沉重的门轴转动声，在死寂的夜空里显得格外清晰。又有两户人家的灯绳被默默收起，原本挂在土墙上的铁钩空荡荡地悬在冷风中，发出叮当的撞击声。

靠近水井的那户人家没有立刻关门。门内的年轻人扶着一截已经开裂的墙梁，老人则把灯护在胸前，两个人低声争了几句。最终，年轻人先松开墙梁上的副绳，却把门槛前的一块碎砖踢到路边，给苏晚留下可以站稳的地方。他们没有继续守阵，也未把她推出巷子，只把自身能够承担的部分划到这里为止。

更深处的一扇门后传来孩子的咳声。那家的灯绳收得最快，木栓落下时甚至带着慌乱。苏晚听见了，没有回头责问。她把左臂往怀里收紧，让命灯尽量避开从墙裂灌入的风。每一户关门都有自己的代价，也有自己的拒绝；她没有权利用母债替他们规定哪一种选择才算勇敢。
在此过程中，并无一户的命火被调用、转移或扣减，依然由各户持有。泥灯巷在这冰冷的冬夜里，第一次以这种近乎剥离伪饰的方式，画出了不代债、不交人、允许各户撤守的边界。

陆沉渊沿着黑字的去向逐门看过去。那些字没有钻入门缝，也未攀上被收回的灯绳，说明原地执行申请接受了住户退出共同守御，却没有得到向第三人摊派债额的权限。这不是胜利，只是把即将落下的力收窄到一个具名目标。越是收窄，苏晚手中那盏灯承受的压力便越清楚。
没有大义凛然的对峙，没有同仇敌忾的口号。这里的每个人都太冷、太饿了，他们自顾不暇。不替旁人认账是天理，不主动把街坊送去命籍衙是最后的良心，而当危险真正压倒墙头时，退回自家的门槛后面，交出共同的防线以求自保，是他们唯一能做出的本能挣扎。那些紧闭的门扉，不是对同胞的背叛，而是这片冻土上最真实、最寒冷也最沉重的活命方式。

苏晚静静看着这一切。她看着那些渐渐隐没在黑暗中的门扇，看着那些收回的灯绳。她右手掌背的裂口还在缓缓拉丝，那股寒意和债务都是她自己的，她从来就没有打算过让这街上的任何人替她承担一分一毫。她用左手端着那盏带裂纹的命灯，迈出一步，走出了屋檐的阴影。
陆沉渊站在她身后半步，脸色苍白得近乎透明。他右手袖口下代表识账权限的暗色丝线已经深深勒进了皮肉，在手腕上绞出一道道暗红的血痕。他看着苏晚的背影，没有说话，只是握着账册的手在微微颤抖。
苏晚没有回头，她只是微微侧了侧首，声音很轻，却字字清晰地落在这空旷的巷道里：“赵叔，关门吧。收了灯绳，留出路来。”
赵老头愣了一下，那双浑浊的眼睛里闪过一丝复杂的痛苦。他看着苏晚手背上滴落的冷光，又看了看自己手里那盏快要燃尽的命灯，终究是长长地叹了一口气。他转过身，将自家门楣上的那根粗糙的麻绳解了下来，卷成一团塞进怀里。随后，他推上门扇，伴随着“吱呀”一声，木栓扣上的闷响在夜色中散开。
至此，外沿的所有人家，已经全部撤守。

原本用来抵御外侮的护阵，此时彻底暗淡下去，碎裂的砖石散落在冻土上，再无半分灵光。一条宽敞、冰冷而毫无阻拦的通路，在泥灯巷的青砖地上铺展开来。
陆沉渊没有再开识账。他站在母亲身后半步，只看黑字沿着各户主动让出的空位向前推进。每经过一扇紧闭的门，字锋都会停顿一瞬，确认门内命灯仍归原主，随后绕开。没有一根灯绳被强行扯走，也未一个名字被并进苏晚的债里。住户付出的，是放弃共同外沿后的寒风和墙裂；苏晚承担的，则是黑字最终只朝她一人聚拢的全部压力。

冷风倒灌，吹得苏晚的长发掠过面颊。寒气沿着命灯木柄爬上她的左臂，她便把手肘更稳地贴近腰侧。右手掌背的伤口被风吹得重新开裂，她没有拿这只手去碰灯，只任冷光顺着垂下的指尖滴落。灯芯在黑字的逼近中伏得更低，却仍并无寿火被抽出。

陆沉渊把脚下松动的碎砖踢开，为母亲让出半步平地，随即退回见证位置。他没有碰灯，也未替她挡住黑字。苏晚只借那块平地重新站稳，左手仍独自托着灯座，目光越过儿子肩头，看向巷口最后一道尚未闭合的门。

那一封“原地执行申请”化作的黑色字迹，在此时终于完成了所有的变异。在最后一户街坊关上大门的刹那，这些黑字得到了来自命籍衙深处某个规则节点的最终获准。
它们不再是地表蠕动的墨迹。
那些由墨锭般的黑冰凝聚而成的字符，在这一瞬间轰然暴涨，化作一道道如钢针、如铁棘般的黑色流影。它们越过了那些已经紧闭的木门，越过了门缝后那些藏在黑暗中的惊恐眼睛，也绕过了双眼流血、身形战栗的陆沉渊。
它们的目标极度单一，甚至带着一种死板的、毫无温度的精确。
这些获准执行的黑字越过荒凉巷口和所有撤守留下的空位，在空气中拉出刺耳破空声。在距离苏晚脚尖仅剩半寸的青砖地上，所有字迹猛地昂起，化作密集黑色铁刺，锁定她左手中那盏孤零零的、带着裂纹的命灯。
