石台尽头，黑槽嵌在银灰印屑之间，像一道沉默多年的裂口。细屑悬在槽沿半寸处，不升不落，将四周照得惨白。灰白影门封住后方，石台边缘的冷线则横在退路上，外层没有风，也没有别的声音，只有某种尚未落档的手续悬而未决。

陆沉渊半跪在石台前，右臂早已失能，沉沉垂在身侧。他用左手压住胸前的旧布裹物，隔着硬结的布面，仍能感觉到残印清晰的轮廓。

闻照微站在黑槽另一侧。她的身影比先前更淡，衣袂边缘几乎融进影门。她抬起半透明的手，掌心朝上，数缕由外层条例化出的影光在指间游动。

“把它放进来。”她说，“外层收回候验锁纹，你便可以回城。今日之事到此为止。”

陆沉渊看向她：“收回锁纹，还是收回残印？”

“同一条手续。交出持有，候验终止。”

“那是州府写成了一条。”陆沉渊道，“回收持有与终止候验，本是两笔账。东西一旦进槽，残印归回收，底档也随退档抹去，最后只留下我自愿交还的记录。”

闻照微指间的影光微微一顿。黑槽深处传来纸页摩擦般的细响，石台边缘的冷线随即亮起。

“你已经过了校时。再拖下去，候验转为逾候。外层只会认定异物未归，追缴可以越过门界，落到一切与残印有关的人身上。”

“所以我要把核验和回收分开。”陆沉渊左手未松，“既然它能被送到我手里，就该先核送出端。你们可以主张回收，我也可以保留持有，但不能借一次交还，把它从何处送出、为何送出一并抹掉。”

悬在槽沿的银灰印屑缓缓下沉，又在触及黑暗之前停住。闻照微身后的影门浮出数道交错细线，像等待落款的空档，却没有一条通往门后。

“你要立原始转运交接？”她问。

“是。”

“原始交接一旦接入，候验锁纹会改为原始交接锁纹。你将失去自行退出外层的资格。此后每一次复核，你都必须到场，直到送出端验明、接收端响应，或你的持有资格先行断开。”

“资格断开之后呢？”

“外层判定持有者失能，启动强制回收。你留在门内，所持之物也不再由你处置。”

陆沉渊抬眼望着她：“苏晚的名字如何记？”

“已经分列，不并入你的到案记录。”

“泥灯巷住户呢？”

“现有外层记录中没有他们。只要交接申请不追加旁人因果，外层无权以此案追溯。”

“把这一点写进前置申明。”陆沉渊道，“核验只及残印、我的行迹与我的锁纹。苏晚不并案，泥灯巷住户不追加。此后若槽口索要旁人记录，也由我拒绝，停档与追责都落在我身上，不得转开。”

闻照微没有立刻宣读。她抬手，将指间游动的影光分作三缕。第一缕停在陆沉渊姓名之前，第二缕绕过苏晚的分列空栏，第三缕沿着泥灯巷住户本该被牵出的数道暗痕逐一掠过。

“原始交接的前置申明，不是口头限定。”她说，“一旦锁纹受理，外层会用既有牵连补全空项。苏晚虽已分列，仍可能被以共同到案、共同知情、共同接触三项并入；泥灯巷住户虽无姓名，也可能被按居处、见闻、留置之物三类索引唤出。你要排除，就要逐条排除。”

她指尖微动，第一缕影光先落到苏晚的空栏上方。栏内随即浮出三行细字，尚未凝实，便已向陆沉渊的记录伸出细线。

“苏晚既有分列，非共同持有者。”闻照微道，“是否排除共同到案？”

“排除。”

细线断去一根。

“是否排除共同知情？”

“排除。”

第二根细线熄灭。

“是否排除共同接触？”

“排除。”

最后一根也缩回空栏。苏晚的名字没有消失，只是被一层极薄的界线隔开，界线旁添出“既有分列，不得以本申请重开并案”的小字。

第二缕影光转向泥灯巷方向。影门内先后亮起数十点黯淡微芒，每一点都没有姓名，只以门牌、灯位、井沿、檐角和夜巡时刻作临时标识。它们相互牵连，像一张尚未展开的名单。

“居处索引。”闻照微说，“是否追加同巷住户？”

“不追加。”

“见闻索引。是否索要目击、留宿、传话与指认条目？”

“不索要。”

“留置索引。是否将巷内器物、门锁、灯盏与痕迹归入本案？”

“不归入。”

每答一项，影光便在对应索引前落下一道斜封。那些微芒没有被抹去，只从本次交接的边缘退开，重新沉入影门深处。闻照微又将第三缕影光依次停在“追缴”“复核”“逾候”三项旁。

“若外层日后以手续未尽为由重启索引，是否仍以此次申明为界？”

“仍以此次申明为界。”

“若索引因此无法闭合，是否由持有者承担停档？”

“由我承担。”

“若外层以追责名义转开边界，是否准许转向苏晚与泥灯巷？”

“不准。”

影门内传来一声极轻的鸣响，仿佛远处的账板被扣了一记。几道游移的细线随之折转，绕过原本向外延伸的分支，只余一线垂向陆沉渊。

闻照微垂下手：“外层只认记录，不认你想护住谁。你可以限定这次申请，却不能替未来所有复核定规矩。”

“我不替未来定规矩，也不替旁人许诺。”陆沉渊道，“我只认领自己的持有、自己的到案和自己的拒绝。槽口要追加名字，我便拒绝；因此停下的手续记在我名下。若最后强制回收，也只从我这里回收。”

黑槽内又响了一声。

闻照微转向悬浮的银灰印屑，逐条复诵：“持有者陆沉渊申请原始转运交接复核。申请不以解除持有为前置。苏晚既有记录分列，不并入本次到案。泥灯巷住户无记录，不追加。若后续核验索取旁人条目，持有者有权拒绝；拒绝所致停档、逾候及追责，均不得转嫁。”

每念一句，影门上的细线便收拢一分。最后一字落下，所有向外分岔的痕迹尽数熄灭，只剩一道狭长暗线悬在黑槽与陆沉渊之间。

闻照微没有让那暗线立即入档。她以引档人的手势，将先前落下的三道斜封一一提起核对。苏晚栏上的界线、泥灯巷三类索引的封记、追缴与复核后的拒绝归属，依次映在她掌前。她先看申明是否与口述相合，再看每一项封记是否只截断本案的牵连，而未改动原有记录，最后才将它们按原来的次序压回影门。

“苏晚分列仍在，未被撤销，也未被并案。”她道，“泥灯巷住户无新增名录，无代称，无补录因果。你的拒绝只绑定本次原始交接，不越过既有档案。程序记录由引档位留存，后续若有人改动封记，锁纹会先比对这一份。”

她将掌心覆向黑槽上方，指间影光化作四枚极小的暗印，分别落在申明首尾、苏晚分列、泥灯巷封记与拒绝归属之后。四枚暗印彼此不相连，却都向同一处回照。

“前置申明核对完毕。”闻照微说，“记录时间、见证人、持有者答复、封记次序，均已留档。现在落明双方责任。”

“双方责任也要落明。”陆沉渊说。

闻照微看了他一眼：“你承担持有、到场、候验与拒绝追加后的全部后果。外层承担封存交接原档、维持回收与核验分列、先行核验送出端，并在接收端出现响应后如实转录。见证人不得代你交出残印，也不得擅自将申请改记为退档。”

“闻照微的责任呢？”

“我以外层引档人身份见证此次交接，确认残印未入回收槽，确认申请由你本人提出，确认锁纹生成前的前置申明已经落档。此后若原档与今日记录不符，由我的引档资格承担追索。”

陆沉渊将胸前裹物向石台推近半寸，却仍留在槽沿之外。银灰印屑立刻颤动，拉成无数纤细光线，贴着旧布边缘游走，确认其中响应，却没有穿透封布。

闻照微收回掌心原本用于回收的引线：“残印不交出，只准封布外的响应入槽。原始交接由你提出，外层见证。锁纹一旦接受，申请立即成立，不能再改回普通候验。”

陆沉渊直起身，左手稳稳护住裹物：“落档。”

石台边缘的冷线倏然越过他的脚边，在黑槽前合成一圈封闭的银白纹路。闻照微抬指点向槽口，声音转为逐字宣读旧档般的平直。

“报明身份与申请。”

“陆沉渊，持印候验。申请原始转运交接复核。”

黑槽上方的印屑骤然旋转，形成一枚灰色漩涡。吸力牵动旧布，陆沉渊按住裹物，未使它越过槽沿。

“是否以解除持有为前置？”

“否。”

“是否追加苏晚及泥灯巷住户记录？”

“否。”

“是否确认持有、到场与拒绝追加之责归于自身，不向旁人转开？”

“确认。”

“是否确认外层封存原档，分列回收与核验，先核送出端；引档人闻照微承担见证与转录之责？”

“确认。”

“是否接受原始交接锁纹，放弃自行退出外层入口之权？”

陆沉渊看着漩涡深处。那里没有门，没有归路，只有一份等待承接的黑暗。他开口，声音清晰地穿过石台。

“接受。”

银灰印屑齐齐定在半空。

下一刻，黑槽边缘的石纹尽数亮起。银白冷光沿石台铺开，封布外那一点微弱响应被抽成一缕细线，投入槽中。残印本体仍留在陆沉渊胸前，悬浮的印屑绕过旧布，确认边界与持有者身份，随即汇成数道冷线，越过石沿，缠上他的右腕。

锁纹一圈圈扣合，与先前候验留下的痕迹严丝合缝。每完成一环，黑槽深处便传来一声低沉的闭锁声。冷线最终收束成一枚狭长深暗的纹印，牢牢贴进皮肉，不向门内牵引，也不准持有者退离。

影门上的杂线同时开始重组。

最先显出的，是陆沉渊的姓名与持有状态。其下依次落出原始转运交接申请、残印未交回、回收与核验分列、旁人记录不追加。再往下，两列细字分立左右。

一列归于持有者：保存残印，依令到场，承担候验；拒绝旁人追加时，停档与追责止于己身。

一列归于外层与见证人：封存原档，不以回收代替核验；先查送出端，再候接收端；闻照微确认申请真实、边界未越、前置申明完整，承担引档转录之责。

最后一道细线落下，贯穿两列记录，在末端结成封口。原始交接至此成立。

封口闭合的瞬间，黑槽底部原本静止的刻度逐级亮起。最外一圈标着持有者确认，中间一圈标着原档封存，最深处那圈没有文字，只有一道朝门后延伸的细缝。前两圈依次暗下，像已完成的步骤被压入底档；最深处的细缝却被锁纹牵出一线幽光。

闻照微抬眼望向那道光：“送出端刻度已启动。它不会替你查明任何事，只会把今日封存的边界、残印响应和原始转运申请送往最初的出档位。送出端若仍存原记录，刻度会回显其编号；若有人先一步改写过原档，刻度会停在改写处，外层不得越过它转候接收端。”

黑槽中的幽光没有冲向影门，而是沿着已重组的档线缓慢推进。每越过一处申明封记，便有一粒印屑短暂亮起，像在逐项比对送出的内容。苏晚分列处没有响应，泥灯巷住户的索引也始终沉寂，唯有陆沉渊的姓名、持有状态与残印边界被刻度反复照明。

闻照微的影手掠过锁纹上方，没有触碰，只作最后一次确认。

“原始交接已立。残印仍由你持有，争议也随你保留。外层入口自此封闭，你不能自行离开。送出端未验明之前，接收端即使出现波动，也不得越序记档。”

陆沉渊以左手撑住石台，缓缓坐直，将旧布裹物重新按回胸前。锁纹的冷光沿腕骨明灭，与黑槽中的微光遥相呼应。灰白影门依旧紧闭，却不再是一片无序的墙；方才重组的档线已经没入门缝，向更深处传递。

闻照微的身形渐渐散开，只余声音停在黑槽另一端：“我会随原档进入引档位。下一次外层唤你，不会再询问是否交接，只会复核已经成立的条目。若有人试图追加旁人、合并回收，或改写持有状态，锁纹会先行示警。”

她的影子彻底融入门壁。黑槽随之沉寂，槽沿悬浮的印屑一粒粒归位，在空中排成整齐而冷硬的档序。

陆沉渊独自坐在石台前。右腕上的锁纹将他钉在外层，胸前的残印则隔着封布发出极微弱的震动。那震动被黑槽捕获，记入交接，却没有被夺走。门后有一道遥远的回响刚刚升起，便被外层截停，压在尚未验明的送出记录之后。

灰白门壁中央，一行幽蓝冷字缓缓浮现，越过所有既成条目，悬在黑槽上方。

先验送出端，再候接收响应。
