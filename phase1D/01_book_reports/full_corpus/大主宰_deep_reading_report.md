# 《大主宰》深读剖析报告

- batch: 1
- evaluator: Agent
- verified_against_schema: yes

### 1. 主角初始处境
牧尘，北灵境牧域少主，曾因在试炼地灵路中大开杀戒，被定性为“灵路血祸者”强行驱逐。

### 2. 核心欲望
洗刷灵路驱逐的污名 -> 寻找洛璃变强 -> 营救被浮屠古族囚禁的母亲 -> 封印天邪神，守护大千世界。

### 3. 成长路径
感应、神魄、三天境、至尊、地至尊、天至尊、主宰境。副职为“灵阵师”。

### 4. 爽点释放机制
“至尊法身爆发与血祸者威名”。主角身怀灵路血祸者的凶威。在学院大赛中以看似落后的至尊境界，召唤九龙法身配合灵阵突发逆袭，打碎敌手压制。

### 5. 地图推进方式
北灵院 -> 五大院 -> 大罗天域（大陆争霸） -> 浮屠古族（救母决战） -> 大千世界与邪族边界（终局）。

### 6. 资源竞争结构
核心资源为至尊法身排行、万古不败材料、古族血脉真血。

### 7. 阶层压迫结构
上古浮屠古族对普通人类血脉的无情禁锢，域外邪族对大千世界的吞噬污染。

### 8. 组织 / 阵营关系
五大院与洛神族（温情共同体），对立面是浮屠古族保守派、天邪神。

### 9. 世界观扩张方式
北灵境只是大千世界一角 -> 大罗天域只是千百天域的一格 -> 完结点将前作主线并网，构建大千世界终极法典。

### 10. 情绪主轴
少年进取、宿命守护与文明博弈。

### 11. 写作手法
商业升级模板圆润，爽点周转速率快；法身斗法极具画面华丽感；完美的并网联动策略。

### 12. 叙事节奏
“灵阵挑战 -> 秘境突破 -> 遭遇古族打压 -> 法身逆袭战胜对手 -> 下一大陆天域”。

### 13. 读者长期追更机制
牧尘何时救母、洛璃何时重聚、前作主角何时联袂客串。

### 14. 二次传播生命力
三作合流的终极重聚情怀，在书迷群体中具有长线讨论度。

### 15. 可蒸馏经验
1. “灵路血祸者”的禁忌杀戮前置身份；2. 学院向宏大世界过渡的平滑跳板设计；3. 共享世界观并网策略。

### 16. 不应复刻内容
浮屠塔的设定外观、具体人物名字客串。
