> 此文件记录早期 8 卷、卷一 60 章方案，不能再作为正文、授权或发布依据。
> 当前唯一生产事实源为 `system/production_runtime/plans/borrowed_heaven_longform_contract.v0.1.json`、`system/production_runtime/plans/borrowed_heaven_first100_manifest.v0.1.json` 和 `system/production_runtime/plans/borrowed_heaven_volume1_production_manifest.v0.25.json`：18 卷、1,800 章、600–680 万中文字符，卷一固定 100 章。

## 定位与规模

- 目标：原创东方玄幻长篇，不模仿语料作品的名称、桥段、语言风格或能力体系。
- 预计总规模：8 卷，480-560 章，约 160-210 万中文字符。
- 单章目标：2800-3800 中文字符；冲突或卷末章可上浮至 4200，禁止用字数填充。
- 稳定节奏：每 3 章完成一个局部问题推进；每 8-12 章完成一次可验证的小反转；每卷完成一次公开或共同体层面的成果，并以更高法权压力收束。

## 正文恢复门禁

以下条件必须全部满足，才可重新创建任何正文 Chapter Intent：

1. 八卷路线与卷一 60 章节奏表经 Owner 审阅确认；卷二至卷八只保持卷级边界，不生成正文级细纲。
2. 卷一 60 个非正文 Chapter Intent 全部通过 Schema、资产选择与禁止项验证。
3. 所有可写状态账本都有明确初值、允许变化、最小证据和跨账事务同伴；禁止由审查意见补填未经观察的数值。
4. 对 60 个 Intent 完成无正文 Dry Run：上下文编译、资产依赖、状态事务、章节顺序和禁止资产扫描全部通过。
5. Hermes 与 Antigravity 各完成 10 次无正文 canary：超时、空输出、stderr JSON、非 JSON 输出、模型回退均有可验证结果。
6. `production-preflight`、全量测试、资产验证、状态验证和 Studio 快照全部通过。
7. Owner 单独授权“卷一 Cluster 1 的正文试生产”。授权仅覆盖 Cluster 1，不自动延展至 Cluster 2。

## 正文试生产策略

- 首次正文试生产不是三章，而是 Cluster 1 内的 10 章受控批次。
- 每章仍独立经历：Intent → Context → Hermes → Observation → Antigravity → Revision → Settlement → Acceptance。
- 第 5 章和第 10 章额外进行卷内节奏审查；任一章出现阻塞问题，停止批次并回到无正文修复。
- 章节之间不得复用过期 Owner Gate、不得写入未观察事实、不得将审查建议当作状态变化。
