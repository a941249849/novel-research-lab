# Phase 2A Entry Plan

## 1. Phase 2A Goal

Phase 2A planning prepares the controlled path from the accepted Core7 mechanism library toward an original long-form design prototype.

This entry plan does not authorize prose writing. It defines planning inputs, expected planning outputs, tool roles, red lines, and acceptance criteria.

## 2. Phase 2A Inputs

Allowed input classes:

- accepted Phase 1 owner package
- Core7 formal BookDNA / NarrativeDNA / StateLedger assets
- Core7 mechanism inventory
- Core7 category manifest
- cross-book feature notes
- Phase 1 validation and review reports
- system master specification

Detailed input list:

- `phase2/00_entry/phase2A_input_assets.md`

## 3. Phase 2A Output Assets

Planning-stage outputs may include:

- Phase 2A planning review report
- original design requirements brief
- mechanism selection matrix
- originality transformation plan
- world-rule planning outline
- state-ledger planning outline
- audit checklist for later creative generation

Phase 2A planning outputs must not include:

- novel prose
- chapter drafts
- dialogue
- scene expansions
- imitation of source plots

## 4. Tool Division

Tool roles are defined in:

- `phase2/00_entry/phase2A_tool_roles.md`

Summary:

- Codex handles filesystem structure, validation, indexing, reports, and Drive sync.
- Antigravity reviews Phase 2A planning direction and originality constraints.
- Hermes may later produce controlled original-setting candidates only under approved prompts.
- Owner / ChatGPT makes direction decisions and stage approvals.

## 5. Prohibited Actions

Red lines are defined in:

- `phase2/00_entry/phase2A_red_lines.md`

Key prohibitions:

- no original prose generation
- no first chapter drafting
- no Hermes free writing
- no 18-book full extraction
- no source-name reuse
- no source-plot imitation
- no model training or commercial publication step

## 6. Acceptance Criteria

Phase 2A planning entry is acceptable when:

- Phase 1C acceptance record exists.
- Phase 2A input assets are explicitly listed.
- tool roles are defined.
- red lines are defined.
- no Phase 1 formal asset is modified.
- no novel prose is generated.
- no Hermes call is made.
- Antigravity can review the planning pack.

## 7. Next Gate

Next gate:

- Antigravity Planning Review

This gate reviews whether the Phase 2A planning boundary is safe, coherent, and aligned with the accepted Phase 1 mechanism library.
