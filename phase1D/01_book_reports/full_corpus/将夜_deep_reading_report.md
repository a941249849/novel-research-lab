# 《将夜》深读剖析报告

- batch: 1
- evaluator: Agent
- verified_against_schema: yes

### 1. 主角初始处境
宁缺，边军砍柴人，带着捡来的侍女桑桑。气海雪山不通判定无法修行，面临为将军府灭门血案复仇的必死局。

### 2. 核心欲望
打通气海修行 -> 考入书院二层楼 -> 狙杀灭门仇人 -> 守护桑桑对抗昊天永夜规则。

### 3. 成长路径
初识、感知、不惑、洞玄、知命、无距。副职为“符师”。

### 4. 爽点释放机制
“大唐十三先生的红尘反杀”。宁缺为人冷静阴险。爽点在于他在长安城春风亭雨夜，手持朴刀越阶斩杀军部修行强者，并在书院二层楼考核中力压群雄登顶，兑现身份。

### 5. 地图推进方式
梳碧湖 -> 长安城（书院复仇） -> 荒原（探秘） -> 烂柯寺 -> 举世伐唐 -> 斩天战。

### 6. 资源竞争结构
核心资源为天地元气、大黑伞、浩然气。

### 7. 阶层压迫结构
西陵神殿以昊天永夜名义对人类进行的纪元收割与规则奴役。

### 8. 组织 / 阵营关系
书院后山（同门手足极温情共同体，最强靠山），对立面是西陵神殿、昊天化身。

### 9. 世界观扩张方式
长安城外是天下神殿的版图 -> 永夜冥王是昊天的圈套 -> 昊天化身为凡人桑桑，规则开始被人性磨损。

### 10. 情绪主轴
市井人烟气、大唐书院不羁傲骨与反抗昊天法则。

### 11. 写作手法
将吃面、砍柴等红尘烟火气与修行结合，极其雅致细腻；战斗充满力量与诗意；配角群像极为出彩。

### 12. 叙事节奏
“市井生活与复仇准备 -> 春风亭决战突发爆发 -> 书院扬名 -> 举世伐唐的爱国狂澜”。

### 13. 读者长期追更机制
宁缺何时入二层楼、宣威将军府幕后主使是谁、桑桑的昊天身份何时觉醒。

### 14. 二次传播生命力
春风亭雨夜一战的江湖豪迈、夫子登天的名场面在读者中被奉为网络文学文艺巅峰之一。

### 15. 可蒸馏经验
1. 世俗日常描写与玄幻境界的极佳融合；2. 骄傲师门共同体（书院）的人格化设计；3. 天道规则化为婢女被人类感情磨损反制的逻辑。

### 16. 不应复刻内容
大黑伞的具体视觉外观、春风亭这一具体空间名称。
