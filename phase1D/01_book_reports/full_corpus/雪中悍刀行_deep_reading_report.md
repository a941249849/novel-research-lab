# 《雪中悍刀行》深读剖析报告

- batch: 1
- evaluator: Agent
- verified_against_schema: yes

### 1. 主角初始处境
徐凤年，北凉世子。因父亲徐骁手握三十万铁骑，主角面临朝廷无休止的杀机与猜忌，被迫扮演纨绔子弟自保，气海未通。

### 2. 核心欲望
游历江湖躲避联姻 -> 练刀继承北凉衣钵 -> 查清母亲死亡真相 -> 誓死镇守北凉关隘，阻击北莽，保护百姓。

### 3. 成长路径
一品四境：金刚、指玄、天象、陆地神仙、天人长生。

### 4. 爽点释放机制
“大凉铁骑与江湖老祖的骄傲兑现”。主角在老黄（剑九黄）、李淳罡等盖世老祖默默守护下低调游历。爽点在于朝廷刺客以为他是废物纨绔上门截杀时，老王出手一剑斩江；或主角在经历老黄死后毅然练刀，入陆地神仙境越阶杀敌，给读者带来极大的情感震荡。

### 5. 地图推进方式
北凉 -> 第一次三年游历（江湖风雨） -> 第二次游历江湖（扬名） -> 太安城（朝堂博弈） -> 拒北关（死守）。

### 6. 资源竞争结构
核心资源为天下气运、武道真意、剑胎舍利。

### 7. 阶层压迫结构
离阳皇室与世家门阀对北凉三十万将士的无情排挤和猜忌，把北凉当作阻挡北方魔莽的盾牌。

### 8. 组织 / 阵营关系
北凉王府（三十万铁骑效忠、徐骁深沉的父爱）与北凉江湖，对立面是离阳皇室、北莽大军。

### 9. 世界观扩张方式
北凉只是一地藩王 -> 江湖是藏龙卧虎的万古大侠客场 -> 大离与北莽的天下逐鹿是人间气运的博弈 -> 天上仙人想垂钓人间气运，徐凤年斩断天上仙凡通道。

### 10. 情绪主轴
家国大义、江湖侠骨、人仙相别与知己零落的悲凉史诗。

### 11. 写作手法
将“庙堂博弈”与“写意江湖”完美糅合；极佳的配角群像塑造（剑九黄、李淳罡，每个配角都有独立史诗名场面）；行文充满古风雅致。

### 12. 叙事节奏
“世子纨绔日常 -> 老祖逝世/名师传功引爆主角决心 -> 苦练出阁杀敌 -> 接掌北凉 -> 拒北关悲壮防线”。

### 13. 读者长期追更机制
徐凤年何时真正练刀、李淳罡何时重回陆地神仙境、拒北关铁骑结局。

### 14. 二次传播生命力
“天不生我李淳罡”、“小二，给少爷上酒”等名句在社交网络广泛流传，北凉铁骑赴死的悲壮片段经常在贴吧引发讨论。

### 15. 可蒸馏经验
1. “门阀世子与隐秘刺杀”的朝堂江湖复合张力；2. 绝世守护者NPC的人格化传承机制；3. 拒守国门、斩断天人垂钓人间气运的壮烈主线。

### 16. 不应复刻内容
剑九黄烤地瓜等具象画面复刻、北凉拒北关这一专属称呼。
