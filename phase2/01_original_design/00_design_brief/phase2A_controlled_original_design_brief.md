# Phase 2A Controlled Original Design Brief

## 1. Current Phase 2A Goal

Phase 2A is currently authorized for planning only.

The immediate goal is to prepare a controlled design brief that can later guide Hermes toward original project candidates at the setting, mechanism, and structure level.

This brief does not authorize:

- original prose generation
- first chapter drafting
- scene expansion
- Hermes free creation
- 18-book full extraction

## 2. Original Design Task Boundary

Allowed design level:

- project premise
- genre direction
- reader promise
- mechanism selection
- mechanism combination logic
- world-rule candidate
- protagonist starting condition
- conflict engine
- power/growth system planning
- resource constraint planning
- state-ledger planning
- originality risk notes

Forbidden design level:

- prose
- first chapter
- dialogue
- scene-by-scene plot
- source-plot imitation
- source-style imitation
- original-work proper noun reuse

## 5. Mechanism Library Scope

The callable mechanism range is limited to:

- the 35 entries in `core7_mechanism_inventory.json`
- the 9 categories in `category_manifest.json`
- the cross-book abstraction notes in `cross_book_feature_notes.md`

The 11 remaining stub books are not mechanism sources for Phase 2A.

## 6. Mechanism Recipe Principle

The Core7 mechanism library must be used as a mechanism recipe system, not as a source-text patchwork library.

Allowed use:

- select mechanism IDs
- combine abstract narrative functions
- transform causal logic
- transform costs and tradeoffs
- transform social structure
- transform reader feedback effect
- map planned assets to BookDNA / NarrativeDNA / StateLedger

Forbidden use:

- copying source sequences
- copying source character paths
- copying proper nouns
- copying symbolic objects
- recombining recognizable source scenes
- preserving one original book's full structure under new names

## 7. Hermes Later Allowed Actions

If Owner later authorizes Hermes, Hermes may only produce original project candidates that are:

- setting-level
- mechanism-level
- structure-level
- non-prose
- non-chapter
- non-scene
- explicitly tied to selected mechanism IDs
- accompanied by originality risk notes

## 8. Hermes Later Prohibited Actions

Hermes must not:

- write prose
- write a first chapter
- write dialogue
- write scene descriptions
- imitate source style
- copy source plots
- use original proper nouns
- freely expand beyond the approved prompt
- read forbidden input assets
- use the 11 stub books as formal sources

## 9. Why This Stage Does Not Generate Prose

This stage does not generate prose because the project has not yet passed original-design review.

The safe sequence is:

1. Accept Phase 1 assets.
2. Prepare controlled Phase 2A design brief.
3. Review the design brief.
4. Generate only structured original project candidates under a controlled prompt.
5. Review originality and schema mapping.
6. Only later consider prose-stage authorization.

## 10. Required Owner Approval Before Hermes

Before Hermes can be invoked for original project candidates, Owner must approve:

- this design brief
- mechanism recipe selection policy
- original project option template
- Hermes controlled prompt draft
- Phase 2A design validation checklist

No Hermes execution is authorized by this file.
