# 《百工夜行录》全书设计 v0.3

> 状态：v0.3 已通过独立复审并初始化正式设计项目。Story Bible 与全书大纲树已落地，创作资产尚未生成，正文未授权。

## 一句话

五名普通维护者在城市退构灾害中追查一套把公共安全建立在无名承重者身上的旧制度，并用十二类真实劳动逻辑，重建一个允许拒绝、复核、替换和退出的文明维护体系。

## 为什么能够长写

长篇驱动力不是“每到一地解锁一种非遗技能”，而是四条持续加深的因果线：

1. 每次修复只能转移、隔离、转化或延期损伤，因此每卷成功都会生成下一卷必须处理的新债；
2. 周砺、程雪青、杜承礼、林岱和马小满各自拥有独立欲望、专业权限和不能替代的局限；
3. 恢复旧枢、现代替代、地方自治和彻底归零四种方案都能真实保护一部分人，也都会伤害另一部分人；
4. 一栋建筑逐步扩展到街区、城市、区域工谱、全国供应链、历史审计与文明退出制度，尺度变化必然改变规则。

## 规模

- 十五卷；
- 约 900 至 1080 章；
- 单章约 2600 至 3200 汉字；
- 目标总量约 260 万至 340 万汉字。

不预设六百万字。只有人物、制度和地域机制仍在产生不可逆变化时才扩容，禁止以重复案件、重复境界和地图打卡充字数。

## 文明机制母库

十二类工艺已经被编译为十二种操作机制：分载、热相提交、窑火不可逆、记录修复、分布式纹样记忆、角色授权、临时骨架、时间校准、风险隔舱、减材保护、材料转性和共享计量协议。

每种机制都绑定：

- 必需知识；
- 现实失效模式；
- 责任代价；
- 来源 ID；
- 禁止挪用边界。

## 当前门禁

下一步不是正文，也不是继续无边界搜集资料，而是独立审查以下问题：

- 十五卷是否存在重复案件和伪升级；
- 五人是否在每个阶段保有独立目标与否决权；
- 每卷引用的地域证据是否足够，缺口是否诚实阻断；
- 宗教、族群、医疗和知识所有权边界是否可执行；
- 第一卷能否在不灌输设定的情况下完成强情节、生活感和人物关系闭环。

审查通过后，才初始化正式项目、生成 Story Bible 与卷一资产；正文仍需单独授权。
