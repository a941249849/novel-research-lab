# 《仙逆》深读剖析报告

- batch: 1
- evaluator: Agent
- verified_against_schema: yes

### 1. 主角初始处境
王林，资质极差的凡人少年，因父母期望求仙却被逐出门派，捡到神秘天逆珠。家人后惨遭修仙家族灭门。

### 2. 核心欲望
报杀全家之仇 -> 复活爱人李慕婉 -> 踏天成仙掌控生死因果。

### 3. 成长路径
练气、筑基、结丹、元婴、化神（修意境，如生死意境）、问鼎、碎涅、空劫、踏天。副职为木雕雕刻。

### 4. 爽点释放机制
“铁血复仇与凡尘化境”。主角报仇不避手段，化身魔头将灭门仇家藤氏一族全数屠戮，将头颅累成京观。另一爽点在“化凡”阶段，以凡人雕刻店老板身份感悟生死，在众目睽睽下化神问鼎，给读者带来极度震撼的心境爽感。

### 5. 地图推进方式
赵国（修仙小国） -> 乱星之地（魔道发育） -> 联盟星域 -> 罗天星域 -> 太古神境（宇宙真相）。

### 6. 资源竞争结构
核心资源为天逆珠、仙元气、太古雷魂。

### 7. 阶层压迫结构
高阶修真国对低阶修真国的绝对附庸与压榨；古老世家（如藤家）对散修的无情欺凌。

### 8. 组织 / 阵营关系
除了李慕婉和极少数知己，仙途举世皆敌。

### 9. 世界观扩张方式
赵国只是偏远朱雀星的一角 -> 朱雀星只是低阶修真国星体 -> 联盟星域只是遗弃之地 -> 太古神境才是宇宙的大道战场。

### 10. 情绪主轴
坚毅、冷酷与在无情仙路中对爱人的极致深情。

### 11. 写作手法
开创了经典的修真“化凡”写法，将凡人生老病死与仙人超脱完美融合；战斗血腥残酷，杀伐极度果断。

### 12. 叙事节奏
“被压迫/被灭门逃亡 -> 天逆珠闭关修真 -> 极度冷血的清场复仇 -> 化凡感悟心境 -> 突破重构”。

### 13. 读者长期追更机制
王林何时屠灭藤家、李慕婉何时复活、化凡感悟如何实现。

### 14. 二次传播生命力
藤家灭门案是网文界“杀伐果断”的标志性事件，“化凡”段落被封为修仙小说的艺术巅峰。

### 15. 可蒸馏经验
1. 化凡意境修行的心境质感转化；2. 惨烈灭门仇恨极速结清的强烈爽感释放；3. 天逆珠时空流速不对称的复利修炼。

### 16. 不应复刻内容
天逆珠催熟金丹等直接法宝外观、藤氏京观的特定画面复刻。
