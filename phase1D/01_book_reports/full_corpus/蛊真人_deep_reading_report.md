# 《蛊真人》深读剖析报告

- batch: 1
- evaluator: Agent
- verified_against_schema: yes

### 1. 主角初始处境
方源，五百年记忆重生的老魔。开局仅为丙等下等资质，在青茅山古月山寨被族人冷眼对待，资产微薄，遭遇同胞弟弟的排挤。

### 2. 核心欲望
解开天意的宿命网络棋局 -> 摆脱寿元和死亡威胁，追求唯一的绝对“永生”。

### 3. 成长路径
一转至九转（蛊仙）。核心成长不靠资质灵根，而是利用重生信息差，捕捉、培育并合炼不同规则特性封装的蛊虫（如春秋蝉、酒虫、定仙游）。

### 4. 爽点释放机制
“反英雄绝对利己套利”。方源无传统道德束缚，在多方混战中利用人心漏洞和规则弱点，反手献祭盟友或大反派，以最小代价取得核心资产（如炼制仙蛊、抢夺福地）。

### 5. 地图推进方式
青茅山（新手微观博弈） -> 三王山与商朝城（商业与战术套利） -> 北原王庭（战局博弈） -> 中州与五域乱战（天下大争） -> 宿命大战（天尊博弈）。

### 6. 资源竞争结构
极度零和。天道运势守恒，仙蛊唯一，夺得规则所有权即可实行降维垄断，失败即当场死亡淘汰。

### 7. 阶层压迫结构
氏族宗门利用亲情与正道道德叙事实施资源垄断，天意通过宿命规约网罗世间一切生命。

### 8. 组织 / 阵营关系
不存在任何永恒组织与友情，所有人都是可交易或献祭的利益筹码；魔道以力量掠夺，正道以规则道德绑架利益。

### 9. 世界观扩张方式
凡俗五域只是被隔绝的沙盘 -> 蛊仙福地/洞天是更高的微观规则生态 -> 《人祖传》是整个世界历史与修行底层规则的元叙事互证。

### 10. 情绪主轴
绝对的功利、理智与永生的孤独求索。任凭天下皆敌、千刀万剐，方源毫无动摇。

### 11. 写作手法
将《人祖传》作为寓言小说嵌在正文中形成虚实交织；极其出色的阴谋与多方博弈描写，设定闭环且无降智反派。

### 12. 叙事节奏
“长线蛰伏、伪装扮演 -> 抓准漏洞、致命反击、灭族灭门 -> 立刻跑路飞升下一地图”。

### 13. 读者长期追更机制
春秋蝉何时重生回切先手、宿命蛊如何被摧毁、尊者博弈胜负。

### 14. 二次传播生命力
极度颠覆的反抗宿命意志、利己主义主角的极致理性、人祖传的哲学探讨。

### 15. 可蒸馏经验
1. 重生作为信息差回切的终局先手逻辑；2. 蛊虫作为“底层法则微型封装”的设计；3. 寓言元叙事与主线互证。

### 16. 不应复刻内容
突破底层人伦社会底线的具体桥段（如灭族等过度血腥行为）。
