午后的命籍衙前厅像被人从屋梁里抽走了热气。

回执案摆在正中，木面浮着一层细白霜。仇慎把上报的十张纸依次铺开，纸角仍留着泥灯巷三户分立的指印，封口、轮守、拒验、护阵裂口，各占一页，谁也没替谁补一句。最上方空着的回执位，却压了一张薄得透光的州府纸。

陆沉渊站在案外两步，右掌仍缠着昨日浸透后晾硬的旧布。布边贴住血口，稍一蜷指，里面便传来细碎的撕裂感。苏晚没有扶他，只把自己的袖口拢紧。她掌背的温度比厅里的木案还低，腕骨下那点暗冷光缩成细线，贴着皮肉一跳一跳。

莫井兰站在另一侧，手里没有带任何东西。仇慎早先问过她是否继续作证，她只答亲眼看过的可以再说，别的仍旧空着。于是她面前也没有预先写好的整页口述，只有昨日十张纸的页首抄目。

门外无风，案上的州府纸却自行鼓起。

先是左角，再是右角，像纸下有一口极冷的气缓慢吐出。仇慎僵硬的左手压住上报纸，右手停在回执边沿，指腹尚未碰到，纸面便响了一声。

极轻，像薄冰从里面裂开。

一线银灰自纸背渗出，沿回执位绕了半圈。厅内的命灯同时矮下一截，灯芯发青，灯油表面结出一层灰膜。苏晚的五指立刻扣紧袖中手腕。陆沉渊胸骨旧裂处跟着一沉，呼吸被截在喉间，掌心暗红线隔着布条勒紧，往腕内拖了半寸。

银灰没有合拢。

它在印环右下缺了一角，缺口窄而整齐，边缘却留着两道不相接的拖痕。其余印纹继续下压，冷金与灰白相杂，最后凝成州府转运残印。印落定时，木案底下传出一记闷响，霜色顺着案腿爬到地面。

仇慎的右手缩回袖边。

他盯着那处缺角，额角的汗没有落下，半途便冷成一颗浑浊的珠子。案边备着抄录纸。只须把回执正文逐行誊下，再以本地呈印确认"与原件相合"，州府纸便可折入封套。抄件上只记回执有印，不必描出缺角，更不会让前厅留下谁看见了两道拖痕。

他的左袖里传出一声硬物碰腕骨的轻响。

仇慎把抄录纸抽了出来。

莫井兰抬眼看他，没出声。苏晚也没有靠近，只将自己的站位往案外退了半步。那半步把选择留得很清楚：谁若要认完整，自己伸手，自己落印，不能借她们站在这里便算共同作证。

陆沉渊看着回执。右眼里的重影把银灰印分成两层，一层完整，一层缺角。他没有动用任何术法，只用左手按住右腕，让掌心别因痉挛碰上案沿。

仇慎铺平抄录纸，磨开的冷金印泥泛起薄光。他先抄日期，笔锋尚稳；抄到"复核本地封存案"时，左手忽然一僵，纸面被划出一道墨刺。

州府回执上的字随残印一行行显出。

"原封存对象，分项办理。"

仇慎停笔。

下一行先亮的是"异物封档"。残命灯盏的登记名紧随其后，封口、原圈、轮守次序仍按上报纸保留，却多了"不得由本地撤封、移档、销记"十二字。三户并未因此被写成献火人，也没有哪一盏住户命灯被列入调用；可从这一刻起，命籍衙先前宣布的暂停只剩看守之效，已无权把封存案自行收回。

再下一行亮起时，陆沉渊掌中的布条迅速洇黑。

"半寿送审。"

他的名字单列其下，限三日内到命审台。到场责任、血口核验、旧追缴存续，三项并记。纸上没有写苏晚，也没有莫井兰，更没有把三户轮守人列入半寿名册。可在"共同保管"四字后，留着一道尚未落定的灰线，正对着空白名位。

仇慎的笔尖悬在那道灰线上方。

他若按通常抄法，把异物封档与半寿送审合在一页，共同保管人便会顺着空位并入送审附件。那样最省事：物有人守，人随物核，三日内一并交出。州府问起，他只需说按回执合案执行。

莫井兰把面前的抄目往后推开。

纸底擦过霜面，发出沙哑的一声。

"我只见过交接。"她说，"没见过谁把命交给他。"

仇慎看向她："回执未问你肯不肯。"

"那就别把我昨日肯说的话，填进今日没问的空处。"

她的手背旧伤已经结痂，指节却因厅中失温泛白。说完，她退到门槛旁，既未离开，也不再碰案上任何纸。

苏晚把袖口松开一点，让腕骨下那线暗冷光露在灯下。

"我的灯也不并。"

仇慎的目光在她掌背停了一瞬。命灯裂纹并未合拢，那点暗光随呼吸往里收，像随时会沉进骨缝。若把她列作家属随审，送审纸会更齐整；她只须按下一个指印，陆沉渊的到场便多一道可扣的牵系。

苏晚却把手收回身侧。

苏晚把自己的寿债页从并列纸张中抽开半寸，单独压在掌下。

"先核这页。"她说。

陆沉渊松开左手。右掌布条下的血已经浸到腕口，冷下来后黏住皮肤。他向案前挪了一步，胸骨随之磨出一声低响。

"半寿送审，写我单独到场。"

仇慎没有落笔："异物由三户轮守，你要把人和物拆开，州府若追问谁保管——"

"照原页答。谁今日愿意继续守物，谁只守今日；谁退出，按原圈交还。她们没有答应陪审。"

"回执下的是合案。"

"回执写的是分项。"

陆沉渊抬起流血的右手，没有碰州府纸，只将指尖停在"异物封档"与"半寿送审"之间的空隙上。那空隙不足一指宽，却没有银灰线相连。

仇慎脸上的汗珠终于落下，砸在抄录纸边，晕开一个小黑点。

"你看清楚了？"

"肉眼看见两项。"陆沉渊的声音被胸口压得发哑，"再多的，我不认。"

仇慎盯着他泛黑的右眼。陆沉渊始终没有动用任何辨识手段——那只眼只映着灯芯的青光，焦纹未曾新生，寿印也就未被引得更深。

案上另一盏命灯忽然低了一寸。

州府残印开始收紧。银灰沿印环缓慢内缩，回执边缘卷起，像在催促本地落下接收印。仇慎若再拖，回执可能自行封定；届时命籍衙连分项抄录的余地都没有。

他把抄录纸折起，却没有收入封套。

随后，他用两指夹住州府原件上端，将整张回执竖在案前。缺角半印、两道断开的拖痕、分列的两项字样，都朝向厅内。

冷意从纸面直扑出来。莫井兰肩头一颤，却仍站在门槛内。苏晚的命灯暗光猛地缩向腕骨，她咬住牙，将手压在自己衣襟上，没有向陆沉渊伸出，也没有让他替她遮。

仇慎取出袖中的本地半印。

半印撞过腕骨的地方已经青紫。他将其按入冷金印泥时，左手僵得无法扶纸，只能用右腕硬压。金光沿指缝刺出，案上的霜顷刻化成冷水，又在纸边重新冻结。

"州府回执原件，当厅呈验。"

他说出这句话时，嗓音很轻。

"异物封档一项，沿用原圈封口与逐次自愿轮守，不并命火，不补全程见证。半寿送审一项，陆沉渊单独到场。旧追缴不撤。三日期限，自此印落定起计。"

本地半印压下。

冷金没有覆盖州府残印，而是落在原件下缘。仇慎左腕骤然一歪，印边擦过纸面，留下一道清楚的斜痕。厅内命灯尽数失色，灯焰只剩米粒大小。他的左手从腕到指尖僵住，半印脱手砸在案上。

州府残印却亮了起来。

缺角处没有被本地冷金补满。两道银灰拖痕一长一短，贴着斜落的本地印边显露出来。凡站在前厅的人都能看见：这份回执经过转运，印却残缺；仇慎仍选择以原件接收。

原件下端随即浮出一行新字。

"已呈原印，本地不得撤回。"

仇慎闭了一下眼。他保住了呈印资格，也把自己的越权痕迹留在原纸上。往后州府若查为什么暂停封存、为什么分开送审、为什么缺角未抄平，第一道问责会先落到他按歪的冷金印。

他没有再碰抄录纸，只把原件平放回案中。

陆沉渊伸出左手，在单独到场一栏按下指印。纸面冷得像铁，指腹一贴上去，掌心暗红线便猛然勒进腕内。右掌旧血口同时裂开，血沿布条滴落。他迅速把手移开，血滴砸在自己脚边，没有沾到回执，也没有落向莫井兰与苏晚。

胸骨里那道旧裂随呼吸错了一下。

陆沉渊弯下腰，牙关叩紧，喉底涌上来的不是血味，是一股干涩的铁锈气。他用左手撑住膝盖，指尖嵌进裤褶，视野里的灯影晃成数层。命审台三个字仍钉在纸上，银灰发冷。

苏晚没有碰他，只用鞋尖把案边矮凳拨到他膝后。凳脚刮过地面停稳，她便收回脚，掌背暗光仍缩在袖口下。

"站得住吗？"她问。

陆沉渊缓了两息："先站。"

仇慎将异物封档页与半寿送审页分开放置，各压一角，不再把空白共同保管位续上。他用尚能活动的右手写下接收时刻。每写一笔，左手便在案边轻颤一下。

门外忽然响起铁节相撞的声音。

一下。

又一下。

不急，却沿着地面把冷铁气味推进前厅。案上刚恢复些许的命灯再次向门外偏斜。陆沉渊掌心那条暗红线隔着湿透的布骤然绷直，像被远处某物试着核了一次。

仇慎抬头，脸色比霜纸更白。

州府回执旁，一道刚刚生出的细灰字缓慢定形：送审令已转追缴。

陆沉渊借矮凳稳住重心，把身子往旁边挪了半步，让自己的影子避开泥圈。苏晚已经退回寿债页旁，拇指压着那道分开的纸缝。圈内，残命灯盏封口发白，轮守纸角仍压得平整；护阵裂口里的两截暗红火痕隔着一线焦黑，时明时灭，谁也没有伸手去拨。

仇慎将十张纸重新分开，亲见的归亲见，拒验的归拒验。他蘸墨时停了一下，抬眼逐个问过去。有人按住自己的纸，没有撤回；也有人把纸往怀里收了半寸，只肯保留方才那一句。莫井兰照着原话复述，不替任何人添字。巷中静得只剩纸页摩擦声，像一层薄硬的皮，被每个人各自捏在手里。

陆沉渊胸骨又闷响了一下，血沿布边渗到指节。他望向残命灯盏，最终把手压回自己那页："不启灯，不补验，不替没看见的事作保。"

仇慎随即封住本地记录，将上报纸推到州府回执的空位前。印位仍白着，他没有催，也没有把"暂停"改成"撤销"。众人守着各自的纸退开一步，给下一道命令留下了地方。

巷口方向，铁节第三次合拢。

顾巡到了。
