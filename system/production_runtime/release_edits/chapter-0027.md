州府封档的冷意是从巷口压进来的。

先是灯焰齐齐矮了一截，接着墙缝里的湿泥泛白。那股冷没有风声，贴着地面爬，越过轮值桌，钻入三户共守的临街屋。屋内泥圈边缘很快结出一层薄霜，共同保管箱的铜扣发出细响，箱中残命灯盏仍旧冰冷，没有亮，也没有烟。

莫井兰刚把轮守纸压回箱角，脚底忽然一抖。

灯座先裂。

一道细缝从座脚钻出，擦过泥圈，沿墙根直奔屋基。墙内的暗红火痕被冷意逼得急缩，像一截烧到尽头的线。干灰簌簌落下，屋梁随即发出一声闷响。

"出去！"

她只来得及把靠门的人推出半步。左边墙面猛地内陷，斜梁压落，撞翻轮值桌。箱子被桌脚顶得滑向里墙，泥圈崩去一角。莫井兰扶着门框退出来时，肩头撞在砖楞上，整条手臂从肘弯一直酸到指尖。里面有人咳了一声，声音立刻被碎瓦砸断。

临街屋向巷中歪了半尺。歪出的那半尺把门楣拧成斜角，泥灰从裂开的檐下落成一道帘。

梁尾卡在裂开的灯座上，梁头压进内室。门洞被碎砖堵住，只剩一条能伸进手的缝。缝里先探出几根发白的手指，随即缩了回去。屋基还在往下沉，每沉一下，箱角便从乱木后露出一点。

"箱子就在那边。"有人指着右侧，"先拖出来，两个人就够。"

另一人跪在门边，把耳朵贴上砖缝。里面的喘息断断续续，夹着木头摩擦衣料的窸窣声。

"梁压着人。"

"再塌，灯盏也没了。封口、轮守纸、泥痕都在箱里，明日拿什么复核？"

三户的人聚在歪屋前，没有谁往前跨。门内又响了一声，短促得像被什么掐断。共同保管箱的铜扣同时闪过一线冷白，随后被滑落的瓦片遮住。

陆沉渊扶墙赶到时，呼吸只进得了半口深。夜气灌入喉管便堵在肋间，怎么也沉不到腹底，好像胸腔里有一面软墙拦住了去路。他只睁着左眼，看见灯座裂缝正把护阵剩下的暗红火痕往屋基里扯。

他没有去看箱。

"谁还在里面？"

门边的人用手比了比："靠内墙。腿可能压住了。"

陆沉渊蹲下，掌根撑住砖面。指节碰到湿灰时没有温度，也没有粗糙感——好像手掌隔了一层不导触觉的皮。他将重心全移到右腿，才勉强蹲稳："先问三户。箱是你们共守的，屋也是你们的。"

"还问什么？"一户守物的人盯着乱木后的铜扣，嘴唇发青，"灯盏若压坏，州府会说我们毁封。先拖箱，拖出来再拆梁，也就几息。"

"那几息谁担？"

无人答。门内传来一下沉闷的刮擦，像是什么重物在地面上被缓慢拖动，又像困在里面的人在试着挪开身上的东西。声音拖了很长，末尾是一声极轻的呻吟。

冷意继续往下压。护阵裂处啪地断开一小截，暗红火痕落成灰粉。屋顶又倾了一寸，门缝里的手指重新伸出，这次没有力气抓，只在砖面上划了两道。

苏晚挤到人群前。她掌背的暗光贴着新裂的一格跳，指尖冷得握不住袖口。她没有碰陆沉渊，也没替他开口，只把手按在自己胸前，缓过一阵气，问守物的两户："你们还守箱吗？"

"守。"

"守物，还是守里面的人？"

铜扣被瓦砾撞了一下，声音又轻又脆。

先前主张拖箱的人抬起手，在半空停了片刻，转身抓住堵门的砖："先拆梁。箱子压住，算我的一份。"

第二户的人把轮守纸从腰间抽出来，折了两折，塞进衣襟："屋塌了，我那份也不撤。先救人。"

退出轮守的那一户原本站得最远。此时也走到门边，弯腰搬开第一块碎砖："我不重新接物，也不替你们认封口。我只救人。"

莫井兰把被砖边磨破的手背藏到袖后，点了点头："三户都说清了。先救人。箱不动，灯盏不点，住户命火一缕也不出。"

陆沉渊撑着墙站起来，退到泥圈外能看见的位置。他离共同保管箱最近不过三步，只要跨过倒下的桌脚，便能碰到箱侧。他却往后挪，让开那条路。

"我不靠近箱。"他说，"谁也别替我补这一段见证。"

斜梁忽然下挫。

冷铁碰撞声从巷口逼近，顾巡的债链先掠过灯影。链节没有扑向陆沉渊，也没有缠住任何一盏住户命灯，而是贴地滑进门缝，绕过断砖，咬上斜梁中段。

顾巡站在歪屋外，手背青筋一根根绷起。

"这条链接的是有效追缴令。"他声音发紧，"撑梁不改令，也不撤旧追缴。屋一稳，链仍要回到该锁的归属上。"

链节收紧，梁木顿时迸出一串碎屑。冷铁气味灌满门洞，浓得刮嗓子。旁边几盏泥灯齐齐暗了一层，焰尖缩得像针。有人本能地护住自己的命灯。

顾巡看见了，手腕一翻，把债链余段扣在自己臂上。链身原本要向灯火偏去，硬生生被扯回。铁环陷进他的骨节，指根发白。

"都退开灯。"他咬着字，"我只借梁的重，不取你们的火。"

莫井兰俯身去看链节落处，一道一道确认没有支链牵向住户，才喊："拆！"

砖块一块块传出去。没有人排成整齐的队，谁离得近谁接，接不稳就放地上，再换手。碎瓦割开掌心，血落在泥里，很快被冷气凝成暗点。有人的指甲被砖缝别翻，咬着嘴唇没有出声，把砖放下，换一只手继续搬。门缝拓宽后，里面露出半截衣袖，袖下的手腕还在动。

苏晚想蹲下，掌背那道裂纹却猛地一跳。她身体晃了晃，扶住墙，没有把自己的命灯往前送，只将一块松砖推到脚边："这一块空了，别从上面掀。"

陆沉渊顺着她指的地方探手，摸到砖后压着的木楔。他没有动用识账术，右眼一直闭着。只凭掌下的震动等梁木停住，才把木楔向外抽。

抽到一半，指头忽然失力。

不是痛——是手掌完全感觉不到木楔的纹路，仿佛捏着一截不存在的东西。他换了个握法，用虎口夹住楔子边沿，靠腕骨和掌根硬别，才把它拧了出来。额角磕在门框上刮破一层皮，血珠渗出来糊住半边视线。他没有擦，等视野里的黑影散开，再把木楔递给身后的人。

"够了。"苏晚说，"你退。"

"里面还压着腿。"

"你再进去，谁来认你没碰箱？"

陆沉渊看向倒塌的桌脚。箱子还在右侧，封口被灰盖住一半，铜扣朝外。离他越近，越像一个能补回物证的机会。

他把手从门框上拿开，退回泥圈外。

"我不进去。"

这一退让出了位置。三户的人从扩开的门洞钻入，两人托住压腿的横木，一人把受困者往外拖。斜梁受力改变，债链猛地向下一沉。

顾巡的肩膀被扯得一偏，膝盖撞在地上。铁环在他腕上拧紧，冷铁味骤浓。靠墙的泥灯又暗下去，焰尖几乎贴住灯油。

"住手！"莫井兰朝屋里喊，"梁要走！"

顾巡抬头看了一眼那些缩小的灯焰，五指没有朝它们张开。他将债链在小臂上又缠一匝，以肘骨抵住地面。链节摩擦断梁，发出令人牙酸的刮响。

"继续拖。"

屋内的人不再停。

先是一只脚从门洞下露出来，鞋底沾满泥灰。接着是腰、肩和垂下的头。门外的人抓住衣襟和手臂，一齐向后退。受困者被拖离屋基时仍有呼吸，胸口起伏很浅，喉间却终于挤出一声完整的咳。

那声咳落下，斜梁也落下。

顾巡猛地松开腕上那匝链。债链从梁木间弹出，断梁砸穿地面，整面内墙向里坍塌。共同保管箱被木石压入屋基，只剩一角封布在缝隙里晃了晃，很快也被尘土盖住。

灯座裂成两半。

护阵的暗红火痕在裂口处熄去一段，沿巷的泥灯接连晃动。没有一盏彻底灭掉，也没有哪一户的命火被抽走，然而屋檐下原本连着的微光断了，留下一个黑沉沉的缺口。

尘灰散开后，临街屋的门已经不见了。墙向内折，屋基陷落，任何人再进去都会把剩下的梁带倒。

三户站在废墟前，谁都没有说"还能修"。

莫井兰先去看被救出的人，指尖停在鼻下，确认气息还在。她抬起头，脸上灰一道、血一道："人出来了。"

守物的两户望着塌陷处。

"箱呢？"

陆沉渊没有跨进断裂的泥圈。他蹲在外缘，用一截掉落的瓦片沿地面轻轻拨开浮灰，露出箱角压过的浅印。印子往下延伸，止在新塌的屋基里。

"在下面。"他声音发哑，"位置能认。现在取，屋基还会走。"

"残命灯盏……"

"没亮过。"莫井兰接道，"没开封，没得守火，也没人碰它。它只是被压住。"

主张先拖箱的人蹲下，把手按在那道浅印旁。掌心的伤口被砂石硌得发抖，他仍没有把手收回："屋算我这一份。"

第二户的人站到他身后："也是我的。"

已经退出轮守的那户没有去碰箱印，只将救人时撕破的袖口系紧："我不认箱里的情形。屋塌在眼前，我认。"

没有欢声。被救出的人还躺在冷泥上，呼吸每一下都牵得旁人屏住气。临街屋成了一堆无法再入住的断木，护阵缺口吹进来的夜气刮过众人手背，像细小的刀。

苏晚靠着墙，掌背失温的暗光仍贴着裂纹跳。她看了陆沉渊一眼："你怕吗？"

陆沉渊望着屋基下那一点被压住的封布："怕。"

"后悔没拿箱？"

他很久没有答。呼吸仍旧只进得到肋间，每一口都像撞在一面看不见的壁上弹回来。他把沾血的手掌压回袖中："若先拿箱，现在躺在这里的就未必还能咳。"

三户没有应声，只各自去扶受困者。有人护头，有人托腿，有人把自己的外衣垫到冷泥上。谁也没有提取灯火，谁也没有要求陆沉渊用身体补上塌掉的阵痕。

顾巡最后才收链。

债链从废墟上滑回来，经过灯座裂口时忽然卡了一下。他腕骨已经被勒得发僵，只能换手提链。链尾拖过断梁，带下一块薄薄的木屑。

木屑背面没有焦黑，只有一道银灰压痕。

顾巡把它托到灯下。压痕沿木纹缺去一角，边缘细密，沾着与州府转运残印相同的冷灰色。它没有发亮，也没有自行显出任何去向，只在靠近债链时渗出冷铁般的气味。

陆沉渊闭着右眼，没有伸手。

"这是梁上带回来的。"顾巡说，"只能认今夜由我的链刮下，不能认是谁压的，也不能认何时留下。"

莫井兰用尚未裂开的那只手接住一片干净瓦片，让顾巡把木屑放上去。她没有按印，只守在旁边："我认它从断梁上落下。我不认别的。"

两户守物的人也各退半步。

"今夜不补证。"

"等复核时再选认不认。"

顾巡把债链重新绕回腕间。链节碰到那道银灰压痕，断续灰痕一闪而过，随即沉下。他看向被压住的共同保管箱，又看向彻底失用的临街屋。

"旧追缴还在。半寿送审也不因救人停。"他将木屑连瓦片放到轮值桌残存的一角，"这道痕明日须与转运残印分开比对。三户谁到场，谁只认亲见；谁拒绝，照拒绝留着。"

巷口的冷意没有退。

护阵缺口里又落下一撮干灰，打在瓦片边缘。银灰压痕隔着半指距离映着它，颜色相近，却没有合在一起。顾巡收紧债链，陆沉渊仍站在泥圈之外。三户扶着救出的人往未塌的灯下移，身后那座屋一点点沉入黑暗。

残命灯盏留在可追溯的屋基下，封口未启，灯火未醒。

瓦片上的银灰压痕，则等着下一次有人到场、有人拒绝、有人亲眼看它与州府残印能否严丝合缝。
