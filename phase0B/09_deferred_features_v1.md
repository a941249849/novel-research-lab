# v1.0 延期与未来架构展望 (Deferred Features Spec)

本文件作为 Phase 0B 冻结包的一部分，锁定并定义了不进入 v1.0 实现范围的复杂功能，防止在下一阶段开发时发生需求蔓延（Scope Creep）。

---

## 1. v1.0 冻结排除的延期特性

在 v1.0 研发周期内，以下 7 大子系统被严格排除在实现之外：

1.  **重生时间线 DAG 分叉与回滚引擎 (DAG Rebirth Engine)**：
    *   *描述*：用于处理由于重生回档导致的故事大纲分裂和记忆/气运跨线继承。
    *   *排除原因*：分叉时间线会引入大纲发散爆炸风险，影响 v1.0 闭环的可靠性。
2.  **多马甲因果/声望防火墙 (Multi-Persona Karma Firewall)**：
    *   *描述*：多重假名身份在阵营和因果关系上的物理隔离与计算防火墙，防止逻辑穿透。
    *   *排除原因*：可以通过静态的伪装属性与剧情事件来表现，无需在数据结构层作账号级隔离。
3.  **动态法理/规则覆写图层 (Dynamic Domain Rule Overlay)**：
    *   *描述*：运行时动态重写某一区域内所有 Actor 属性公式的限制法则图层。
    *   *排除原因*：完全可转化为地图节点的静态文字提示语，不需要代码层动态执行。
4.  **动态社会、关税与地缘政治模拟 (Dynamic Social Simulation)**：
    *   *描述*：基于博弈论和纳什均衡的大型派系决策与资源竞争动态系统。
    *   *排除原因*：v1.0 写作只需静态的敌对度配置，动态模拟对生成第一章并无实质增益。
5.  **图数据库 Neo4j 等物理图集成 (Graph Database Integration)**：
    *   *描述*：用于追踪极度复杂的关系网和相邻超凡途径的互换的最短路径算法。
    *   *排除原因*：图计算开销对于 MVA 过重，v1.0 采用轻量 JSON 存储关系矩阵。
6.  **智能法宝神兵 (Sentient Weapon Actor)**：
    *   *描述*：将极道武器提升为具有情感、意志度和复苏等级的 Proxy-NPC 实体。
    *   *排除原因*：会使状态账本（State Ledger）追踪非生物实体，显著增加复杂度。
7.  **编译型超凡逻辑表征 (Compiler-like Power Engine)**：
    *   *描述*：将功法和法术技能模拟为具备输入-输出接口、负载因子和环境道痕乘数的代码级级联系统。
    *   *排除原因*：过度设计。v1.0 将技能定义为纯粹的静态配置文本。

---

## 2. 演进路线图 (Roadmap)

*   **v1.0**：跑通“机制脱敏 -> 双轨身份账本约束 -> 避战与法宝反噬大纲 -> 第一章原创正文生成 -> 原创度审计”的基本闭环。
*   **v1.5**：引入多账号马甲防火墙（`Karma Firewall`）及智能法宝意志追踪，支持生成多张长篇地图切换剧情。
*   **v2.0**：实现多周目重生 DAG 引擎和图数据库相邻超凡体系，探索具备自适应决策的多 Agent 交互式网文大纲沙盒。
